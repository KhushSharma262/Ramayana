# Ramayana

AI-assisted production system for a Hindi Ramayana web series based primarily on Goswami Tulsidas's *Ramcharitmanas*.

## Project Principles

- Canon first
- Source traceability
- Human-realistic performance
- Professional cinematic direction
- User-controlled creative approval
- AI as a production tool, not a source of canonical truth
- Versioned and traceable production decisions
- Zero-budget production pipeline

## Project Architecture

The repository contains the production architecture for:

- Canon and research
- Characters
- Locations and architecture
- Costumes and props
- Animals and nature
- Acting and performance
- Motion and rigging
- 3D
- Cinematography and lighting
- Audio, narration and music
- VFX, compositing and editing
- Scenes and shots
- Continuity
- AI agents and production orchestration
- QA and approval
- Registries and traceability
- Episode production

## Current Phase

Structure and production architecture established.

Content, research, canonical decisions and production assets will be added progressively.
