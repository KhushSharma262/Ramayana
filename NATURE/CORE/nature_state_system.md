# NATURE STATE SYSTEM

Natural elements have states.

Examples:

Tree:
healthy
dry
flowering
fruiting
wind-affected
rain-wet
dust-covered
damaged
burned
recovering

River:
normal
low
high
flooding
muddy
clear
rain-fed
disturbed
calm

Ground:
dry
moist
wet
muddy
dusty
snow-covered where applicable
burned
disturbed

State changes belong to the appropriate environment/event systems
but the resulting natural state must remain consistent with NATURE.
