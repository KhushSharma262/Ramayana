# NATURE IDENTITY VS STATE

This distinction is mandatory.

## IDENTITY

What the thing fundamentally is.

Examples:
- cedar tree
- river
- mountain
- grassland
- cloud system
- soil type

## STATE

What condition it is currently in.

Examples:
- wet
- dry
- flowering
- muddy
- foggy
- stormy
- burned
- recovering

## STATE TRANSITION

State changes must have a cause.

Examples:

dry ground
    ->
rain
    ->
wet ground

clear atmosphere
    ->
humidity increase
    ->
mist

normal vegetation
    ->
fire
    ->
burned vegetation
    ->
recovery

Do not allow an AI generation step to create unexplained state
changes.
