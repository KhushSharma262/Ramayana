# NATURE RANGES

Every important natural system should be described using ranges
rather than a single fixed value wherever natural variation exists.

Examples:

ATMOSPHERE
- humidity range
- visibility range
- haze range
- aerosol range
- mist range

WIND
- normal speed range
- gust range
- direction range

RIVER
- normal flow range
- seasonal flow range
- water-level range
- clarity range

VEGETATION
- normal density range
- seasonal density range
- growth variation

CLOUDS
- coverage range
- density range
- movement range

Ranges are constraints, not instructions to randomly vary every shot.

ENVIRONMENT selects the current state from the allowed range based
on the established world state.
