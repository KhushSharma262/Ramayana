# NATURE

NATURE is the natural-world truth layer.

## What this folder does

It defines:

- natural identities
- physical characteristics
- biological characteristics
- ecological relationships
- natural ranges
- possible states
- controlled variation
- continuity
- source classification

## What it does NOT do

NATURE does not determine the exact appearance of every shot.

It does not control:

- exact lighting
- camera framing
- lens
- editing
- compositing
- final VFX implementation

It does not lock:

- one atmosphere
- one sky
- one cloud state
- one vegetation density
- one river appearance
- one weather condition

## The correct model

NATURE
    ↓
defines identity + possible states + constraints

ENVIRONMENT
    ↓
selects and simulates the current state

CINEMATOGRAPHY
    ↓
photographs that state

COMPOSITING
    ↓
integrates the elements

## Example

A forest:

NATURE:
    forest ecology
    tree/plant identities
    soil
    natural ranges
    seasonal behavior

ENVIRONMENT:
    dawn
    high humidity
    light mist
    low wind
    wet ground

CINEMATOGRAPHY:
    selected camera/lens/light

Result:
    one believable state of the same forest.

Later:

ENVIRONMENT:
    evening
    dry air
    stronger wind
    no mist

The forest remains the same world while its state changes.

## Core principle

CONSISTENCY DOES NOT MEAN REPETITION.

Natural continuity means:

SAME IDENTITY
+
BELIEVABLE CHANGE
=
LIVING WORLD
