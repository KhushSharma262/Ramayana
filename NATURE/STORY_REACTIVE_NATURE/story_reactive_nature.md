# STORY REACTIVE NATURE

Natural reactions to story events must be event-driven.

Examples:

event
    ->
wind changes
    ->
vegetation responds
    ->
animals react
    ->
atmosphere changes
    ->
sound environment changes

The reaction must have:

- event ID
- affected natural systems
- onset
- intensity
- duration
- aftermath
- continuity state

Do not use dramatic environmental reactions merely because they
make a shot look cinematic.
