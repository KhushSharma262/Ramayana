# DIVINE NATURE

This folder defines how extraordinary sacred/narrative natural
responses are classified.

It does NOT automatically declare every beautiful natural event
to be divine.

A divine natural phenomenon requires:

- source support, or
- an explicitly approved production interpretation

Examples may include extraordinary:

- light
- atmospheric changes
- flowering
- celestial appearance
- environmental response

CANON determines whether the event is source-supported.

NATURE defines the natural element involved.

ENVIRONMENT defines the resulting world state.

VFX implements the visual effect.

CINEMATOGRAPHY determines how it is photographed.

Never use DIVINE_NATURE as a shortcut for cinematic spectacle.
