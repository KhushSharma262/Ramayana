# PROMPTS

PROMPTS is the controlled AI-instruction layer.

## Purpose

It converts approved production decisions into structured prompts
for AI tools.

## It does NOT own

CANON
    = source truth

CHARACTERS
    = character truth

LOCATIONS
    = spatial truth

COSTUMES
    = costume truth

ACTING
    = performance behavior

MOTIONS
    = physical movement

NATURE
    = natural-world truth

ENVIRONMENT
    = current world state

CINEMATOGRAPHY
    = camera truth

MATERIALS
    = material truth

PROMPTS
    = instructions that communicate those decisions to AI

AI
    = model/generation system

QA
    = determines whether the result is acceptable

## Most important rule

THE PROMPT IS NOT THE SOURCE OF TRUTH.

It is a compiled representation of the source of truth.

## Prompt architecture

AUTHORITATIVE SYSTEMS
        ↓
SOURCE REFERENCES
        ↓
BUILDING BLOCKS
        ↓
PROMPT TEMPLATE
        ↓
SHOT / SCENE PROMPT
        ↓
MODEL-SPECIFIC FORMAT
        ↓
AI GENERATION
        ↓
OUTPUT QA

## Locked vs variable

LOCKED:

- character identity
- approved costume identity
- established architecture
- important props
- canonical requirements
- continuity-critical details

VARIABLE:

- legitimate natural variation
- approved camera variables
- minor background variation
- secondary movement
- atmospheric state where environment permits

Variable does not mean random.

## Human realism

Prompts must not request generic "perfect" humans.

Where appropriate, preserve:

- breathing
- weight shifts
- asymmetry
- blinking
- eye movement
- micro-expressions
- pauses
- natural hesitation
- physical weight
- secondary motion

## Final principle

SOURCE OF TRUTH
    >
PROMPT
    >
MODEL

Never reverse this hierarchy.
