# PROMPT HIERARCHY

Prompt information should be assembled in this order:

1. TASK
2. SUBJECT / IDENTITY
3. CANON REQUIREMENTS
4. SCENE CONTEXT
5. ACTION / PERFORMANCE
6. ENVIRONMENT
7. COSTUME / PROPS
8. CAMERA
9. LIGHTING
10. MATERIAL / PHYSICAL BEHAVIOR
11. CONTINUITY
12. OUTPUT REQUIREMENTS
13. NEGATIVE CONSTRAINTS

Not every prompt requires every layer.

Do not add irrelevant information merely to make prompts longer.
