# PROMPT QA

Before generation check:

- correct character
- correct identity
- correct source
- correct location
- correct costume
- correct action
- correct emotional state
- correct environment
- correct camera
- correct continuity
- correct model format
- correct negative constraints

After generation check:

- identity
- anatomy
- performance
- environment
- architecture
- costume
- materials
- camera behavior
- continuity
- AI artifacts

A technically valid prompt can still produce an invalid result.
