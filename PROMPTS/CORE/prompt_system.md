# PROMPT SYSTEM

PROMPTS is the controlled instruction layer between the production
systems and AI generation tools.

Its purpose is to convert approved production information into
precise AI instructions.

PROMPTS does NOT define:

- canon
- character identity
- location truth
- costume truth
- acting rules
- motion rules
- camera rules
- environment rules

Those systems remain authoritative.

PROMPTS retrieves and assembles those decisions.

## Core pipeline

CANON
    ↓
PRODUCTION SYSTEMS
    ↓
SCENE / SHOT REQUIREMENTS
    ↓
PROMPT BUILD
    ↓
MODEL-SPECIFIC FORMAT
    ↓
AI GENERATION
    ↓
OUTPUT VALIDATION
    ↓
APPROVAL

## Fundamental rule

The prompt must never become the source of truth.

The prompt is a representation of the source of truth.

If the prompt conflicts with an authoritative production system,
the authoritative system wins.
