# PROMPT POLICY

Prompts must be:

- traceable
- structured
- versioned
- reusable
- model-aware
- continuity-aware
- canon-aware
- concise where possible
- explicit where ambiguity would cause drift

Do not write prompts as uncontrolled prose.

Do not silently invent:

- character attributes
- costumes
- locations
- architecture
- historical details
- religious details
- emotional states
- camera decisions
- environmental states

If information is missing, the prompt should identify the missing
decision rather than inventing it.
