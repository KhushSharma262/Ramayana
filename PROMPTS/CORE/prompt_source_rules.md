# PROMPT SOURCE RULES

Every important prompt component should be traceable to its source.

Possible sources:

- CANON
- CHARACTER
- LOCATION
- ARCHITECTURE
- COSTUME
- PROPS
- ANIMALS
- NATURE
- ENVIRONMENT
- ACTING
- MOTIONS
- CINEMATOGRAPHY
- MATERIALS
- AUDIO
- SCENE
- SHOT
- DIRECTORIAL DECISION

A prompt may combine multiple sources.

The prompt registry must record those dependencies.
