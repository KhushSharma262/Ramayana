# VALIDITY REGIMES

Every model must state where it is valid.

Possible regime dimensions:

- temperature
- pressure
- humidity
- moisture
- strain
- strain rate
- velocity
- acceleration
- Reynolds number
- Mach number
- Knudsen number
- scale
- time
- load
- geometry
- contact condition
- phase
- material condition

Never extrapolate beyond a model's validated range without marking the extrapolation.

Regime transitions must be explicitly represented.

Examples:

elastic → plastic

laminar → turbulent

dry → wet

solid → softened → molten

stable → fracture

intact → damaged

Do not assume a regime transition occurs at a visually convenient threshold.
