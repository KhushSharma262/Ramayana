# MATERIAL SYNONYMS AND TRANSLATION CONTROL

Historical Indian material terminology can map imperfectly onto modern scientific terminology.

## Required fields

- source term
- language/script
- transliteration
- literal translation
- contextual meaning
- proposed modern identity
- alternative identities
- confidence
- evidence source

## Rules

Never assume:

historical word = modern species
historical word = modern mineral
historical word = modern alloy
colour name = pigment identity
ornament name = material identity

If a Sanskrit or vernacular term has multiple scholarly interpretations, preserve them and route the question to `07_HISTORICAL_CANONICAL`.
