# CORDAGE, ROPE, MATS, THATCH AND FIBRE ASSEMBLIES

These are material assemblies rather than single raw substances. Their constituent fibre identity must remain traceable.

## Families

- twisted fibre cord
- braided cord
- rope
- thread
- string
- netting
- woven mats
- reed mats
- grass mats
- bamboo mats
- thatch
- fibre bundles
- lashings

## Required identity fields

- constituent fibre/material
- fibre preparation
- twist/braid/weave construction
- diameter/thickness class
- binding material if any
- surface treatment
- historical/traditional construction
- intended use
- evidence status

Do not treat all rope as one material. Construction changes physical identity and must link to PHYSICS and SURFACE_STRUCTURE.
