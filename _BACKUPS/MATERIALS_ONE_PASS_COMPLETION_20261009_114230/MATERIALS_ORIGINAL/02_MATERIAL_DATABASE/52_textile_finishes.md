# TEXTILE FINISHES

## Finish families

- washing
- sizing
- starching
- calendaring/pressing
- oiling
- waxing
- mordant-assisted dyeing
- resist processes
- printing
- embroidery
- metallic thread decoration
- surface polishing/finishing

## Rule

A finish does not replace the base textile identity.

Record:

base fibre + yarn + fabric + dye + finish + decoration

rather than calling the final appearance a new generic material.
