# MATERIAL RESEARCH QUEUE

This is a controlled exception list, not a dumping ground.

Each unresolved material must have:

- temporary ID
- source term or scene requirement
- suspected material family
- why identification matters
- possible identities
- missing evidence
- priority
- downstream impact
- owner folder
- resolution status

Statuses:

OPEN
UNDER_RESEARCH
PROVISIONAL
RESOLVED
REJECTED
SUPERSEDED

An unresolved item must never silently become a production truth.
