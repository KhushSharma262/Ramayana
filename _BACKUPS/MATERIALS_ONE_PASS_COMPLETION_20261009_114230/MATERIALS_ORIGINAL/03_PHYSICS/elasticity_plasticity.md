# ELASTICITY AND PLASTICITY

Elastic deformation is recoverable.

Plastic deformation is permanent.

Models may include:

- linear elasticity
- nonlinear elasticity
- hyperelasticity
- viscoelasticity
- elastoplasticity
- rate-dependent plasticity

The selected model must correspond to the material.

Do not use a cloth model for wood.
Do not use a rigid-body model for a deformable material when deformation affects the observed result.

Record:

- constitutive law
- parameters
- calibration source
- validity range
- failure behavior
