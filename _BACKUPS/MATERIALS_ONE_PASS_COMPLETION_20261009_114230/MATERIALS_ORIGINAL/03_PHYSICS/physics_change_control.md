# PHYSICS CHANGE CONTROL

Any change to an approved physical property or model requires:

1. Change request.
2. Reason.
3. Source/evidence.
4. Affected material IDs.
5. Affected models.
6. Affected simulations.
7. Affected assets.
8. Affected scenes/shots if known.
9. Revalidation.
10. QA.
11. Approval.
12. Version increment.
13. Traceability update.

No silent physics changes.

A change in a fundamental property may require downstream regeneration.
