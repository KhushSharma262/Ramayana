# MATERIALS Production Completion Checklist

This checklist tracks work that cannot be completed truthfully through structural repair alone.

## Research
- [ ] Review every open research record.
- [ ] Attach genuine sources and relevant quotations or references.
- [ ] Record alternatives, confidence, and rationale for reconstructions.
- [ ] Resolve questions or explicitly retain them as unresolved.

## Asset assignments
- [ ] Assign only real, identifiable project assets.
- [ ] Link each assignment to its approved material record.
- [ ] Record the source, owner or responsible party where applicable, and approval status.
- [ ] Do not treat an empty assignment template as a completed assignment.

## Master registry
- [ ] Create material entries only when supported by project evidence or explicitly labeled reconstruction.
- [ ] Use stable unique IDs and traceable links.
- [ ] Check for duplicates and contradictory definitions.
- [ ] Do not invent material entries to satisfy a count.

## Evidence ledger
- [ ] Record actual source identifiers, locations, access details, and relevant evidence.
- [ ] Classify each item using the project's evidence taxonomy.
- [ ] Distinguish source facts from inference, reconstruction, and directorial choice.
- [ ] Do not create placeholder citations that look like real evidence.

## Renderer validation
- [ ] Execute each defined renderer test in the intended environment.
- [ ] Record the actual test configuration and result.
- [ ] Capture relevant outputs or screenshots.
- [ ] Document failures and rerun after fixes.
- [ ] Never mark an unrun test as passed.

## Final approval
- [ ] Review migrated rules against their legacy sources.
- [ ] Check continuity and state behavior across representative shots.
- [ ] Review open risks and unresolved questions.
- [ ] Obtain the required production approval.

A checked box must represent work actually performed. Creating this checklist does not mean the work is complete.
