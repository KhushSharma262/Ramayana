# Asset Assignment Rules

Defines traceability between actual production assets and material records.

## Assignment requirements

Each assignment must reference an existing asset and an existing material record. Record asset ID/path, material ID, intended component or surface, assignment status, rationale, source/approval reference when available, and continuity constraints.

Do not invent assets to populate the assignment system. If no real asset is available, leave the assignment uncreated and record the dependency in the completion checklist.

A placeholder schema is not a valid asset assignment.
