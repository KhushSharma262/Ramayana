# COMPOSITE AND ENGINEERED HISTORICAL MATERIALS

## Scope

Materials created by combining constituents so that the resulting material has its own production identity.

Examples:

- bronze
- mortar
- plaster
- ceramic body
- glazed ceramic
- faience
- painted/coated material
- composite textile
- laminated or inlaid materials
- rope/cord systems
- packed earth
- thatch assemblies where the assembly itself is relevant

## Rule

Do not create a new material merely because an object has multiple components.

Object:

wood + bronze fitting + leather grip

remains an object assembly.

Material:

bronze

is a material definition.

## Required record

For a genuine composite material:

- constituents
- ratios/ranges where known
- manufacturing process
- transformation caused by processing
- resulting identity
- uncertainty
- historical evidence
