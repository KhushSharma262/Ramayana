# PHYSICAL PROVENANCE

Every physical claim must be traceable.

Required chain:

SOURCE
→ DATA
→ INTERPRETATION
→ PHYSICAL PROPERTY
→ MODEL
→ IMPLEMENTATION

Sources may include:

- peer-reviewed literature
- standards
- laboratory measurements
- authoritative databases
- conservation science
- engineering references
- archaeological science
- experimental archaeology
- documented traditional practice
- direct measurement

Source type must be preserved.

Do not convert an inference into a measurement.

Do not convert a simulation parameter into a measured property.
