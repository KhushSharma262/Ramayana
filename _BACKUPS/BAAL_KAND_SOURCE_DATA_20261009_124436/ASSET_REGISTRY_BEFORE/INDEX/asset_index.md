# Asset Index

## Purpose
Central index of production assets. This index must describe real assets from the project; do not create fictional asset records to fill gaps.

## Required fields
- asset_id
- asset_name
- asset_type
- canonical_character_or_environment_reference, if applicable
- source file or source document
- asset version
- status
- scenes and shots using the asset
- linked material assignment records
- owner and reviewer
