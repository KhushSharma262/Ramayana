# REAL-WORLD VALIDATION

Validation compares model behavior against physical reality.

Possible validation targets:

- laboratory measurement
- field observation
- documented physical experiment
- archaeological reconstruction
- engineering test
- conservation test
- controlled production test

Validation must specify:

- target phenomenon
- measured quantity
- conditions
- measurement uncertainty
- model output
- discrepancy
- acceptable tolerance
- reason for tolerance

One matching image is not sufficient validation.
