# YARN, WEAVE AND FABRIC MATERIALS

## Stages

raw fibre
→ cleaned/prepared fibre
→ spun fibre/yarn
→ yarn construction
→ woven/knitted/braided fabric
→ dyed/printed/finished fabric

## Construction families

- plain weave
- twill
- patterned weave
- tapestry-like structures
- braided structures
- netted structures
- felted/nonwoven structures
- mats
- cords
- ropes

Only use a construction when evidence supports it.

## Historical Indian textile evidence

Cotton weaving is extremely old in the Indian subcontinent; archaeological and museum sources also document silk, wool and diverse hand-made textile traditions.

## Production rule

The database identifies fabric construction; detailed drape, friction, wetness and tearing behavior belong in physics/behavior.
