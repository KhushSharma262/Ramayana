# Material Record Requirements

Defines the minimum information expected for a traceable material entry.

## Required fields

- Material ID: stable and unique.
- Material name and category.
- Intended use and physical function.
- Base material identity and construction, if established.
- Surface properties and expected physical behavior.
- Applicable states and their causes and persistence.
- Evidence classification and source references.
- Uncertainty, alternatives, confidence, and rationale where needed.
- Continuity constraints and permitted state changes.
- Asset references, where actual assets exist.
- Validation status, tests performed, results, and outstanding risks.

Unknown information must be marked UNKNOWN or OPEN. Do not use guessed values to satisfy required fields.
