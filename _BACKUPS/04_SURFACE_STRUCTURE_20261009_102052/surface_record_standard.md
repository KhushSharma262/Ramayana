# SURFACE RECORD STANDARD

For each relevant feature, record:
- surface_record_id; material_id; material/version
- feature name/type; scale class
- characteristic dimensions and SI units
- size range/distribution only when supported
- orientation, density/spacing, spatial correlation and clustering
- profile/depth/height/topology when relevant
- composition/phase and layer order when relevant
- formation mechanism and likely cause
- current material state and history
- source, provenance, confidence and uncertainty
- validity/scale range
- physical consequences: optical, contact, thermal, fluid, mechanical or acoustic
- representation: geometry, displacement, normal, texture, volumetric or other
- renderer/lighting handoff and version
- continuity status and downstream dependencies

Use UNKNOWN if a needed fact is not known; NOT_APPLICABLE only when it genuinely does not apply. A shader control is not automatically a measured physical quantity.
