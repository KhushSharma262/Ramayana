# NARRATION INFORMATION RULES

Before adding narration ask:

1. Is this information necessary?
2. Is it already visible?
3. Is it already communicated by dialogue?
4. Is it better expressed through the source verse?
5. Is narration the clearest solution?

Narration may:

- establish context
- bridge time
- establish location
- connect events
- introduce characters
- clarify necessary relationships
- compress necessary events
- introduce a verse
- provide narrative reflection
- transition between sequences

Narration should not:

- repeat obvious visuals
- explain every emotion
- describe every camera shot
- replace character acting
- replace dialogue unnecessarily
- manufacture unsupported canon
- add invented historical facts
- turn the narrator into a modern commentator

The audience should be allowed to experience scenes without
constant verbal explanation.
