# NARRATOR TRANSITION SYSTEM

Narrator changes are narrative events.

A transition from Tulsidas to Shiva must contain:

1. Previous narrator
2. Narrative position
3. Handoff point
4. Reason for transition
5. Visual context
6. Dialogue/context establishing Shiva and Parvati
7. First Shiva narration
8. Confirmation that Rama-katha has begun

## Standard structure

TULSIDAS
    ↓
Shiva-Sati-Parvati narrative
    ↓
Shiva-Parvati present together
    ↓
Tulsidas reaches the approved handoff
    ↓
Narrative attention moves into the Shiva-Parvati interaction
    ↓
Shiva begins speaking
    ↓
Shiva continues into Rama-katha

The transition must feel intentional rather than like an unexplained
voice-over replacement.

## Return transition

If a later episode returns from Shiva's Rama-katha to the external
narrative:

SHIVA
    ↓
completion / pause of Rama-katha
    ↓
frame-story context
    ↓
TULSIDAS

This transition must also be explicitly recorded.

## No accidental switching

A narrator may not change merely because:

- a scene changes
- a location changes
- a verse begins
- the camera changes
- an AI voice generation changes
- an editing cut occurs

Narrator identity changes only through an approved narrative decision.
