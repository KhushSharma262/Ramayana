# NARRATOR HANDOFF RULES

Every narrator handoff requires an explicit record.

Required fields:

- previous narrator
- next narrator
- location
- scene
- narrative purpose
- handoff trigger
- final line/section of previous narration
- transition action
- first line/section of new narrator
- source/script reference
- approval status

Primary Episode 1 handoff:

TULSIDAS
    ->
SHIVA

The handoff is not merely an audio transition.

It must be supported by the narrative situation.
