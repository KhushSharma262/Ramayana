# NARRATION PLACEMENT

Narration may enter at:

- opening
- scene opening
- scene transition
- sequence transition
- time jump
- location change
- character introduction
- event introduction
- scene closing

Placement must be determined by narrative necessity.

Avoid placing narration over dialogue or important visual information
unless the overlap is intentional.

Every narration segment should have:

START
END
PURPOSE
NARRATOR
SOURCE / SCRIPT REFERENCE
SCENE
SEQUENCE
STATUS
