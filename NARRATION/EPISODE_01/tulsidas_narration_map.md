# EPISODE 1 - TULSIDAS NARRATION MAP

Tulsidas is the primary external narrator for the Shiva-Sati-Parvati
portion of Episode 1.

His narration should carry the audience through the approved
Shiva-Sati-Parvati narrative.

The exact narration segments are determined from:

- CANON
- approved source mapping
- Episode 1 script
- narration placement decisions

Do not invent narration merely to fill silence.

Each segment must receive:

- segment ID
- scene
- narrator
- source
- purpose
- exact text
- performance direction
- start point
- end point
- approval state
