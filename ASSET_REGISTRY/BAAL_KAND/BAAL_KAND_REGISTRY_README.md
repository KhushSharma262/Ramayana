# Bālakāṇḍ Asset Registry

## Hierarchy rules

- This folder is the Bālakāṇḍ content collection.
- Kanda-level category folders hold reusable assets and cross-episode records.
- `EPISODE_01`, `EPISODE_02`, and later episode folders hold episode-specific records and usage.
- Permanent asset IDs identify assets. Do not create a new asset ID merely because the asset is used in another episode.
- A mention in scripture does not by itself establish exact color, dimensions, construction, costume, anatomy, or camera design.
- Keep source citation, edition, verse locator, confidence, and approval state with each record.
- Do not delete legacy folders until references and migration results have been verified.

## Standard episode categories

ANIMALS, ARCHITECTURE, CHARACTERS, COSTUMES, LOCATIONS, MATERIALS, NATURE, PROPS, RITUALS, USAGE, VEHICLES, VFX.
