# CROSS REFERENCE RULES

Cross-references connect systems without copying their content.

A reference should identify:

SOURCE ID
TARGET ID
RELATIONSHIP
CONTEXT
VERSION
STATUS

Example:

CHAR_001
    APPEARS_IN
SCENE_014

SCENE_014
    LOCATED_AT
LOC_005

SCENE_014
    USES_COSTUME_STATE
COST_003_STATE_002

SCENE_014
    DERIVES_FROM
EVENT_021

Do not paste the full contents of another system into the registry.
