# MOTIONS SYSTEM

MOTIONS is the physical movement system.

It defines how bodies and objects physically move.

It does NOT define why a character moves.

ACTING defines motivation, emotion and performance intent.

MOTIONS defines physical execution.

## Movement must contain

- initiation
- acceleration
- movement
- deceleration
- stabilization
- secondary motion
- contact
- reaction

Avoid mathematically perfect movement.

Human movement contains:

- small corrections
- weight shifts
- balance adjustments
- asymmetry
- variable timing
- inertia
- imperfect stops
- natural pauses

## No universal movement

Characters must not share identical:

- gait
- posture
- gesture amplitude
- speed
- stillness
- transitions
- ceremonial behavior

Character-specific movement overrides generic motion where appropriate.

## Reusable motion

A motion asset can be reused only when:

- body proportions permit
- character movement rules permit
- context permits
- emotional state permits
- environment permits
- continuity permits

Reuse does not mean identical playback.
