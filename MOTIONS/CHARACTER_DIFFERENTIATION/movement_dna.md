# CHARACTER MOVEMENT DIFFERENTIATION

Generic motion is only the physical base.

Each character receives movement overrides.

Possible variables:

- gait length
- gait rhythm
- walking speed
- torso movement
- shoulder movement
- head stability
- gesture amplitude
- hand activity
- foot placement
- movement economy
- stillness
- balance style
- turning style
- stopping style
- ceremonial movement
- emotional movement

Do not assign differences arbitrarily.

Character movement should derive from:

- character definition
- personality
- context
- social role
- spiritual/narrative characterization
- acting direction
- approved performance design

This file does not itself establish scriptural claims.
