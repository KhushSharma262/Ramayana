# DOMAIN REGISTRY

Each domain record must declare:

domain_name
domain_record_id
authoritative_owner
version
snapshot
status
scope

Supported authoritative domains include:

BIOLOGY
BEHAVIOR
MOVEMENT
ECOLOGY
DOMESTIC_TRAINED
INTERACTION
VISUAL_IDENTITY
CONTINUITY
AUDIO
BATTLE_HIGH_STRESS
COSTUME
CINEMATIC_INTEGRATION
AI_PRODUCTION
RESEARCH
CONFLICTS_UNKNOWN
PRODUCTION_HANDOFF
QA_APPROVAL

The Registry references these systems; it does not replace them.
