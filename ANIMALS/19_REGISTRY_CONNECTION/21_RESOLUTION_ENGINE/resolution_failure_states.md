# RESOLUTION FAILURE STATES

UNKNOWN:
No valid record identified.

AMBIGUOUS:
Multiple valid candidates cannot be distinguished.

STALE:
Reference points to superseded state.

ORPHANED:
Reference has no valid target.

CONFLICTED:
Multiple authoritative records materially disagree.

INVALID:
Reference violates registry rules.

BLOCKED:
Downstream use is prohibited until resolved.

Registry never converts these states into a valid resolution without
authoritative input.
