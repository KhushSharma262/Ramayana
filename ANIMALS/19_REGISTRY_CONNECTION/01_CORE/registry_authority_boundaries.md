# REGISTRY AUTHORITY BOUNDARIES

DOMAIN SYSTEMS OWN TRUTH.

Registry owns:
- indexing
- stable identifiers
- references
- relationship mapping
- dependency mapping
- version references
- resolution routing
- connection integrity
- registry status
- registry audit

Registry does NOT own:
- biological truth
- behavioral truth
- movement truth
- ecological truth
- domestic/training truth
- interaction truth
- visual identity truth
- continuity truth
- audio truth
- costume truth
- cinematic truth
- research truth
- conflict resolution truth
- QA approval truth

Registry cannot overwrite an authoritative domain record.
