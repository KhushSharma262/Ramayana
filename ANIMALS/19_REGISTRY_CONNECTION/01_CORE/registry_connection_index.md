# REGISTRY CONNECTION SYSTEM

19_REGISTRY_CONNECTION is the controlled indexing, identity, reference,
resolution, and connection layer for the approved animal-world systems.

The Registry connects records.

The Registry does NOT create canonical truth.

The Registry does NOT replace domain authority.

The Registry does NOT resolve scientific, canonical, historical,
behavioral, ecological, or continuity disputes by itself.

Primary function:

AUTHORITATIVE RECORD
-> STABLE IDENTITY
-> REGISTERED REFERENCE
-> VALIDATED CONNECTION
-> VERSIONED RESOLUTION
-> DOWNSTREAM ACCESS

The Registry is the connective tissue between systems.
