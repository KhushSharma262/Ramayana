# REGISTRY CONNECTION DEFINITION

The Registry connects records across authoritative systems.

The Registry does not create canonical truth.

It provides controlled indexing, identity, reference, resolution,
dependency, version, lineage, and cross-system connection.

Registration is not approval.
Connection is not validation.
Resolution is not truth creation.

A registered record must identify its authoritative owner.

The Registry may report UNKNOWN, AMBIGUOUS, STALE, CONFLICTED,
ORPHANED, INVALID, BLOCKED, REJECTED, or SUPERSEDED states.

The Registry never converts an unresolved state into a valid state
through plausibility or guessing.
