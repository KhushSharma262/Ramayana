# REGISTRY MASTER PRINCIPLES

1. REGISTRY CONNECTS. IT DOES NOT INVENT.
2. EVERY RECORD HAS AN AUTHORITATIVE OWNER.
3. EVERY CONNECTION HAS A PURPOSE.
4. EVERY REFERENCE HAS A TARGET.
5. EVERY TARGET HAS AN IDENTITY.
6. EVERY MATERIAL REFERENCE IS VERSION-AWARE.
7. STALE REFERENCES ARE NOT VALID REFERENCES.
8. UNKNOWN IDS ARE NOT GUESSED.
9. DUPLICATE IDS ARE BLOCKED.
10. ORPHAN REFERENCES ARE BLOCKED.
11. REGISTRY STATUS DOES NOT EQUAL DOMAIN APPROVAL.
12. REGISTRATION DOES NOT EQUAL TRUTH.
13. APPROVAL DOES NOT TRANSFER AUTHORITY.
14. HISTORICAL RECORDS ARE NEVER SILENTLY REWRITTEN.
15. SUPERSESSION MUST REMAIN AUDITABLE.
16. CROSS-DOMAIN CONNECTIONS MUST RESPECT AUTHORITY.
17. REVERSE RESOLUTION MUST BE POSSIBLE.
18. FORWARD RESOLUTION MUST BE POSSIBLE.
19. CIRCULAR AUTHORITY IS FORBIDDEN.
20. FAIL-CLOSED IS THE DEFAULT.
