# INDIVIDUAL STATE HISTORY

Purpose:
Track important changes in an individual animal through story time.

Core state chain:

AGE
→ SEX
→ HEALTH
→ INJURY
→ ENERGY
→ HUNGER
→ THIRST
→ STRESS
→ FEAR
→ ALERTNESS
→ SOCIAL STATE
→ ENVIRONMENT
→ ACTIVITY
→ BEHAVIOR
→ RECOVERY

Each meaningful state change should record:

state_event_id:
individual_id:
story_time:
episode:
scene:
shot:
previous_state:
new_state:
cause:
evidence_or_decision:
duration:
visible_effects:
behavioral_effects:
movement_effects:
continuity_requirements:
approval:
version:

State history must distinguish story/world time from knowledge/research time.

A temporary state must not accidentally become a permanent identity attribute.

Example:

INJURY = temporary state

SPECIES = identity attribute

Do not mix them.
