# COMMON NAMES

## PURPOSE

Stores commonly used names associated with a biological species.

## REQUIRED FIELDS

species_id
name
language
region
historical_or_modern
source
usage
confidence
notes

## NAME TYPES

common
vernacular
regional
historical
modern
translated
adaptation_specific

## RULE

A common name is a label.

It is not automatically taxonomic evidence.

## MULTIPLE NAMES

Multiple names may legitimately map to one species.

## SAME NAME PROBLEM

The same common name may refer to different animals in different regions or historical periods.

Therefore every important common name should include:

language
region
period where relevant
source

## TRANSLATED NAMES

Translated animal names must remain linked to the original terminology from which they were derived.

## ANTI-HALLUCINATION RULE

Do not invent regional names.

Do not assign a common name merely because it sounds culturally appropriate.

Unknown names remain UNKNOWN.
