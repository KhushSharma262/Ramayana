# CLAIM RELATIONSHIP RULES

Evidence-to-claim relationships must be typed.

Allowed relationship types:

DIRECTLY_SUPPORTS
Directly supports the claim.

PARTIALLY_SUPPORTS
Supports only part of the claim.

INDIRECTLY_SUPPORTS
Supports the claim through a documented reasoning chain.

CONTEXTUALIZES
Provides useful context but does not establish the claim.

CONTRADICTS
Provides evidence against the claim.

REFUTES
Strongly demonstrates that the claim is incorrect.

DOES_NOT_ADDRESS
The evidence is relevant to the domain but does not establish the claim.

UNCERTAIN_SUPPORT
Potentially supports the claim but contains unresolved uncertainty.

Rules:

1. A source mention alone does not establish a claim.

2. Multiple weak sources must not automatically become one strong claim.

3. Contradictory evidence must remain visible.

4. Contextual evidence must not be counted as direct support.

5. A production decision cannot be used as evidence for the claim that created it.

6. AI-generated output cannot be used as independent evidence.

7. Every approved claim must have a traceable evidence relationship
   unless explicitly classified as a project production choice.

8. A claim with only indirect or uncertain support cannot silently
   receive the same status as directly established information.
