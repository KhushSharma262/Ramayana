# ANIMAL CANON CONNECTION

## PURPOSE

Connect animal-specific information to the project's central CANON system without duplicating the complete canonical database.

## OWNERSHIP

GLOBAL CANON owns:

- source hierarchy
- canonical source records
- source versions
- canonical textual database
- global source authority

ANIMAL_TRUTH owns:

- animal-specific extraction
- animal-specific relevance
- animal identification implications
- animal-specific canon status

## REQUIRED CONNECTION

Every canon-derived animal should be traceable to:

canon_record_id
source_name
source_type
source_section
source_reference
source_language
source_term
source_context
evidence_summary
animal_relevance
canon_status

## SOURCE CHAIN

CANON SOURCE
→ SOURCE PASSAGE
→ ANIMAL-SPECIFIC EVIDENCE
→ INTERPRETATION
→ IDENTIFICATION
→ DECISION

## IMPORTANT RULE

Do not copy an entire canonical source into this folder.

Store only the information necessary to establish animal identity.

## EVIDENCE VS INTERPRETATION

Example structure:

SOURCE:
The text uses a particular term.

EVIDENCE:
The term occurs in a specific context.

INTERPRETATION:
The term may correspond to candidate species.

DECISION:
Candidate A selected with MEDIUM confidence.

These must never be collapsed into one sentence presented as absolute fact.

## MULTIPLE SOURCES

When multiple canonical/traditional sources provide different information:

- preserve each source
- identify source authority
- identify differences
- document resolution
- preserve unresolved conflict if necessary

## DOWNSTREAM RULE

Only approved or explicitly qualified animal identity information may be passed to downstream systems.
