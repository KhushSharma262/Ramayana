# TRANSLATION VERSION CONTROL

Translation is an interpretive layer and must remain traceable.

Every translated animal reference should identify:

translation_id:
source_id:
source_mention_id:
original_language:
original_term:
original_text:
translator:
translation:
translation_date:
edition:
publisher_or_source:
translation_method:
translation_notes:
alternative_translations:
translation_uncertainty:
review_status:
version:

Rules:

1. Original wording must be preserved whenever available.

2. Translation must never replace the original textual evidence.

3. Alternative translations must remain recoverable.

4. A claim based on a translation must identify the translation version.

5. If translation differences materially affect species identification,
   the identification must remain uncertain until resolved.

6. A production translation cannot silently become canon.

7. Correcting a translation must create a new record/version rather than
   destroying the earlier translation history.
