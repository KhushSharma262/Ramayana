# TRUTH REOPEN RULES

A FROZEN record may be reopened only for:

1. New authoritative evidence
2. Demonstrated research error
3. Source correction
4. Translation correction
5. Taxonomic correction
6. Entity merge/split
7. Newly discovered contradiction
8. Material production-impacting error

Required:

reopen_id:
record_id:
current_version:
reason:
new_evidence_ids:
affected_claims:
affected_decisions:
affected_entities:
affected_handoffs:
affected_assets:
requested_by:
reviewed_by:
approved_by:
reopen_date:
new_version:

Reopening does not itself approve a new conclusion.

The workflow becomes:

FROZEN
→ REOPENED
→ RESEARCH/REVIEW
→ DECISION
→ APPROVAL
→ NEW VERSION
→ NEW FREEZE
