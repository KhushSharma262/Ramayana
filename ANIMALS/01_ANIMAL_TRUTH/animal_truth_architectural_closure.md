============================================================
FIVE-LAYER TRUTH SEPARATION
============================================================

1. WHAT THE SOURCE SAYS

2. WHAT THE EVIDENCE ESTABLISHES

3. WHAT WE INTERPRET

4. WHAT THE PROJECT DECIDES

5. WHAT PRODUCTION DEPICTS

These layers must never be silently collapsed.

============================================================
TRUTH STATUS
============================================================

UNKNOWN
Information has not been established.

NOT_STATED
The examined source does not state the proposition.

UNCERTAIN
Multiple possibilities remain.

KNOWN
Adequately established for the relevant scope.

APPROVED
Project-approved for downstream use.

REJECTED
Determined not to be accepted.

SUPERSEDED
Previously valid project state replaced by a newer one.

============================================================
IDENTITY RULE
============================================================

ENTITY ≠ RECORD

An entity is the represented animal/species/group.

A record is a versioned description of that entity.

============================================================
TAXONOMY RULE
============================================================

HISTORICAL TERM ≠ MODERN SPECIES

unless evidence establishes the mapping.

============================================================
UNCERTAINTY RULE
============================================================

Uncertainty is multidimensional.

SOURCE confidence
does not equal
IDENTIFICATION confidence
does not equal
BIOLOGICAL confidence
does not equal
PRODUCTION confidence.

============================================================
NEGATIVE EVIDENCE RULE
============================================================

NOT_FOUND ≠ NOT_MENTIONED ≠ EXPLICITLY_DENIED ≠ CONTRADICTED

============================================================
AI RULE
============================================================

AI-generated text, images, video, prompts, or model outputs are not
independent evidence.

They may assist:

- visualization
- hypothesis generation
- production
- reference exploration

but cannot silently become:

- canon
- historical fact
- zoological fact
- evidence

============================================================
DOWNSTREAM RULE
============================================================

ANIMAL_TRUTH owns animal truth.

Other systems implement it.

Other systems cannot silently rewrite it.

============================================================
FREEZE RULE
============================================================

No record is considered production-authoritative merely because it exists.

It requires:

RESEARCH
→ REVIEW
→ APPROVAL
→ HANDOFF
→ ACKNOWLEDGEMENT

Frozen records can be reopened only through the documented lifecycle.

============================================================
NO-INVENTION RULE
============================================================

When evidence is insufficient:

UNKNOWN is preferred over invention.

When sources conflict:

CONFLICT remains visible until resolved.

When several identifications remain plausible:

ALTERNATIVES remain visible.

When production requires a choice despite uncertainty:

the choice is explicitly marked as reconstruction/directorial/production
decision and is never represented as established canon.

============================================================
SCOPE BOUNDARY
============================================================

01_ANIMAL_TRUTH covers:

- real wild animals
- real domestic animals
- real trained animals
- real working animals
- real historically plausible animal populations
- important individual real animals

It does NOT own:

- divine animal beings
- mythological creatures
- supernatural creatures
- extraordinary non-natural entities

Those belong to separate project mechanisms.

============================================================
FINAL ARCHITECTURAL RULE
============================================================

If a new requirement can be satisfied by an existing record, field,
relationship, status, or downstream handoff, do NOT create another
parallel truth system.

New structure should be created only when it represents a genuinely
different concept.

This prevents architecture inflation and duplicate sources of truth.

============================================================
FINAL AUTHORITY
============================================================

The project's approved authority determines final production truth.

Where no authoritative answer exists, the system must preserve the
uncertainty rather than manufacture certainty.
