# IDENTITY REOPEN

An approved identity may be reopened only when:

- new authoritative evidence appears
- an earlier interpretation is demonstrated to be incorrect
- a source translation is corrected
- taxonomic classification materially changes
- entity merge/split becomes necessary
- a documented project error is discovered

Required:

reopen_id:
entity_id:
previous_lock:
reason:
new_evidence:
affected_claims:
affected_decisions:
affected_assets:
requested_by:
reviewed_by:
approval_status:
reopen_date:
new_version:

Reopening does not automatically approve the replacement identity.
