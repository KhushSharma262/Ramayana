# EVIDENCE REGISTRY

Purpose:
Register evidence used to support animal-related claims.

Core rule:
Evidence is not automatically a fact, claim, interpretation, or decision.

Required chain:

SOURCE
→ SOURCE MENTION
→ EVIDENCE
→ CLAIM
→ INTERPRETATION
→ DECISION

Each evidence record should contain:

evidence_id:
source_id:
source_mention_id:
evidence_type:
evidence_text_or_observation:
evidence_location:
language:
translation_status:
directness:
context:
world_time:
knowledge_time:
researcher:
research_status:
reliability:
limitations:
supports_claim_ids:
contradicts_claim_ids:
related_entity_ids:
approval_status:
version:
supersedes:
superseded_by:

Allowed evidence types may include:

- direct_textual_evidence
- translated_textual_evidence
- manuscript_evidence
- commentary_evidence
- archaeological_evidence
- historical_evidence
- zoological_evidence
- biological_evidence
- ecological_evidence
- iconographic_evidence
- linguistic_evidence
- geographic_evidence
- comparative_evidence
- negative_evidence
- researcher_observation
- expert_assessment

AI-generated output is not evidence merely because it appears plausible.

A generated image, generated video, generated description, or model response may be a production reference or hypothesis, but cannot independently establish canon or zoological truth.
