# COSTUME STATE VECTOR

Identity:
who owns or wears the costume.

Configuration:
which approved items are currently present.

Layering:
physical order of garments and accessories.

Condition:
clean, worn, dirty, wet, damaged, repaired, etc.

Context:
formal, domestic, travel, ritual, military, agricultural,
ceremonial, sleeping, bathing, combat, work, etc.

Environment:
weather, water, mud, dust, heat, cold, fire, terrain.

Temporal:
timeline position and historical state.

Continuity:
previous state, current state, next valid transition.

Every state change requires a traceable cause.
