# NON-GOALS

Cinematic Integration does not:

- invent animal behavior
- invent species
- redefine anatomy
- redefine ecology
- redefine identity
- redefine continuity
- invent historical facts
- use camera to conceal factual errors
- use editing to repair contradictory world state
- use sound to imply unsupported behavior
- use color to redefine physical reality
- use AI output as evidence

If an upstream state is wrong or unresolved:
BLOCK.
