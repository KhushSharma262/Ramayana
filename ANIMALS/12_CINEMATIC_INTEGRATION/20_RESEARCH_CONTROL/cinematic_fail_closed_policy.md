# CINEMATIC FAIL CLOSED POLICY

BLOCK when:

- required upstream snapshot is missing
- upstream snapshot is stale/revoked
- scene state is contradictory
- shot causality is unresolved
- identity is unresolved
- animal behavior is unsupported
- ecological source is unsupported
- camera requires impossible physical state
- audio contradicts action
- editing creates false causality
- historical state is contaminated
- AI output cannot be reconciled
- provenance is incomplete

When truth is unknown:
DO NOT INVENT IT.
