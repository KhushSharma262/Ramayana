# EPISODE INTEGRATION DEFINITION

Episode Integration controls:

- episode identity
- episode version
- episode timeline
- scene ordering
- scene dependencies
- entity presence
- recurring animal identity
- population continuity
- ecological continuity
- behavior continuity
- movement continuity
- interaction continuity
- visual continuity
- audio continuity
- costume/equipment continuity
- battle/high-stress continuity
- cinematic integration
- production handoff integration
- QA integration
- cross-scene consistency
- episode-level blocking
- episode snapshot
- episode freeze
- reshoot/rework integration

Episode Integration assembles approved states.

It does not create biological, canonical, ecological, behavioral,
historical, continuity, or QA truth.
