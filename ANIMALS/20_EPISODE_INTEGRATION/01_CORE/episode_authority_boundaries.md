# EPISODE AUTHORITY BOUNDARIES

DOMAIN SYSTEMS OWN DOMAIN TRUTH.

REGISTRY OWNS CONNECTIONS.

CONTINUITY OWNS PERSISTENT STATE.

PRODUCTION HANDOFF OWNS CONTROLLED PRODUCTION TRANSFER.

QA OWNS VERIFICATION AND APPROVAL.

EPISODE INTEGRATION OWNS:
- episode-level assembly
- ordering
- cross-scene dependency
- episode state composition
- episode-level integration checks
- episode freeze
- episode-level lineage

EPISODE INTEGRATION DOES NOT:
- redefine domain truth
- resolve scientific conflicts
- resolve canonical conflicts
- invent missing identity
- override continuity
- override QA
- override production handoff
- convert unknown into known
- convert conflict into resolution
