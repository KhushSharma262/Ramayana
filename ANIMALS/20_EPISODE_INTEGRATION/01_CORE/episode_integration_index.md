# EPISODE INTEGRATION SYSTEM

20_EPISODE_INTEGRATION assembles approved animal-world states into
a complete episode.

It is an INTEGRATION layer.

It is NOT a new source of truth.

Core chain:

APPROVED DOMAIN SNAPSHOTS
-> REGISTRY CONNECTIONS
-> EPISODE STATE
-> SCENE ORDER
-> CROSS-SCENE STATE
-> PRODUCTION HANDOFFS
-> QA
-> EPISODE OUTPUT

Episode Integration determines how approved records coexist across
the episode.

It does not rewrite the authoritative domain systems.
