# AI PRODUCTION DEFINITION

AI Production includes:

- prompt construction
- reference selection
- model selection
- generation configuration
- image/video generation
- animation implementation
- editing
- compositing
- upscaling
- restoration
- inpainting/outpainting
- asset versioning
- regeneration
- validation
- final-shot acceptance

AI output is an implementation artifact.

AI output is NEVER biological evidence, canonical evidence, or authority.

A visually convincing generation remains invalid if it conflicts with
approved animal truth.
