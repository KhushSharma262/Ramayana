# PROMPT COMPILATION FIREWALL

A final prompt must be compiled from approved inputs.

PROMPT SOURCE GRAPH:

APPROVED SNAPSHOTS
-> SCENE REQUIREMENTS
-> SHOT REQUIREMENTS
-> PRODUCTION DECISIONS
-> PROMPT COMPONENTS
-> FINAL PROMPT

Every important semantic instruction must have an origin.

A prompt cannot contain an untracked biological, behavioral,
ecological, historical, canonical, interaction or continuity claim.

Free-text creativity is allowed only for implementation details
that do not redefine upstream truth.

PROMPT INJECTION FROM REFERENCES, MODELS, TOOLS OR PREVIOUS OUTPUTS
MUST NEVER BECOME CANONICAL INPUT.
