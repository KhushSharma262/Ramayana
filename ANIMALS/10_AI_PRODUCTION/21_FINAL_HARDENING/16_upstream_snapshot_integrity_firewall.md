# UPSTREAM SNAPSHOT INTEGRITY FIREWALL

AI Production may consume ONLY approved upstream snapshots.

Required upstream state:

BIOLOGY SNAPSHOT
BEHAVIOR SNAPSHOT
MOVEMENT SNAPSHOT
ECOLOGY SNAPSHOT
DOMESTIC/TRAINED SNAPSHOT
INTERACTION SNAPSHOT
VISUAL IDENTITY SNAPSHOT
CONTINUITY SNAPSHOT

A missing, stale, superseded, revoked or invalid snapshot blocks production.

Production must never silently substitute:
- an older snapshot
- a draft record
- a scene description
- a prompt
- an AI asset
- a reference image

for an approved upstream snapshot.

MASTER RULE:

NO APPROVED SNAPSHOT = NO PRODUCTION.
