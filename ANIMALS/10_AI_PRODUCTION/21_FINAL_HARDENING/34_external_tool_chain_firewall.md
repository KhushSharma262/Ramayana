# EXTERNAL TOOL CHAIN FIREWALL

Every external AI or post-production tool is part of the production chain.

For each tool where relevant record:

tool_id
provider
tool_version
operation
input_asset
output_asset
configuration
timestamp

Changing tools creates a new derived asset lineage.

Unknown tool processing on a final asset = BLOCKED.

No hidden enhancement, upscaling, interpolation or restoration step
may exist outside the recorded production chain.
