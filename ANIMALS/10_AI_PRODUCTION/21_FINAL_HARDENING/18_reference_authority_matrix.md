# REFERENCE AUTHORITY MATRIX

Reference types have different authority.

CANONICAL SOURCE:
evidence for approved canonical interpretation.

BIOLOGICAL SOURCE:
evidence for biological reconstruction.

HISTORICAL SOURCE:
evidence for historical reconstruction.

ECOLOGICAL SOURCE:
evidence for ecological reconstruction.

VISUAL IDENTITY REFERENCE:
implementation reference for approved appearance.

AI-GENERATED REFERENCE:
implementation aid only.

MODEL-GENERATED REFERENCE:
implementation aid only.

No reference may silently outrank an approved domain snapshot.

If reference and approved state conflict:

APPROVED STATE WINS.
REFERENCE IS REJECTED OR RECLASSIFIED.

REFERENCE != TRUTH.
