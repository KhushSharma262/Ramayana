# VALIDATION INDEPENDENCE FIREWALL

Generation and validation are conceptually separate stages.

The generator cannot declare its own output biologically correct.

Validation must compare the output against approved state.

Required comparison:

EXPECTED STATE
vs
GENERATED STATE

The following do not constitute validation by themselves:

- model confidence
- prompt quality
- visual attractiveness
- human intuition
- similarity to a reference
- successful rendering
- absence of obvious artifacts

A valid render is not automatically a valid animal.
