# REFERENCE SET POLICY

References are implementation aids.

Reference categories:

- canonical textual reference
- biological reference
- historical reference
- ecological reference
- visual identity reference
- continuity reference
- technical production reference
- AI-generated reference

AI-generated references cannot establish truth.

Every production reference set must have:
reference_set_id
version
purpose
source_type
source_provenance
approval_status
applicability
expiration_or_supersession state
