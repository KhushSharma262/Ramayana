# VOCALIZATION CAUSALITY FIREWALL

Every animal vocalization must have a causal explanation.

Required chain:

ANIMAL STATE
→ BEHAVIORAL STATE
→ COMMUNICATION / PHYSIOLOGICAL PURPOSE
→ VOCALIZATION TYPE
→ AUDIO REPRESENTATION

The presence of an animal is not sufficient cause.

The following are prohibited without approved causal justification:

- random calls
- dramatic roars
- automatic growls
- automatic screams
- automatic neighing
- automatic barking
- automatic trumpeting
- automatic bird calls
- automatic snake hissing
- repeated calls added for atmosphere

If no credible cause exists:
USE SILENCE OR NONVOCAL AUDIO.
