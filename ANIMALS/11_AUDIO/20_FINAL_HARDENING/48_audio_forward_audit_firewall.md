# AUDIO FORWARD AUDIT FIREWALL

Every approved audio requirement must be traceable forward:

SOURCE
→ CLAIM
→ DECISION
→ SNAPSHOT
→ SCENE
→ SHOT
→ AUDIO REQUIREMENT
→ PROMPT
→ GENERATION/RECORDING
→ ASSET
→ VALIDATION
→ APPROVAL
→ FINAL MIX
→ FINAL SHOT

Unimplemented approved requirements must be identified.
