# AUDIO PROMPT COMPILATION FIREWALL

The final audio prompt must be compiled only from:

- approved domain snapshots
- approved continuity snapshot
- scene state
- shot requirements
- approved audio decisions

The prompt must not introduce unsupported:

- species
- vocalization
- behavioral meaning
- environmental source
- historical sound
- supernatural property

Prompt text is not evidence.

If prompt content conflicts with approved state:
BLOCK.
