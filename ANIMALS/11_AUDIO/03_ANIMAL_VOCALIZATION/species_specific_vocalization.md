# SPECIES-SPECIFIC VOCALIZATION

Vocalization rules must be species-specific whenever taxonomy is resolved.

Consider:

- species
- sex
- age
- reproductive state
- social structure
- territoriality
- alarm state
- distress
- aggression
- submission
- contact calling
- parental behavior
- mating
- feeding
- isolation
- group density
- time of day
- season
- habitat

Generic sound libraries cannot override approved species/context rules.
