# AUDIO DATABASE

The database uses species-level and context-level rules with controlled individual variation.

No file is created for every animal.

Broad unresolved categories remain unresolved until taxonomy is established.

Each sound record must support:

- sound_id
- species_or_group
- taxonomic_resolution
- sex
- age/life_stage
- individual_or_population
- behavioral_state
- acoustic_function
- context
- season
- habitat
- distance
- source_type
- evidence
- confidence
- interpretation
- approval_state
- snapshot_id
