# DOMESTIC TYPE / BREED SEPARATION

BIOLOGY owns species biology.

06_DOMESTIC_TRAINED owns:

- domestic type
- breed
- working type
- training
- human selection
- husbandry
- riding
- load carrying
- trained behaviour.

Example:

SPECIES:
Equus caballus

DOMESTIC TYPE:
UNKNOWN / APPROVED TYPE

BREED:
UNKNOWN unless explicitly established

INDIVIDUAL:
HORSE-XXXX

Never write:

"horse = Arabian horse"

unless the individual has been explicitly approved as that breed.

Never write:

"dog = German Shepherd"

unless the production individual is explicitly identified as such.

Modern breed characteristics must not be treated as universal species
biology.
