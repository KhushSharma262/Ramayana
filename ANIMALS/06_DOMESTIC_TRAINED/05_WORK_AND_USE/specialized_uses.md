# SPECIALIZED ANIMAL USE

## CATEGORIES

- royal
- agricultural
- transport
- ceremonial
- military
- hunting
- messenger
- household
- religious
- companion
- guarding
- pastoral

## HISTORICAL CONTROL

Each specialized use must have evidence appropriate to the selected
Ramayana/canonical/historical reconstruction.

Modern practice cannot automatically become ancient practice.

## CULTURAL CONTROL

Cultural meaning and biological fact remain separate fields.
