# BEHAVIOR HANDOFF

## DOMESTIC_TRAINED PROVIDES

- training history
- learned cues
- handler relationship
- work role
- domestication status
- management context
- stress context caused by human use

## BEHAVIOR PROVIDES

- actual behavioral response
- social behavior
- fear response
- communication
- behavioral manifestation

## HARD RULE

Domestic/Trained does not prescribe impossible or biologically unsupported
behavior simply because an animal is trained.
