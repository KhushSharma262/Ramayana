# MOVEMENT HANDOFF

## DOMESTIC_TRAINED PROVIDES

- riding context
- draft context
- pack context
- work role
- equipment
- load context
- handler interaction
- training state

## MOVEMENT PROVIDES

- physical execution
- biomechanics
- gait
- balance
- acceleration
- load mechanics
- equipment interaction

## HARD RULE

DOMESTIC_TRAINED specifies why/how the animal is being used.

MOVEMENT determines whether the physical execution is possible and how it occurs.
