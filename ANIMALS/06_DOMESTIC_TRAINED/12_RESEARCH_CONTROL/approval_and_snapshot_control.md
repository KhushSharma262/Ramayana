# APPROVAL AND SNAPSHOT CONTROL

## LIFECYCLE

DRAFT
→ RESEARCHING
→ EVIDENCE_COLLECTED
→ INTERPRETED
→ REVIEW_REQUIRED
→ APPROVED
→ SNAPSHOTTED
→ PRODUCTION

Failure state:

BLOCKED

## SNAPSHOT

Every production state references an immutable snapshot.

Example:

DT-SNP-000001

## RULE

Production never directly consumes mutable research.
