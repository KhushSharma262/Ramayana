# DEPENDENCY INVALIDATION

## RULE

If an upstream fact changes, all dependent domestic/training claims must be
reviewed.

Example:

historical species identity
→ domestic status
→ equipment compatibility
→ training practice
→ work role
→ scene
→ asset

## STATUS

CURRENT
STALE
REVIEW_REQUIRED
INVALID
BLOCKED

## HARD RULE

A stale parent cannot support an approved child claim.
