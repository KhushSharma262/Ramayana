# UPSTREAM DEPENDENCY MANIFEST

Mandatory upstream systems may include:

15_RESEARCH
16_CONFLICTS_UNKNOWN
BIOLOGY
BEHAVIOR
MOVEMENT
ECOLOGY
DOMESTIC/TRAINED
INTERACTION
VISUAL IDENTITY
CONTINUITY
AUDIO
BATTLE/HIGH-STRESS
COSTUME
CINEMATIC INTEGRATION
AI PRODUCTION

Only dependencies actually applicable to the scene are required.

Applicability itself must be explicit.

A dependency cannot be omitted merely because it is inconvenient.

A genuinely non-applicable dependency must have a recorded reason.
