# NON-GOALS

Production Handoff does NOT:

- invent missing facts
- resolve scientific conflicts
- resolve canonical conflicts
- resolve taxonomy without authority
- rewrite approved snapshots
- change animal behavior for cinematic convenience
- change anatomy for AI generation
- create new species interpretations
- convert unknown into assumed
- convert absence of evidence into absence
- use AI output as evidence
- treat prompts as canonical truth
- approve its own downstream output
- silently repair contradictory upstream state
- bypass validation
- bypass continuity
- bypass research controls
- replace upstream domain ownership
- erase rejected assets
- erase superseded versions
- silently replace identities

If a required truth is missing, the handoff is incomplete or blocked.
