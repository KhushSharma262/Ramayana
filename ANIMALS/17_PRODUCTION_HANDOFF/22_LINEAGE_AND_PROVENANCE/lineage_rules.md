# LINEAGE AND PROVENANCE

Every production artifact must be traceable backward to its originating handoff.

Required reverse chain:

FINAL OUTPUT
→ ASSET
→ GENERATION / SOURCE
→ SHOT HANDOFF
→ SCENE HANDOFF
→ CONTINUITY SNAPSHOT
→ DOMAIN SNAPSHOTS
→ RESEARCH / EVIDENCE / CLAIMS

Every upstream approved input must be traceable forward to the assets and shots that consume it.

No orphaned production artifact is valid.
