## CONTINUITY

The same tracked animal must retain:

- previous experience
- learned associations
- current stress
- current fatigue
- recent interactions
- injury
- social relationship
- training history
- location familiarity

## STATE TRANSITION

SHOT N
→ EVENT
→ STATE CHANGE

SHOT N+1
→ STATE PERSISTS OR RECOVERS

SHOT N+2
→ NEW EVENT MODIFIES STATE

## AI PROBLEM TO PREVENT

Do not allow the same individual to become:

calm
→ terrified
→ calm
→ aggressive
→ playful

between consecutive shots without a causal event.

## BACKGROUND POPULATION

Background animals do not need individual IDs.

Instead vary:

position
orientation
activity
spacing
attention
age
sex where visible
behavioral timing

Avoid synchronized group behavior unless the species naturally coordinates it.
