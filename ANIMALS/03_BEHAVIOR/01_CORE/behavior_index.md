version: BEHAVIOR-LEAN-01

## PURPOSE

This system defines realistic animal behavior for the Ramayana production.

Behavior must be treated as species-specific biological behavior rather than
human acting assigned to an animal.

The system exists to make animal behavior:

- biologically plausible
- species-specific
- context-dependent
- continuous across shots
- consistent with age and sex
- consistent with health and energy
- consistent with environment
- consistent with previous experience
- consistent with domestication/training where applicable
- consistent with the animal's senses
- consistent with realistic animal limitations

## CORE BEHAVIOR CHAIN

ENVIRONMENT
→ PERCEPTION
→ INTERNAL STATE
→ MOTIVATION / NEED
→ DECISION
→ BEHAVIOR
→ MOVEMENT
→ INTERACTION
→ CONSEQUENCE
→ RECOVERY

## BEHAVIOR IS NOT ANIMATION

Behavior defines what the animal is trying to do.

MOVEMENT defines how the body physically performs it.

AI_PRODUCTION defines how that behavior is generated.

## BEHAVIOR IS NOT HUMAN EMOTION

Avoid assigning human emotional narratives unless directly justified.

Prefer:

fear response
startle
vigilance
avoidance
resource defense
social attraction
maternal response
territorial response
curiosity
exploration
fatigue
stress
pain response

over:

sad
happy
jealous
guilty
proud
angry for no reason

## PRIORITY

1. Canon where applicable
2. Zoological evidence
3. Species-specific behavioral research
4. Individual biological state
5. Environment
6. Historical/cultural context
7. Directorial reconstruction
8. Production requirements

Production convenience must never silently override biological constraints.

## OWNERSHIP

BIOLOGY:
What the animal physically is and can biologically do.

BEHAVIOR:
What the animal does, under what conditions, and why.

MOVEMENT:
Physical movement execution and reusable movement assets.

ECOLOGY:
Ecological relationships and environmental systems.

DOMESTIC_TRAINED:
Training, domestication, working roles and learned human-associated behavior.

CONTINUITY:
Persistence of behavior across scenes and shots.

AI_PRODUCTION:
Generation implementation and artifact prevention.

## INDIVIDUAL RULE

Do not create an individual behavior file merely because an animal appears.

Create an individual record only when the animal is:

- named
- repeatedly tracked
- narratively important
- ridden
- trained
- closely interacting with a principal character
- behaviorally important to a scene
- required for continuity

Background animals use species/population-level behavior.
