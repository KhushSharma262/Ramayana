# BEHAVIOR CONTROL AND VALIDATION

## VALIDATION CHECKLIST

Every production-critical behavioral claim should answer:

[ ] Species identified
[ ] Taxonomy resolved
[ ] Behavioral context defined
[ ] Trigger defined
[ ] Biological state defined
[ ] Observable response defined
[ ] Species-specific evidence available
[ ] Age/life stage checked
[ ] Sex checked where relevant
[ ] Environment checked
[ ] Season checked where relevant
[ ] Human interaction checked where relevant
[ ] Individual state checked where relevant
[ ] Conflicts resolved
[ ] Uncertainty recorded
[ ] Downstream systems acknowledged
[ ] Continuity requirement defined

## BLOCKING CONDITIONS

Missing species identity
Missing critical evidence
Unresolved critical conflict
Unsupported anthropomorphism
Unsupported generalization
Wrong life stage
Wrong sex
Wrong environmental context
Contradiction with Biology
Contradiction with Ecology
Contradiction with Domestic/Training state
Continuity break

→ BLOCK

## FINAL RULE

A behavior that merely "looks good" is not automatically acceptable.

Biological plausibility comes first.
