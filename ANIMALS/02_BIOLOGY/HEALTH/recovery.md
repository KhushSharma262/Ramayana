# HEALTH RECOVERY

## Purpose

Defines biological recovery from illness, exertion and injury.

## Status

ACTIVE

## Biological Scope

This file belongs to the ANIMALS → BIOLOGY system.

It defines animal biological truth and production constraints.

The baseline is modern real-world zoology unless another project-level decision explicitly changes the scope.

## Content

Recovery depends on:

- species
- age
- injury
- disease
- nutrition
- hydration
- rest
- environmental conditions
- severity.

Recovery can be:

partial
complete
slow
complicated
incomplete
permanent.

Recovery must not be instantaneous unless the biological event is genuinely minor.

The visual condition of the animal must reflect the recovery state.

Healing wounds, gait changes and body condition must remain continuous.

4. Sex differences must only be used where biologically supported.

6. Natural variation must be preserved.

8. Unknown information must remain UNKNOWN.
