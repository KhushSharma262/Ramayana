# BIOLOGY MASTER CONTRACT

## Purpose

Defines the non-negotiable biological rules for the entire ANIMALS subsystem.

## Status

ACTIVE

## Scope

This file defines biological truth and production constraints for the Ramayana animal system.

The biological baseline is current real-world zoology unless a separate project decision explicitly establishes another scope.

## Core Rule

Biological facts must never be invented merely to make a shot easier to generate.

Where reliable evidence is unavailable, the record must state:

- UNKNOWN
- UNCERTAIN
- SPECIES-DEPENDENT
- INDIVIDUAL-DEPENDENT
- SOURCE-CONFLICT
- DIRECTORIAL CHOICE

as appropriate.

## Content

# 1. REAL ANIMAL FIRST

Every real animal must behave within the capabilities of its species.

# 2. SPECIES IS NOT ENOUGH

Species identity does not fully determine an individual.

The system must allow variation in:

- body size
- body proportions
- coat/plumage
- scars
- body condition
- age
- sex
- health
- temperament-related behavioral tendencies
- energy state
- environmental exposure

# 3. BIOLOGY PRECEDES PERFORMANCE

The desired shot cannot force biologically impossible performance.

If a requested action conflicts with biology, the action must be:

REJECTED
or
RECONSTRUCTED
or
EXPLICITLY LABELLED AS NON-REALISTIC.

# 4. CONTINUOUS STATE

An animal cannot instantly change:

- weight
- injury
- fatigue
- hunger
- hydration
- reproductive condition
- age
- coat/plumage
- physical development

between adjacent shots.

# 5. SPECIES-SPECIFICITY

Never use one generic "animal behavior" model.

Behavior depends on:

species + individual + state + environment + stimulus.

# 6. ANTHROPOMORPHISM CONTROL

Human interpretation may be used in direction, but internal animal states must be biologically meaningful.

Use:

fear response,
avoidance,
vigilance,
defensive aggression,
feeding motivation,
social contact,
territorial response,
maternal behavior,
curiosity,
habituation,

rather than unsupported human emotions.

# 7. UNCERTAINTY

Unknown information remains unknown.

The system must not manufacture precision.

# 8. PRODUCTION INTEGRITY

AI generation cannot change biological identity without an approved change.

# 9. RESEARCH INTEGRITY

A source must support the claim being made.

# 10. INDIVIDUAL OVERRIDE

Once an individual has an approved biological state, generic species information cannot silently overwrite it.

## Evidence Rule

Exact biological claims should be supported by reliable zoological, veterinary, ecological, anatomical, physiological or other scientific sources.

## Production Rule

This file provides biological constraints to downstream systems. It does not replace:

- ANIMAL_TRUTH
- BEHAVIOR
- MOVEMENT
- ECOLOGY
- DOMESTIC / TRAINED
- VISUAL IDENTITY
- CONTINUITY
- RIGGING
- 3D
- MATERIALS
- TEXTURE
- AUDIO
- CINEMATOGRAPHY
- LIGHTING
- EDITING
- RENDER

## Forbidden

Do not:

- invent biological facts
- anthropomorphize animals
- give every species identical behavior
- give every individual identical anatomy
- convert visual stereotypes into biological facts
- use cinematic convenience as biological evidence
- let a generic species profile overwrite an established individual state
- silently resolve contradictory research
- silently convert uncertainty into certainty

## Required Provenance

Every important biological claim should be traceable through:

SOURCE
→ EVIDENCE
→ CLAIM
→ INTERPRETATION
→ DECISION
→ ANIMAL ENTITY
→ INDIVIDUAL STATE
→ PRODUCTION USE

## Downstream Requirement

Any system using information from this file must preserve:

species identity,
individual identity where applicable,
age,
sex,
health,
physiological state,
environment,
and uncertainty.

## Final Authority

Project-level conflicts are resolved through the project's central control and approval systems.

ANIMALS owns animal-specific biological truth.
