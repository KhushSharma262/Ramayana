# BIOLOGY V3 MASTER CONTRACT

## Purpose

This contract defines the minimum conditions required for biological information
to be considered production-safe for the Ramayana animal system.

## Core Principle

A populated file is NOT equivalent to researched biology.

A species is production-approved only when:

SOURCE
→ EVIDENCE
→ CLAIM
→ APPLICABILITY
→ CONFIDENCE
→ SPECIES RECORD
→ CROSS-DOMAIN VALIDATION
→ DEPENDENCY VALIDATION
→ UNCERTAINTY VALIDATION
→ CONTINUITY VALIDATION
→ DOWNSTREAM ACKNOWLEDGEMENT
→ APPROVAL

## Forbidden shortcuts

The following never constitute scientific evidence:

- an existing filename
- a heading
- a template
- a placeholder
- a generic statement
- an AI-generated statement without source evidence
- an unsupported numerical value
- a common-name assumption
- an individual observation generalized to the species
- a weak source treated as universal truth
- UNKNOWN used to avoid research
- NOT_APPLICABLE without justification

## Status meanings

RESEARCH_REQUIRED
Research has not yet established a supported value.

RESEARCH_IN_PROGRESS
Research is actively being performed.

REVIEW_REQUIRED
Evidence exists but has not passed review.

APPROVED
Evidence, applicability, consistency and downstream requirements pass.

UNKNOWN
The value is genuinely not established or not recoverable.

NOT_APPLICABLE
The field does not biologically apply and must contain a reason.

CONFLICTED
Credible evidence conflicts and no final decision has been approved.

BLOCKED
The record cannot safely proceed to production.

## Scientific truth rule

If evidence is insufficient, preserve the uncertainty.

Never invent precision.

## Production rule

No species may be released merely because its record is structurally complete.

## Change rule

Any biological fact that changes must trigger validation of all dependent records.
