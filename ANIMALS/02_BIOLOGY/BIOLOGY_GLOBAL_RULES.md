# BIOLOGY GLOBAL RULES

## Biological State Model

Every tracked animal is represented as:

SPECIES
→ INDIVIDUAL
→ AGE
→ SEX
→ ANATOMY
→ HEALTH
→ ENERGY
→ HUNGER
→ THIRST
→ HYDRATION
→ FATIGUE
→ STRESS
→ SENSORY STATE
→ ENVIRONMENT
→ ACTIVITY
→ BEHAVIOR
→ MOVEMENT
→ INTERACTION
→ RECOVERY
→ CONTINUITY

## Realism Rule

The AI system must generate an animal that could physically exist.

## Scale Rule

Animal scale must remain locked.

## Anatomy Rule

Body structure must remain consistent with species.

## Movement Rule

Movement must originate from real anatomy and biomechanics.

## Behavior Rule

Behavior must emerge from:

species
+
individual
+
internal state
+
environment
+
stimulus.

## Imperfection Rule

Real animals are not perfectly synchronized machines.

Natural variation should remain visible where appropriate.

## AI Artifact Rule

Reject:

- duplicated limbs
- changing markings
- floating feet
- impossible joints
- disappearing tails
- changing body mass
- teleportation
- frame-to-frame identity changes
- impossible gait
- incorrect species morphology.

## Anthropomorphism Rule

Do not assign human intentions merely because the animal's action looks expressive.

## Population Rule

Background animals may vary in:

- size
- posture
- position
- coat/plumage
- age
- sex
- activity.

They must still remain within species limits.

## Individual Rule

Important animals receive individual biological records.

## Unknown Rule

Unknown information remains unknown.

## Source Rule

Biological precision requires evidence.

## Continuity Rule

No biological state may change without a reason.

## Production Rule

Technical limitations do not become biological facts.
