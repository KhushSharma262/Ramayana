# BIOLOGY INDEX

## Purpose

Master navigation and ownership map for animal biology.

## Status

ACTIVE

## Scope

This file defines biological truth and production constraints for the Ramayana animal system.

The biological baseline is current real-world zoology unless a separate project decision explicitly establishes another scope.

## Core Rule

Biological facts must never be invented merely to make a shot easier to generate.

Where reliable evidence is unavailable, the record must state:

- UNKNOWN
- UNCERTAIN
- SPECIES-DEPENDENT
- INDIVIDUAL-DEPENDENT
- SOURCE-CONFLICT
- DIRECTORIAL CHOICE

as appropriate.

## Content

BIOLOGY is the biological truth layer of the ANIMALS system.

It converts zoological knowledge into production-safe constraints.

### Biological chain

SPECIES

### Ownership

BIOLOGY owns:

- anatomy-related biological requirements
- physiology
- age
- sex
- health
- nutrition
- hydration
- fatigue
- rest
- sleep
- senses
- reproduction biology
- biological variation
- biological limits
- individual biological state

BIOLOGY does not own cinematic execution.

### Biological state

An animal is never treated as a static model.

The relevant state may include:

- species
- individual ID
- age
- sex
- body condition
- health
- injury
- pain
- hunger
- thirst
- hydration
- energy
- fatigue
- thermoregulatory state
- stress
- reproductive state
- sensory condition
- environmental exposure

### Required downstream behavior

Biological state must constrain behavior rather than behavior being selected first and biology retrofitted afterward.

## Evidence Rule

Exact biological claims should be supported by reliable zoological, veterinary, ecological, anatomical, physiological or other scientific sources.

## Production Rule

This file provides biological constraints to downstream systems. It does not replace:

- ANIMAL_TRUTH
- BEHAVIOR
- MOVEMENT
- ECOLOGY
- DOMESTIC / TRAINED
- VISUAL IDENTITY
- CONTINUITY
- RIGGING
- 3D
- MATERIALS
- TEXTURE
- AUDIO
- CINEMATOGRAPHY
- LIGHTING
- EDITING
- RENDER

## Forbidden

Do not:

- invent biological facts
- anthropomorphize animals
- give every species identical behavior
- give every individual identical anatomy
- convert visual stereotypes into biological facts
- use cinematic convenience as biological evidence
- let a generic species profile overwrite an established individual state
- silently resolve contradictory research
- silently convert uncertainty into certainty

## Required Provenance

Every important biological claim should be traceable through:

SOURCE
→ EVIDENCE
→ CLAIM
→ INTERPRETATION
→ DECISION
→ ANIMAL ENTITY
→ INDIVIDUAL STATE
→ PRODUCTION USE

## Downstream Requirement

Any system using information from this file must preserve:

species identity,
individual identity where applicable,
age,
sex,
health,
physiological state,
environment,
and uncertainty.

## Final Authority

Project-level conflicts are resolved through the project's central control and approval systems.

ANIMALS owns animal-specific biological truth.
