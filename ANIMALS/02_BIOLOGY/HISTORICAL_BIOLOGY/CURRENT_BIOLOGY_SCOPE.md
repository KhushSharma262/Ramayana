# CURRENT BIOLOGY SCOPE

APPROVED:

The project uses current real-world zoological biology as the
biological reference system.

This means:

USE:
- current taxonomy
- current anatomy
- current physiology
- current sensory science
- current veterinary knowledge
- current animal behaviour
- current reproductive biology
- current ecological biology where relevant.

DO NOT silently use:
- extinct species
- speculative ancestral species
- ancient physiological reconstruction
- ancient breed reconstruction
- unsupported historical zoology.

The story setting may be historical/mythological, but the biological
model remains modern unless a separate approved production decision
explicitly changes the representation.

Such a decision must never overwrite the current biological baseline.
