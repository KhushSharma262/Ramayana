# DOWNSTREAM ACKNOWLEDGEMENT CONTROL

A biological change may affect:

BEHAVIOR
MOVEMENT
ECOLOGY
DOMESTIC / TRAINED
INTERACTION
VISUAL IDENTITY
CONTINUITY
AI PRODUCTION
AUDIO
CINEMATIC INTEGRATION

Each affected downstream system must acknowledge the biological version.

Required acknowledgement fields:

biology_record_id:
biology_version:
affected_domain:
acknowledged_by:
acknowledged_date:
revalidated:
impact:
status:

Allowed:

ACKNOWLEDGED
REVALIDATION_REQUIRED
BLOCKED

## Rule

A changed biological fact with unresolved downstream impact cannot enter final
production.
