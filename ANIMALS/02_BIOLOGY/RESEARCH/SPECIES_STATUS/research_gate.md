# SPECIES RESEARCH GATE

## A species is scientifically complete only when:

ANATOMY = REVIEWED/APPROVED
AGE = REVIEWED/APPROVED
SEX = REVIEWED/APPROVED
PHYSIOLOGY = REVIEWED/APPROVED
HEALTH = REVIEWED/APPROVED
NUTRITION = REVIEWED/APPROVED
REST_AND_SLEEP = REVIEWED/APPROVED
SENSES = REVIEWED/APPROVED
REPRODUCTION = REVIEWED/APPROVED
NATURAL_VARIATION = REVIEWED/APPROVED
HISTORICAL_BIOLOGY = REVIEWED/APPROVED where historically relevant.

## EXCEPTION

A domain may be marked:

NOT_APPLICABLE

only when the domain genuinely does not apply to the species.

Example:

pregnancy is not applicable to an egg-laying species.

However:

RESEARCH_REQUIRED

is not the same as:

NOT_APPLICABLE.

## NO FALSE PASS

A species is not complete because:

- a file exists
- a template exists
- generic biology exists
- a source is listed without evidence
- a claim is plausible
- an AI model generated the information.

Evidence-backed research is required.
