# RESEARCH GAP REGISTRY

Every missing biological requirement must have an explicit gap.

Required fields:

gap_id:
species_id:
domain:
field:
reason:
priority:
required_evidence_type:
status:
blocking:

## Priority

P0 = production-blocking
P1 = important for visual/behavioral realism
P2 = useful refinement
P3 = optional

## Rule

A missing fact may not disappear merely because the corresponding file exists.
