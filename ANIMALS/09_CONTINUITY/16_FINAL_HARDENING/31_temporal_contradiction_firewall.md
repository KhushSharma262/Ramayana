# TEMPORAL CONTRADICTION FIREWALL

Continuity must detect impossible temporal sequences.

Examples:

DEATH
→ LATER ACTIVE EVENT

TRAINING COMPLETE
→ EARLIER UNTRAINED STATE

EQUIPMENT ACQUIRED
→ EARLIER USE WITHOUT PRIOR ACCESS

INJURY
→ EARLIER POST-INJURY EFFECT

LOCATION EXIT
→ EVENT AT LOCATION WITHOUT RETURN

A contradiction may only be permitted through:

- canonical temporal mechanism
- supernatural mechanism
- alternate timeline
- mistaken identity
- explicitly approved interpretation

Otherwise:

CONTRADICTION = BLOCKED.
