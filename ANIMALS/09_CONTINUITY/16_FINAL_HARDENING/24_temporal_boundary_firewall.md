# TEMPORAL BOUNDARY FIREWALL

Every state-changing event must belong to a defined temporal interval.

A scene has:

scene_start
scene_end
timeline_id
chronological_position

An event occurring between two scenes must not disappear merely because
it was not shown.

If a state differs between:

SCENE A END
and
SCENE B START

the difference requires:

EVENT
or
EXPLICIT APPROVED TRANSITION

Unexplained inter-scene change = BLOCKED.

Off-screen does not mean causeless.
