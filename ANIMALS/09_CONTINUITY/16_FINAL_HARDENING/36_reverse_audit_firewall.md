# REVERSE AUDIT FIREWALL

Every final shot must be traceable backwards:

SHOT
→ ASSET
→ PROMPT
→ SCENE
→ CONTINUITY SNAPSHOT
→ DOMAIN SNAPSHOTS
→ DECISION
→ CLAIM
→ SOURCE

The audit must terminate at valid evidence/authority.

If any mandatory link is missing:

FINAL SHOT = BLOCKED

Forward traceability alone is insufficient.

The system must support both:

FORWARD AUDIT
SOURCE → SHOT

and:

REVERSE AUDIT
SHOT → SOURCE
