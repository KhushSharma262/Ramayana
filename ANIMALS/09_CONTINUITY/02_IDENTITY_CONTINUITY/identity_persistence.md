# IDENTITY PERSISTENCE

Every persistent entity retains its immutable canonical identity.

Required:

entity_id
entity_type
identity_status
creation_snapshot_id
current_valid_snapshot_id

Identity cannot change merely because:

- appearance changes
- clothing changes
- equipment changes
- training changes
- location changes
- handler changes
- asset changes
- actor/model changes
- scene changes
- camera changes

Replacement creates a new identity.

Identity similarity does not establish identity continuity.

AI visual resemblance is never identity evidence.
