# CONTINUITY AUDIT

Audit every production-relevant chain:

SOURCE
→ CLAIM
→ DECISION
→ DOMAIN STATE
→ DOMAIN SNAPSHOT
→ CONTINUITY SNAPSHOT
→ TIMELINE
→ EVENT
→ SCENE
→ PROMPT
→ ASSET
→ SHOT

The audit must be reversible from final shot back to source.

If reverse tracing stops at any mandatory node:
PRODUCTION = BLOCKED.
