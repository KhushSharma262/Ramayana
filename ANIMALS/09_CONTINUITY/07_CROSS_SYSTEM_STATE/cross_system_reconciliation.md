# CROSS-SYSTEM RECONCILIATION

Continuity checks compatibility between domain states.

Examples:

Biology ↔ Movement:
physical feasibility

Biology ↔ Visual Identity:
morphological compatibility

Behavior ↔ Movement:
behavioral state vs physical manifestation

Ecology ↔ Behavior:
environmental plausibility

Domestic/Trained ↔ Movement:
training/equipment vs physical execution

Interaction ↔ Behavior:
event vs behavioral response

Interaction ↔ Movement:
event vs physical execution

Visual Identity ↔ Domestic/Trained:
approved equipment/grooming/costume representation

Conflicts are not resolved by majority vote.

The authoritative owner of the disputed claim must resolve it.

Unresolved conflict = BLOCKED.
