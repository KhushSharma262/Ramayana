# STATE TRANSITION FIREWALL

Valid transition:

CURRENT APPROVED STATE
→ EVENT
→ EVIDENCE / OBSERVATION
→ INTERPRETATION
→ DOMAIN DECISION
→ APPROVAL
→ NEW DOMAIN STATE
→ NEW CONTINUITY SNAPSHOT

Forbidden:

PROMPT
→ STATE

ASSET
→ STATE

SCENE DESCRIPTION
→ STATE

ACTOR PERFORMANCE
→ STATE

AI OUTPUT
→ STATE

UNEXPLAINED VISUAL DIFFERENCE
→ STATE

Any unsupported transition = BLOCKED.
