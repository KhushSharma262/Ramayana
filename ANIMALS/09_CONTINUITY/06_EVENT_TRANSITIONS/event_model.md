# EVENT MODEL

Every continuity-changing event requires:

event_id
event_type
initiator
participants
timeline_id
temporal_position
precondition_snapshot_id
cause
evidence
affected_domains
state_changes
consequence_records
approval_status
resulting_snapshot_id

Events may be:

OBSERVED
CANONICAL
HISTORICAL
INFERRED
PRODUCTION_APPROVED
SUPERNATURAL

The classification does not automatically establish truth.

Evidence and authority remain required.
