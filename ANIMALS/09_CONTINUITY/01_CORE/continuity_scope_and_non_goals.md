# CONTINUITY SCOPE AND NON-GOALS

Continuity exists to preserve approved truth over time.

It is NOT:

- a second Biology database
- a second Behavior database
- a second Movement database
- a second Ecology database
- a second Domestic/Trained database
- a second Interaction database
- a second Visual Identity database
- an AI prompt database
- a substitute for research
- a source of canonical facts
- a mechanism for silently fixing contradictions

No competing complete entity truth may be stored here.

Continuity stores references, snapshots, transitions, dependencies,
temporal context, and audit information.
