# STRESS PROMPT COMPILATION

Prompts must be compiled from approved state records.

A prompt must preserve:
- species
- anatomy
- natural behavior
- stress cause
- response
- movement limits
- injury
- fatigue
- environment
- historical context
- equipment
- continuity
- cinematic presentation

Prompt wording must not introduce unsupported behavior.

Prompt changes that alter the approved state require revalidation.
