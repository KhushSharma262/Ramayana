# REPLACEMENT / REGENERATION

Regeneration does not create a new animal identity.

A replacement asset must inherit:

- species
- individual identity
- visual identity
- stress state
- behavior state
- movement state
- injury state
- fatigue state
- equipment state
- continuity state

A new identity is created only through an approved identity transition.

Generation drift must never become a continuity change.

If regeneration changes an approved biological, behavioral, movement, injury, equipment, or continuity state, the asset is BLOCKED and must be revalidated.

Previous assets remain auditable.
