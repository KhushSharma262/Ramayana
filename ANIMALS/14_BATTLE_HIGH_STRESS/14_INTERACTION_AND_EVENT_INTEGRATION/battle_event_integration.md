# BATTLE EVENT INTEGRATION

Battle events must be decomposed into causal components:

ENVIRONMENT
-> THREAT / DISTURBANCE
-> ANIMAL EXPOSURE
-> STRESS STATE
-> BEHAVIORAL RESPONSE
-> PHYSICAL EXECUTION
-> INTERACTION OUTCOME
-> INJURY / FATIGUE IF APPLICABLE
-> RECOVERY

No downstream effect may exist without a traceable upstream cause.

A cinematic shot is not itself the cause of an animal response.
