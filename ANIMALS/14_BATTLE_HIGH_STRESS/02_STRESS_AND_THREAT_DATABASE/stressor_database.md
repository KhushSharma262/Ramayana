# STRESSOR DATABASE

Each stressor must record:

- identity
- source
- species applicability
- individual applicability
- onset
- duration
- intensity
- proximity
- sensory channel
- environmental modifiers
- social modifiers
- training modifiers
- physiological constraints
- evidence confidence

## Temporal Classes
ACUTE = sudden or short-duration exposure.
REPEATED = recurring exposure.
CUMULATIVE = multiple exposures whose effects persist across time.
CHRONIC = prolonged condition.

A dramatic event is not automatically a chronic or traumatic state.
