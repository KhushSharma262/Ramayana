# BATTLE / HIGH-STRESS SYSTEM

## Purpose
This system controls the representation of animals under extreme stress, battle exposure, threat, escape, injury, exhaustion and recovery.

## Master Principle
EXTREME STRESS CHANGES HOW AN ANIMAL RESPONDS; IT DOES NOT TURN THE ANIMAL INTO A HUMAN COMBATANT.

## Authority
Biology = physiological feasibility and physical limits.
Behavior = motivation and behavioral state.
Movement = biomechanical execution.
Ecology = environmental context.
Domestic/Trained = training, handling, work and equipment context.
Interaction = event identity and interaction consequences.
Continuity = persistence through time.
Audio = acoustic manifestation.
Costume Track = costume, tack and equipment state.
Cinematic Integration = presentation.
AI Production = representation only.

## Fail-Closed Rule
Unsupported stress behavior, impossible physical performance, unsupported battle participation, unexplained injury, unexplained recovery, or contradictory state is BLOCKED.

## Production Chain
SOURCE -> EVIDENCE -> CLAIM -> DECISION -> DOMAIN SNAPSHOTS -> STRESS STATE -> SCENE -> SHOT -> PROMPT -> ASSET -> VALIDATION -> APPROVAL
