# PREDATOR / PREY STRESS ESCALATION

Predator-prey stress is an interaction sequence.

Possible progression:
DETECTION
-> ORIENTATION
-> THREAT ASSESSMENT
-> APPROVED RESPONSE
-> PURSUIT / ESCAPE
-> CONTACT / DISENGAGEMENT
-> RECOVERY

Each transition requires a causal event.

Do not compress an extended biological sequence into impossible instantaneous behavior unless the source event itself is instantaneous.
