# VISUAL IDENTITY INDEX

Visual Identity defines the approved visual representation of a persistent entity.

It does not decide biological truth, behavior, movement, ecology, domestication, historical truth, or canonical truth.

It translates approved upstream truth into a controlled visual identity.

Master chain:

SOURCE
→ EVIDENCE
→ INTERPRETATION
→ APPROVED VISUAL DECISION
→ VISUAL IDENTITY
→ SNAPSHOT
→ SCENE
→ PROMPT
→ ASSET
→ SHOT
→ VALIDATION

AI output can never redefine canonical identity.
