# VISUAL IDENTITY DEFINITION

Visual Identity is the controlled system describing how an entity is visually represented across the production.

It includes:

- persistent physical appearance
- morphology as visually represented
- age appearance
- sex-linked visible traits
- skin, hair, fur, feathers, scales and surface traits
- facial structure
- body proportions
- scars and permanent marks
- temporary appearance states
- clothing and ornaments as rendered states
- culturally/historically supported markings
- canonical forms
- supernatural forms
- reference images
- continuity
- approved visual snapshots

Visual Identity is not a substitute for Biology, Behavior, Movement, Ecology, Domestic/Trained, Interaction or Canon research.
