# ANIMAL SEASONAL VISUAL CHANGE

Animal visual identity must support legitimate biological variation across time.

Examples:

molt
seasonal plumage
coat change
breeding condition
body-condition change
fat reserves
wet/dry coat
juvenile-to-adult transition
antler/horn state where applicable
pregnancy-related appearance

Ecology supplies seasonal context.
Biology supplies biological plausibility.
Visual Identity records the approved visual state.

Seasonal change is NOT identity drift when biologically valid.

It becomes identity drift only when it violates the approved species/individual state.
