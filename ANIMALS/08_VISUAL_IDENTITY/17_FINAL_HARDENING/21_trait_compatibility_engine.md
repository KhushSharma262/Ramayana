# TRAIT COMPATIBILITY ENGINE

All visual traits must be checked against one another.

Examples:

age ↔ body condition
age ↔ hair characteristics
life stage ↔ body proportions
sex ↔ supported dimorphism
injury ↔ scar
injury ↔ movement-visible consequences
pregnancy ↔ body state
pregnancy ↔ clothing fit
grooming ↔ hair state
weather ↔ surface condition
rain ↔ wetness
dust ↔ environmental context
animal season ↔ coat/plumage/molt state
equipment ↔ animal compatibility
costume ↔ historical period
ornament ↔ cultural/historical context
form ↔ supernatural state

Compatibility states:

COMPATIBLE
CONDITIONALLY_COMPATIBLE
CONFLICTED
UNKNOWN
BLOCKED

A set of individually valid traits may still be collectively invalid.

COLLECTIVE VISUAL STATE > INDIVIDUAL TRAIT VALIDITY.

If a contradiction cannot be resolved, the snapshot is BLOCKED.
