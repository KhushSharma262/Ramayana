# REPLACEMENT ASSET CONTINUITY

When an asset fails validation:

FAILED_ASSET
→ REJECTION_RECORD
→ SAME_APPROVED_SNAPSHOT
→ REGENERATION
→ NEW_ASSET_ID
→ NEW_ASSET_AUDIT

The replacement does not receive a new identity.

The failed asset cannot alter canonical state.

If a different appearance is desired, it requires an approved visual state transition.
