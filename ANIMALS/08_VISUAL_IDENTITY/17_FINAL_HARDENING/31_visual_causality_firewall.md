# VISUAL CAUSALITY FIREWALL

Every material visual state change requires a cause.

CAUSE
→ EVENT
→ EFFECT
→ VISUAL STATE
→ SNAPSHOT

Examples:

rain → wet clothing
dusty road → dust accumulation
fight → validated injury
haircut → shorter hair
aging → age-related appearance
molt → changed plumage
fire exposure → validated soot/damage

A generator cannot create a state merely because it looks cinematic.

No cause = UNKNOWN or BLOCKED.
