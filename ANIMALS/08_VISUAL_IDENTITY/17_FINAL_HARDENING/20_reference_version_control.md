# REFERENCE VERSION CONTROL

Every reference set is versioned.

Required:

reference_set_id
reference_version
reference_asset_id
source
provenance
purpose
date_added
valid_from
valid_until
status
approval
supersedes
superseded_by

Approved references are immutable.

Changing a reference image requires a new reference version.

A reference update does not automatically update Visual Identity.

It triggers dependency review.

REFERENCE IMAGE ≠ CANONICAL TRUTH.

References implement an approved decision; they do not create one.
