# CLAIM-LEVEL VISUAL PROVENANCE

Every meaningful visual trait is an independently traceable claim.

Examples:

SKIN_TONE
SKIN_UNDERTONE
FACE_SHAPE
EYE_SHAPE
HAIR_TEXTURE
HAIR_LENGTH
BODY_PROPORTION
SCAR
MARKING
CLOTHING
ORNAMENT
EQUIPMENT
AGE_APPEARANCE
BODY_CONDITION
COAT_PATTERN
PLUMAGE_PATTERN
FORM

Each claim requires:

visual_claim_id
entity_id
trait
value
source_id
evidence_id
evidence_class
interpretation
confidence
temporal_scope
geographic_scope
decision_id
approval_id
snapshot_id
version

A broad visual decision may not silently contain unsupported subclaims.

RULE:

ONE CLAIM → ONE TRACEABLE BASIS.

If a trait cannot be traced, it is UNKNOWN or BLOCKED.
