# VISUAL IDENTITY DATABASE

Canonical identity records use persistent IDs.

Required identity fields:

visual_identity_id
entity_id
entity_type
species_or_character_id
taxonomy_status
sex
life_stage
age_state
identity_status
canonical_form_id
appearance_state_id
reference_set_id
current_snapshot_id
continuity_status
approval_status
version

Broad or unresolved biological identities remain unresolved.

A generated image never becomes the identity record merely because it is visually convincing.
