# VISUAL STATE TRANSITION

Permanent or materially important appearance changes follow:

CURRENT SNAPSHOT
→ EVENT
→ EVIDENCE / OBSERVATION
→ INTERPRETATION
→ APPROVED CHANGE
→ NEW VISUAL STATE
→ NEW SNAPSHOT

Examples:

aging
injury scar
hair loss
pregnancy-related change
ritual marking
major grooming change
canonical transformation

Unapproved visual changes are BLOCKED.
