# INTERACTION CAUSALITY FIREWALL

Every consequential interaction must distinguish:

PRECONDITION
→ INTERACTION
→ IMMEDIATE EFFECT
→ DOWNSTREAM CONSEQUENCE

An interaction cannot be assigned as the cause of a state that existed before it.

## Required

causal_event_id
causal_parent_id where applicable
causal_order
precondition_snapshot
interaction_snapshot
consequence_reference

## Rules

Later evidence cannot retroactively become the cause of an earlier event without explicit canonical/historical justification.

Correlation is not automatically causation.

Narrative sequence is not automatically causal sequence.

Cinematic editing cannot change canonical causality.

If causal order is unresolved:
CAUSALITY = UNKNOWN
PRODUCTION = BLOCKED where causality matters.
