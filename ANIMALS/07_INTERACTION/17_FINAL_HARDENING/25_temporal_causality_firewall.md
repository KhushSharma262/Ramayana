# TEMPORAL CAUSALITY FIREWALL

Every consequential interaction must have a temporal relationship to:

previous state
interaction event
resulting state

Temporal layers must remain distinct:

MODERN
HISTORICAL
CANONICAL
INFERRED
PRODUCTION

No temporal layer may silently overwrite another.

Scene editing order does not define real event order.

Flashbacks, nonlinear scenes and parallel scenes require explicit event chronology.

Impossible ordering is BLOCKED.

A consequence cannot exist before its approved causal event unless independently established.
