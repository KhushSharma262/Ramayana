# RELATIONSHIP AUTHORITY MATRIX

Interaction owns:
- interaction event
- event participants
- event-level relationship consequence
- interaction history
- interaction-derived relationship transition

Behavior owns:
- behavioral state
- motivation
- trust/fear as behavioral states
- social response
- communication

Domestic/Trained owns:
- owner/handler/trainer/rider/herder/keeper relationships
- domestication/training relationships
- work relationships

Ecology owns:
- ecological relationships
- predator/prey ecological context
- competition for ecological resources
- mutualism/ecological association

## Rule

Interaction may record a relationship consequence, but the canonical field remains owned by the appropriate authority.

Interaction cannot convert:
interaction event → permanent behavioral state
interaction event → ownership
interaction event → domestication
interaction event → ecological relationship
without the owning system approving the transition.

## Conflict

If two systems disagree:
CLAIM OWNER → EVIDENCE → CONFLICT RESOLUTION → APPROVAL → SNAPSHOT

Unresolved authority conflict = BLOCKED.
