# ENVIRONMENT / OBJECT INTERACTION BOUNDARY

## Interaction owns

A discrete event between an animal and an object/environmental entity when the event itself matters.

Examples:
- animal pushes gate
- animal breaks tether
- animal drinks from vessel
- animal enters enclosure
- animal contacts cart
- animal avoids obstacle

## Movement owns

Physical execution:
- force
- balance
- gait
- contact mechanics
- acceleration
- load
- collision mechanics

## Ecology owns

Environmental existence and ecological context:
- habitat
- water availability
- terrain
- resources
- environmental distribution
- population/environment relationships

## Domestic/Trained owns

Equipment assignment and work context.

## Rule

Environment existing around an animal is not automatically an Interaction.

An animal touching something is not automatically a meaningful Interaction.

A meaningful event requires:
EVENT + PARTICIPANT + CONTEXT + CONSEQUENCE OR RELEVANT OUTCOME.

If ownership is ambiguous = BLOCKED.
