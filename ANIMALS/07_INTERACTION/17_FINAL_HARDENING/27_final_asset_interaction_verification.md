# FINAL ASSET INTERACTION VERIFICATION

Traceability alone is insufficient.

The final generated asset must be checked against the approved Interaction Snapshot.

Verify:

participants
participant identities
participant count
interaction type
relationship state where relevant
physical event
context
equipment
historical state
canonical state
supernatural state where applicable
consequences
continuity

Validation states:

MATCH
MINOR_ALLOWED_VARIATION
CONFLICT
UNVERIFIABLE
REJECTED

CONFLICT or UNVERIFIABLE = asset blocked/rejected when the disputed property is material.

The canonical interaction state is never changed merely to match the generated asset.

MASTER RULE:

THE AI ASSET MUST CONFORM TO THE APPROVED INTERACTION STATE.
THE APPROVED INTERACTION STATE MUST NEVER CONFORM TO THE AI ASSET.
