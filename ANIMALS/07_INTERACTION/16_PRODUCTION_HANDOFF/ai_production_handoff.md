# AI PRODUCTION HANDOFF

Production chain:

APPROVED INTERACTION SNAPSHOT
→ SCENE
→ PROMPT
→ ASSET
→ SHOT
→ AUDIT

AI cannot introduce unsupported:
participants
relationships
interaction types
historical practices
physical outcomes
species behavior
supernatural states

If generated output conflicts with the approved interaction state:
REJECT ASSET.

Never modify canonical truth to match an AI output.
