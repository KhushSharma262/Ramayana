# INTERACTION LIFECYCLE

PLANNED
→ INITIATED
→ ACTIVE
→ INTERRUPTED / COMPLETED
→ OUTCOME_RECORDED
→ APPROVED
→ SNAPSHOTTED
→ PRODUCTION

Alternative failure states:

REJECTED
BLOCKED
INVALIDATED
ROLLED_BACK

An interaction may fail to initiate.

An interaction may be interrupted.

An interaction does not require physical contact.

An interaction cannot be marked complete without a valid end condition where completion is applicable.
