# ANIMAL ↔ OBJECT

Included when the object interaction has meaningful physical, behavioral, domestic, historical, or continuity consequences.

Examples:
- animal ↔ tether
- animal ↔ gate
- animal ↔ cart
- animal ↔ plough
- animal ↔ harness
- animal ↔ enclosure
- animal ↔ water vessel
- animal ↔ transport equipment

Interaction owns the event.

Movement owns physical mechanics.

Domestic/Trained owns equipment assignment and work context.

Objects do not become biological entities.

A mere object appearing near an animal is not an interaction.
