# 07 INTERACTION

## Purpose

07_INTERACTION owns meaningful interaction events and accumulated interaction relationships involving animals.

It is the event/relationship layer connecting entities without replacing Biology, Behavior, Movement, Ecology, Domestic/Trained, Continuity, or AI Production.

## Master Principle

AN INTERACTION IS AN EVENT BETWEEN ENTITIES, NOT MERELY THEIR PROXIMITY.

## Core Rule

Every meaningful interaction must have identifiable participants, context, interaction state, evidence/decision status, and outcome or explicitly recorded non-outcome where applicable.

## Canonical Flow

SOURCE
→ EVIDENCE
→ INTERPRETATION
→ INTERACTION CLAIM
→ APPROVAL
→ INTERACTION STATE
→ SNAPSHOT
→ SCENE
→ PROMPT
→ ASSET
→ SHOT
