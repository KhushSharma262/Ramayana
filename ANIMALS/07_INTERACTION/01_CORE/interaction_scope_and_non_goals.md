# SCOPE AND NON-GOALS

## Included

Animal-involved interactions.

Examples:
- animal ↔ animal
- animal ↔ human
- animal ↔ group
- animal ↔ population
- animal ↔ predator/prey
- animal ↔ object when consequential
- animal ↔ environment when the event itself is interactionally meaningful

## Excluded

Human-human interaction without animal involvement.

Pure environmental existence belongs to Ecology.

Pure movement mechanics belong to Movement.

Pure behavioral state belongs to Behavior.

Pure training state belongs to Domestic/Trained.

## Non-Interaction

These do not automatically constitute interactions:

- same scene
- same location
- visual proximity
- co-presence
- shared habitat
- looking in the same direction
- being in the same herd unless an actual event is established
- cinematic composition
