# OWNERSHIP AND BOUNDARIES

## Biology

Determines whether the interaction is anatomically, physiologically, reproductively, or physically possible.

## Behavior

Determines behavioral state, motivation, response, communication, fear, aggression, affiliation, learning and other behavioral mechanisms.

## Movement

Determines physical execution.

Example:
Interaction: HORSE_A KICKS HORSE_B.
Movement: mechanics of the kick.
Biology: anatomical feasibility and injury consequences.
Behavior: motivation/response.

## Ecology

Determines ecological context and ecological relationship.

## Domestic / Trained

Determines domestication, training, handler, work, equipment and husbandry context.

## Interaction

Determines:
- event identity
- participants
- event type
- event lifecycle
- event context
- event outcome
- relationship consequence
- interaction continuity

## AI Production

Only implements an approved state.

## Conflict Rule

A downstream prompt, generated asset, cinematic choice, or scene description cannot override upstream canonical truth.
