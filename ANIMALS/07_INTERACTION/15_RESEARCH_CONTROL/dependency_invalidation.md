# DEPENDENCY INVALIDATION

If an upstream dependency changes, dependent interaction claims must be revalidated.

Examples:

species identity changes
→ interaction plausibility rechecked

historical date changes
→ interaction practice rechecked

animal identity changes
→ participant identity rechecked

behavior state changes
→ interaction interpretation rechecked

ecological context changes
→ interaction plausibility rechecked

Invalidated states cannot silently remain production-approved.
