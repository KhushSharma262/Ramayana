# ECOLOGY SYSTEM INDEX

## System

ANIMALS / 05_ECOLOGY

## Purpose

This system defines the ecological world in which animals and humans exist.

The goal is not to create visually attractive backgrounds.

The goal is to create environments that behave like real living ecological systems.

## Master Ecological Rule

EVERY ECOLOGICAL ELEMENT VISIBLE IN A SCENE MUST HAVE A REASON FOR BEING THERE.

The reason may derive from:

- climate
- geography
- geology
- soil
- water
- habitat
- vegetation
- season
- food
- reproduction
- animal distribution
- human land use
- cultural landscape
- historical evidence
- canonical evidence

If an element has no defensible ecological reason:

BLOCKED.
