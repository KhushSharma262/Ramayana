# ECOLOGICAL CAUSALITY AND FOOD WEB

## PURPOSE

Prevent isolated ecological facts from producing impossible ecological combinations.

## MASTER CAUSAL MODEL

CLIMATE
→ WATER
→ SOIL / GEOLOGY
→ VEGETATION
→ RESOURCES
→ SPECIES
→ POPULATION
→ INTERACTIONS
→ HUMAN ACTIVITY
→ LOCAL ECOLOGICAL STATE
→ SCENE

This is an audit model, not a rigid one-way biological law.

## FOOD WEB

Where relevant record:

- producer
- herbivore
- omnivore
- carnivore
- predator
- prey
- scavenger
- decomposer
- parasite
- host
- pollinator
- seed disperser

## PREDATOR SUPPORT

Predator presence must be compatible with:

- prey availability
- habitat
- territory
- season
- water
- human pressure

## RESOURCE SUPPORT

High local concentration requires plausible resource concentration.

Examples:

- water
- fruiting
- flowering
- grazing
- carrion
- nesting sites
- shelter
- salt/mineral resources

## CARRYING CAPACITY

Do not represent carrying capacity as an invented exact number unless evidence supports numerical estimation.

Allowed:

KNOWN
ESTIMATED
QUALITATIVE
UNKNOWN

## HUMAN ECOLOGY

Human activities must have ecological consequences where relevant:

- agriculture
- grazing
- irrigation
- hunting
- fishing
- logging
- settlement
- roads
- wells
- ponds
- waste
- fire
- pilgrimage
- resource extraction
- warfare

## ECOLOGICAL EVENT CASCADE

A disturbance can propagate:

EVENT
→ RESOURCE CHANGE
→ VEGETATION CHANGE
→ WATER CHANGE
→ SPECIES RESPONSE
→ POPULATION RESPONSE
→ HUMAN RESPONSE

The affected downstream states must be reviewed.

## IMPOSSIBLE COMBINATION CHECK

Each scene must be evaluated as a combination.

A collection of individually valid facts does NOT automatically make the combined scene valid.

## FINAL RULE

Ecological plausibility is evaluated at the SYSTEM level, not merely field-by-field.
