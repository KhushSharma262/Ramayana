# RAMAYANA LOCATION TO ECOLOGY CONTROL

## Purpose

A Ramayana location must never receive an ecological profile merely because a modern location with the same or similar name exists.

## Required Chain

RAMAYANA LOCATION
→ CANONICAL REFERENCES
→ GEOGRAPHICAL INTERPRETATION
→ TEMPORAL INTERPRETATION
→ HISTORICAL / PALEOECOLOGICAL EVIDENCE
→ ECOLOGICAL RECONSTRUCTION
→ HABITAT
→ VEGETATION
→ WATER
→ SPECIES
→ HUMAN ECOLOGY
→ SCENE

## Location Identity States

RESOLVED
PROVISIONALLY_RESOLVED
CONTESTED
UNRESOLVED

## Rules

RESOLVED:
Evidence sufficiently supports the geographical interpretation.

PROVISIONALLY_RESOLVED:
A working interpretation exists but important uncertainty remains.

CONTESTED:
Multiple serious interpretations exist.

UNRESOLVED:
No defensible geographical interpretation has been established.

## Hard Rule

UNRESOLVED locations cannot receive production ecological claims.

## Important

A modern place-name match is NOT sufficient evidence of historical identity.
