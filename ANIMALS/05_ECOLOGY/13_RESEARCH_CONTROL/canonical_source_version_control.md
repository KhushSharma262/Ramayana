# CANONICAL SOURCE VERSION CONTROL

## Purpose

"Ramayana" is not automatically treated as one undifferentiated textual source.

## Required Canonical Metadata

tradition:
text_name:
edition:
language:
translator:
publisher:
publication_year:
source_reference:
passage:
canonical_scope:
interpretive_status:

## Canonical Scope

Examples may include:

VALMIKI_RAMAYANA
RAMCHARITMANAS
OTHER_SPECIFIED_TRADITION

The exact tradition must be declared.

## Rule

A statement from one tradition must not silently become a universal statement about every Ramayana tradition.

## Conflict

If traditions differ:

record both.

Do not silently merge them.

## Literary Description

Poetic or literary language must be classified before ecological interpretation.

Possible interpretation:

LITERAL_ECOLOGICAL
DESCRIPTIVE
POETIC
SYMBOLIC
THEOLOGICAL
AMBIGUOUS
