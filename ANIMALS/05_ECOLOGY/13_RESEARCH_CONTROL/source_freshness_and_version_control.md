## Review Triggers

A claim becomes REVIEW_REQUIRED if:

- source is superseded
- source is withdrawn
- important new evidence appears
- geographic interpretation changes
- temporal interpretation changes
- parent dependency changes
- methodology is materially challenged
- canon source selection changes

## Rule

Old evidence remains part of the audit trail.

It does not silently remain the current authority if superseded.
