NAME

ECOLOGICAL_SCOPE
EVIDENCE
INTERPRETATION
CLAIM
CONFIDENCE
UNCERTAINTY
APPROVAL_STATE
VERSION
SNAPSHOT

## Geographic Rule

India-first evidence is preferred when applicable.

Priority:

INDIA
→ SOUTH ASIA
→ ASIA
→ GLOBAL

Global evidence must not silently be represented as India-specific evidence.

## Temporal Rule

Modern ecology must not automatically be projected into the Ramayana period.

Historical reconstruction requires independent evidence.
