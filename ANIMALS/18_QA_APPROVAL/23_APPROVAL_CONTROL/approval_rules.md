# APPROVAL RULES

PASS requires:
- complete required inputs
- valid snapshots
- no unresolved blocking defect
- all mandatory tests passed
- traceability complete
- provenance complete
- scope defined
- reviewer decision recorded

PASS_WITH_NONBLOCKING_FINDINGS may only be used where explicitly permitted.

REJECT means output does not conform.

BLOCK means a valid acceptance decision cannot yet be made.

Approval is version-specific and scope-specific.
