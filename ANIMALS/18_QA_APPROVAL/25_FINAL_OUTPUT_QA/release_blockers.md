# RELEASE BLOCKERS

Any of the following blocks final release:

- unknown material truth
- unresolved conflict
- unresolved taxonomy
- stale snapshot
- missing required evidence
- missing dependency
- identity mismatch
- continuity contradiction
- biological impossibility
- behavioral impossibility
- ecological impossibility
- movement impossibility
- invalid interaction
- audio identity failure
- costume/equipment anachronism
- AI reference mismatch
- provenance failure
- lineage failure
- failed critical QA
- failed mandatory test
- unauthorized override
- incomplete approval
