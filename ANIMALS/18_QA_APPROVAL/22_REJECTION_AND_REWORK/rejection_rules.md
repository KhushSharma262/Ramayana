# REJECTION RULES

REJECT when the output demonstrably violates an approved requirement.

BLOCK when QA cannot determine compliance because required truth,
evidence, dependency, identity, provenance, or resolution is unavailable.

Rework must:
1. identify defect
2. identify responsible upstream/production owner
3. create rework reference
4. preserve failed asset lineage
5. regenerate or modify through controlled process
6. return to QA
7. never convert REJECT directly into PASS
