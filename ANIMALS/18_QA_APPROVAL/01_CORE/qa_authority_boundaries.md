# QA AUTHORITY BOUNDARIES

UPSTREAM DOMAINS OWN TRUTH.

QA owns:
- verification
- test execution
- acceptance criteria
- defect classification
- approval status
- rejection status
- audit evidence

QA does not own:
- canonical facts
- biological facts
- behavioral facts
- ecological facts
- identity truth
- continuity truth
- historical truth
- supernatural truth
- cinematic truth

QA cannot override an approved upstream snapshot.

If QA detects an upstream contradiction:
STATUS = BLOCKED
OWNER = RELEVANT AUTHORITY DOMAIN
