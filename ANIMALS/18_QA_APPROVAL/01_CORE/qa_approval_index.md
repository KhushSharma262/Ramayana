# QA APPROVAL SYSTEM

18_QA_APPROVAL is the independent verification and acceptance layer.

QA verifies whether an output conforms to approved upstream truth,
snapshots, scene requirements, shot requirements, production rules,
and validation criteria.

QA DOES NOT:
- create canonical truth
- rewrite Biology
- rewrite Behavior
- rewrite Movement
- rewrite Ecology
- rewrite Domestic/Training
- rewrite Interaction
- rewrite Visual Identity
- rewrite Continuity
- rewrite Audio
- rewrite Costume
- rewrite Cinematic Integration
- rewrite AI Production
- silently resolve conflicts
- silently repair rejected outputs

QA may:
- PASS
- REJECT
- BLOCK
- REQUEST REWORK
- escalate unresolved conflicts

Master rule:

QA ACCEPTS WHAT IS PROVEN COMPLIANT.
QA NEVER MAKES NON-COMPLIANCE BECOME COMPLIANCE.
