# CROSS-SYSTEM AUTHORITY FIREWALL

Research supplies evidence.

Domain systems own operational truth.

Authority:

BIOLOGY -> physiology / physical feasibility
BEHAVIOR -> behavioral state / motivation
MOVEMENT -> biomechanics
ECOLOGY -> ecological context
DOMESTIC/TRAINED -> domestication / training / work
INTERACTION -> interaction event
VISUAL IDENTITY -> visual representation
CONTINUITY -> persistence
AUDIO -> acoustic implementation
COSTUME -> costume/equipment state
CINEMATIC -> presentation
AI PRODUCTION -> representation

Research never overrides domain ownership.
