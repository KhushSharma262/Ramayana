# SOURCE CONFLICT RULES

When sources disagree:

1. Preserve both sources.
2. Verify source identity.
3. Compare source authority.
4. Compare geographic scope.
5. Compare temporal scope.
6. Compare taxonomy.
7. Compare evidence type.
8. Determine whether the conflict is genuine.
9. Route to the domain owner.
10. Record the resolution or keep BLOCKED.

Never delete the weaker source merely because it lost the resolution.
