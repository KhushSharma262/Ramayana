# 16_CONFLICTS_UNKNOWN

## Purpose

16_CONFLICTS_UNKNOWN is the uncertainty-control layer for ANIMALS.

It records and controls:

- unknowns
- evidence gaps
- contradictions
- source conflicts
- taxonomy uncertainty
- geographic uncertainty
- temporal uncertainty
- canonical ambiguity
- historical uncertainty
- biological uncertainty
- behavioral uncertainty
- movement uncertainty
- ecological uncertainty
- domestic/training uncertainty
- interaction uncertainty
- visual uncertainty
- audio uncertainty
- battle/high-stress uncertainty
- costume/equipment uncertainty
- cross-system conflicts

## It Does Not

This system does not invent missing facts.

It does not silently select between conflicting claims.

It does not override Biology, Behavior, Ecology, Movement, Continuity, or any other domain owner.

## Master Principle

UNKNOWN IS A VALID STATE.

CONFLICT IS A VALID STATE.

UNCERTAINTY MUST NEVER BE CONVERTED INTO FALSE CERTAINTY.
