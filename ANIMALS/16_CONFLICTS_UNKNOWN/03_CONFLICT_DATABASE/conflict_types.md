# CONFLICT TYPES

SOURCE_CONFLICT:
Sources directly disagree.

CLAIM_CONFLICT:
Two approved/proposed claims disagree.

SCOPE_CONFLICT:
Claims appear contradictory because their scopes differ.

TEMPORAL_CONFLICT:
Claims belong to different periods.

GEOGRAPHIC_CONFLICT:
Claims belong to different geographic contexts.

TAXONOMIC_CONFLICT:
Entity identity is disputed.

TRANSLATION_CONFLICT:
Canonical translations differ materially.

INTERPRETIVE_CONFLICT:
Same evidence permits different interpretations.

DOMAIN_CONFLICT:
Two domain systems make incompatible assumptions.

CONTINUITY_CONFLICT:
Current state contradicts previous approved state.

PRODUCTION_CONFLICT:
Generated output contradicts approved truth.

VARIABILITY_NOT_CONFLICT:
Different outcomes are naturally possible and should not be incorrectly treated as contradiction.
