# LOCOMOTION AND GAIT ENGINE

## Rule

Locomotion terminology must be species appropriate.

Do not force:
walk / run / jump / gallop
onto species for which those categories are biologically inappropriate.

## Locomotion Dimensions

Where applicable:

- posture
- initiation
- acceleration
- steady movement
- transition
- turning
- deceleration
- stopping
- recovery

## Gait Transition

Abrupt gait changes must not occur without a physically plausible transition unless explicitly supported by the species.

## Flight

Where applicable:

takeoff
→ wingbeat
→ climb
→ cruise
→ maneuver
→ glide/soar
→ descent
→ landing

## Swimming

Where applicable:

propulsion
→ acceleration
→ cruising
→ turning
→ diving
→ surfacing
→ stopping

## Validation

Every movement mode must be checked against:
- species
- morphology
- physical limits
- context
- terrain
- condition
