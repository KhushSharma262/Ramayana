# CHARACTER ADAPTATION

A reusable performance is only a starting point.

Character adaptation applies:

- character posture
- gait
- gesture signature
- emotional signature
- spiritual composure
- relationship behavior
- physical stature
- movement amplitude
- breathing
- eye behavior
- facial behavior

Therefore:

BASE PERFORMANCE
+
CHARACTER PERFORMANCE DNA
+
CONTEXT
=
CHARACTER PERFORMANCE

The final result must belong to the character rather than the source
performer.
