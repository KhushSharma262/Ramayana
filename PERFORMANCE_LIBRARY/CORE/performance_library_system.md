# PERFORMANCE LIBRARY SYSTEM

PERFORMANCE_LIBRARY stores reusable performance assets.

It is the production repository for actual performance material
that can be:

- imported
- cleaned
- retargeted
- adapted
- blended
- approved
- assigned to characters
- assigned to scenes
- assigned to shots
- reused when appropriate

## Domain separation

ACTING
=
how a character should behave emotionally and dramatically

MOTIONS
=
how physical movement works

PERFORMANCE_LIBRARY
=
the actual reusable performance assets

CHARACTERS
=
character-specific performance identity

3D
=
rig and technical implementation

AI
=
generation/transformation tools

SCENES / SHOTS
=
where the performance is used

## Core principle

A performance asset is NOT automatically approved simply because
it exists.

Every performance must pass:

SOURCE
    ↓
INGESTION
    ↓
CLEANUP
    ↓
RETARGETING
    ↓
CHARACTER ADAPTATION
    ↓
PERFORMANCE QA
    ↓
APPROVAL
    ↓
LIBRARY
    ↓
SHOT USE

The library contains reusable approved or clearly labelled
candidate performance assets.
