# PERFORMANCE REUSE RULES

Performance assets may be reused when:

- the context is compatible
- the movement remains believable
- character adaptation is appropriate
- continuity is preserved
- repetition is not visually obvious
- the performance does not contradict the character's identity

Reuse must not produce recognizable mechanical repetition.

The same base performance may be adapted through:

- timing
- amplitude
- posture
- gait
- gesture
- facial behavior
- gaze
- breathing
- emotional intensity
- character-specific movement
