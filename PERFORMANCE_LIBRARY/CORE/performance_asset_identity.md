# PERFORMANCE ASSET IDENTITY

Every performance asset requires a unique identity.

Minimum metadata:

- performance ID
- source ID
- asset type
- performer/source type
- movement category
- emotional category where applicable
- interaction category
- duration
- frame rate
- body coverage
- facial coverage
- hand coverage
- source format
- rig compatibility
- character compatibility
- cleanup status
- retargeting status
- approval status
- version

Performance identity must remain stable across versions.
