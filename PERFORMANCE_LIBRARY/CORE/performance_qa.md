# PERFORMANCE LIBRARY QA

Reject or flag assets containing:

- foot sliding
- floating
- impossible balance
- broken joints
- unnatural acceleration
- robotic repetition
- frozen facial expressions
- incorrect gaze
- disconnected hands
- impossible prop contact
- unstable body weight
- sudden unexplained posture changes
- broken transitions
- AI-generated anatomical artifacts

Technical correctness alone is insufficient.

The performance must also feel human.
