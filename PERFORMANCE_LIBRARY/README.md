# PERFORMANCE LIBRARY

## Purpose

PERFORMANCE_LIBRARY stores reusable performance assets.

It is NOT the place where the rules of acting are invented.

## Domain boundaries

ACTING
    =
why and how a character emotionally performs

MOTIONS
    =
physical movement principles

PERFORMANCE_LIBRARY
    =
actual reusable performance assets

CHARACTERS
    =
character-specific performance identity

3D
    =
rig and technical implementation

AI
    =
generation/transformation

SCENES / SHOTS
    =
final usage

## Most important principle

A reusable performance is a BASE.

It is not automatically the final performance of a character.

The final performance is:

BASE PERFORMANCE
+
CHARACTER PERFORMANCE DNA
+
ACTING
+
CONTEXT
+
EMOTION
+
RELATIONSHIP
+
ENVIRONMENT
+
PHYSICAL CONSTRAINTS

This allows one human performance source to be transformed into
different believable characters without making every character
move identically.

## Human realism

Do not clean away all imperfection.

Preserve appropriate:

- breathing
- asymmetry
- weight shifts
- pauses
- eye movement
- micro-reactions
- timing variation
- physical recovery
- believable momentum

Remove technical errors, not humanity.
