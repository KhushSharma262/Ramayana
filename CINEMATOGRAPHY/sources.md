# SOURCES

This file defines the relationship between cinematography and source material.

Detailed evidence belongs in:

CINEMATOGRAPHY\research\

The root cinematography system must not treat an unverified reference as an authoritative production rule.

## SOURCE HIERARCHY

Research should distinguish:

- primary source
- documented technical source
- measured evidence
- observed evidence
- secondary analysis
- tertiary reference
- inference
- interpretation
- stylistic reference
- uncertain information

## RULE

SOURCE MATERIAL
→ EVIDENCE
→ INTERPRETATION
→ SYSTEM REVIEW
→ AUTHORITATIVE RULE

Never:

SOURCE MATERIAL
→ DIRECT GENERATION COMMAND

## UNKNOWN

If a source does not establish a technical fact, the system must not invent one.

## STYLE REFERENCES

Films, photographers, cinematographers and visual references may be studied for causality and technique.

They must not become automatic visual presets.
