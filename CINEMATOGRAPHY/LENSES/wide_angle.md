# WIDE-ANGLE LENS BEHAVIOUR

## PURPOSE

Control the physical optical behaviour of wide-angle lenses.

A wide-angle lens provides a broader field of view than a normal lens for the selected sensor format, allowing more of the environment to be captured while retaining useful spatial depth.

Wide-angle behaviour must be derived from:

- focal length
- sensor format
- active sensor area
- camera position
- subject distance
- subject/background distances
- lens projection
- lens distortion
- focus distance
- aperture
- lens design
- camera movement
- lighting

A wide-angle lens is NOT:

- a digital wide-angle filter
- an automatic distortion effect
- an automatic perspective-expansion effect
- an automatic deep-focus lens
- an automatic immersive-camera effect
- a fisheye lens
- an automatic cinematic look

The physical camera configuration must produce the wide-angle appearance.

==================================================
FIELD OF VIEW
==================================================

Wide-angle lenses capture more of the environment than normal lenses.

FOV must be physically calculated from:

- focal length
- sensor dimensions
- active sensor area
- aspect ratio
- projection type.

Do not digitally widen the image.

Do not crop or stretch a normal lens to simulate wide-angle optics.

==================================================
SENSOR FORMAT
==================================================

Sensor format affects the FOV produced by a given physical focal length.

For a smaller sensor:

the same focal length produces a narrower FOV.

Crop factor is a FOV/framing relationship only.

It does NOT:

- change physical focal length
- independently create perspective
- independently create distortion
- create compression
- create anamorphic behaviour.

Always use the actual active sensor area.

==================================================
SPHERICAL VS ANAMORPHIC
==================================================

A wide-angle lens may be:

- spherical
- anamorphic.

Determine the optical format before applying lens behaviour.

If spherical:

do not apply:

- anamorphic squeeze
- anamorphic oval bokeh
- characteristic anamorphic horizontal streaks.

If anamorphic:

apply only the optical behaviour supported by the selected lens profile.

Wide-angle does not imply anamorphic.

==================================================
PROJECTION
==================================================

Most conventional wide-angle cinema lenses use rectilinear projection.

Rectilinear projection attempts to keep straight lines straight, subject to the lens's actual distortion profile.

Do not assume:

WIDE-ANGLE = CURVED LINES.

Perspective convergence can still occur.

==================================================
FISHEYE
==================================================

Fisheye is a specialized projection and must not be treated as normal wide-angle behaviour.

Only use fisheye if explicitly selected.

Without explicit fisheye selection:

NO FISHEYE PROJECTION.

Do not create:

- strongly curved horizons
- circular architecture
- extreme edge stretching
- fisheye-like face distortion.

==================================================
PERSPECTIVE
==================================================

Wide-angle lenses can reveal strong perspective relationships when the camera is close.

A nearby foreground object may appear much larger relative to a distant object.

This is caused primarily by:

CAMERA POSITION.

Do not digitally enlarge the foreground.

Do not shrink the background.

==================================================
CAMERA DISTANCE
==================================================

Camera distance is critical for wide-angle rendering.

Closer camera position generally produces:

- stronger relative size differences
- stronger perspective
- greater foreground/background separation
- more pronounced parallax during movement.

Farther camera position generally produces:

- weaker perspective differences
- more restrained spatial relationships.

The system must explicitly determine camera distance.

==================================================
SPATIAL DEPTH
==================================================

Wide-angle lenses can reveal:

- foreground
- midground
- background
- environmental depth
- parallax
- occlusion.

Maintain genuine 3D spatial structure.

Do not manufacture depth using:

- 2D layers
- depth maps
- background scaling
- synthetic parallax.

==================================================
FOREGROUND EMPHASIS
==================================================

A nearby object can become visually prominent with a wide-angle lens.

Useful examples:

- character entering a doorway
- weapon in foreground
- hand reaching toward camera
- tree branch close to camera
- horse or elephant approaching camera
- architectural column
- ritual object.

The increased size must result from actual camera distance and object placement.

==================================================
FACIAL PERSPECTIVE
==================================================

Wide-angle lenses can strongly affect facial perspective when used close to the subject.

Possible physical consequences include:

- nearer features appearing larger
- increased apparent facial depth
- stronger nose-to-ear size difference.

This can be appropriate for certain dramatic shots.

However:

maintain anatomically plausible faces.

NEVER create:

- stretched noses
- enlarged eyes
- warped jaws
- distorted ears
- changing facial proportions
- identity instability.

If facial accuracy is the priority:

increase camera distance and/or use a more appropriate focal length.

==================================================
WIDE-ANGLE PORTRAITS
==================================================

Wide-angle portraiture can be used when:

- environment is narratively important
- subject/environment relationship matters
- immersive perspective is intentional
- character is moving through space.

It should not be used simply to make a portrait look "cinematic."

==================================================
VERTICALS
==================================================

If the camera is tilted upward or downward:

architectural verticals may converge due to perspective.

This is not automatically lens distortion.

If the camera is kept level:

verticals should remain appropriately aligned according to the projection and lens design.

Do not digitally straighten lines unless optical correction is explicitly part of the workflow.

==================================================
LENS DISTORTION
==================================================

Wide-angle lenses may exhibit:

- barrel distortion
- pincushion distortion
- moustache distortion
- complex distortion
- highly corrected rectilinear behaviour.

Distortion must follow the selected lens profile.

Do not assume:

WIDE = HEAVY BARREL DISTORTION.

Modern wide cinema lenses may be highly corrected.

==================================================
EDGE BEHAVIOUR
==================================================

Objects near the frame edges may appear more spatially exaggerated due to:

- wide FOV
- camera position
- perspective
- lens projection
- optical distortion.

This must remain continuous.

As an object moves toward the edge:

its geometry must change gradually according to the lens.

Never allow:

- sudden stretching
- popping geometry
- frame-edge morphing
- unstable proportions.

==================================================
SUBJECT PLACEMENT
==================================================

Wide-angle lenses require deliberate subject placement.

For critical faces:

avoid placing them at extreme frame edges unless intentionally motivated.

For architecture:

avoid placing critical straight lines at positions where the selected lens produces unacceptable distortion unless that appearance is intended.

OPTICAL CAUSALITY / UNKNOWN-PARAMETER RULE
==================================================

Wide-angle behaviour must never be inferred from the label "wide-angle" alone.

Every optical result must be derived from the parameters that physically cause it.

If a required parameter is unknown:

- do not invent a value
- do not infer an optical effect
- do not substitute a generic cinematic effect
- do not exaggerate the visible result

Instead:

1. identify the missing physical parameter
2. preserve the known constraints
3. choose the least-assumptive physically plausible configuration
4. recalculate all dependent optical behaviour

UNKNOWN PARAMETERS MUST NOT AUTHORIZE OPTICAL EFFECTS.

- change focal length merely to obtain stronger distortion

If a required framing is physically achievable with multiple focal lengths:

- camera position
- subject distance
- spatial relationships
- story purpose
- optical continuity.

- ceremonial spaces
- palace halls
- temple corridors
- courtyards.

Maintain:

- stable columns

- natural perspective
- correct scale.

==================================================
WIDE-ANGLE AND MOUNTAINS
==================================================

Useful when:

- foreground geography
- character position
- mountain distance
- landscape scale

must be visible simultaneously.

Maintain atmospheric perspective.

Do not artificially enlarge mountains.

==================================================
ATMOSPHERIC PERSPECTIVE
==================================================

Wide-angle shots can contain large amounts of atmosphere.

Represent:

- mist
- dust
- smoke
- humidity
- haze

only when physically supported.

Do not add generic haze to make the image cinematic.

==================================================
OPTICAL CHARACTER
==================================================

Wide-angle lenses may be:

- highly corrected
- neutral
- vintage
- soft
- high contrast
- low contrast
- character-oriented.

Do not automatically make wide-angle lenses:

- distorted
- soft
- dreamy
- vintage
- heavily flared.

Use the selected lens profile.

==================================================
MODERN WIDE-ANGLE
==================================================

Modern wide cinema lenses may provide:

- strong geometric correction
- high resolution
- controlled CA
- controlled flare
- restrained edge behaviour.

Do not add historical imperfections unless explicitly supported.

==================================================
CHARACTER WIDE-ANGLE
==================================================

A character wide-angle lens may exhibit:

- stronger distortion
- edge softness
- more flare
- greater CA
- stronger field curvature
- distinctive bokeh.

These characteristics must remain:

- lens-specific
- spatially coherent
- temporally stable.

==================================================
TEMPORAL CONSISTENCY
==================================================

Wide-angle optical behaviour must remain stable across frames.

NEVER allow:

- FOV flicker
- distortion flicker
- edge stretching changes
- architecture morphing
- face geometry changes
- bokeh popping
- flare popping
- ghosting flicker
- vignetting flicker
- focus hunting
- parallax discontinuity
- object-scale jumps.

Every change must have a physical cause.

==================================================
LENS CONTINUITY
==================================================

The same wide-angle lens must preserve:

- focal length
- optical format
- distortion profile
- bokeh
- flare
- ghosting
- CA
- breathing
- vignetting
- image coverage.

If the lens changes:

recalculate the complete optical configuration.

Same focal length does not necessarily mean same lens.

==================================================
SEQUENCE CONTINUITY
==================================================

Wide-angle usage should be motivated by:

- environmental importance
- spatial geography
- movement
- architecture
- immersion
- scale
- subject/environment relationship.

Do not randomly alternate between wide-angle and normal lenses.

A transition to wide-angle should have a clear shot purpose.
