## ABSOLUTE RULES

1. AUDIO does not create world truth.
2. AUDIO renders audio consequences of authoritative continuity state.
3. Global STATE remains authoritative for persistent world state.
4. Global EVENT remains authoritative for events.
5. PHYSICS remains authoritative for physical causality.
6. SPATIAL remains authoritative for geometry and position.
7. PERFORMANCE remains authoritative for performed action.
8. CHARACTER remains authoritative for character identity.
9. ANIMAL remains authoritative for animal identity.
10. LOCATION remains authoritative for location identity.
11. ENVIRONMENT remains authoritative for environmental state.
12. TRANSFORMATION remains authoritative for transformation state.
13. AI_GENERATION implements established audio requirements.
14. Prompt text never becomes the source of truth.
15. Previous AI output never becomes authoritative merely because it exists.
16. Regeneration never resets continuity.
17. A new AI output must inherit all approved persistent audio state.
18. Unknown is not silence.
19. Silence is not missing data.
20. Missing data must remain explicitly unknown.
21. Appearance of a sound is not proof of its source.
22. Character intention is not automatically equivalent to audible interpretation.
23. Human hearing perspective and audience perspective may differ.
24. Diegetic and non-diegetic audio must remain explicitly classified.
25. Subjective/internal/dream/memory/spiritual audio must remain explicitly classified.
26. Every audio asset must have lineage.
27. Every authoritative audio attribute must have one owner.
28. Conflicting domains must resolve through authority hierarchy.
29. Retroactive changes must propagate through the dependency graph.
30. Approved masters are immutable unless explicitly reopened.
31. Reopening requires reason, impact analysis, repair and revalidation.
32. Audio continuity exists from frame → shot → scene → sequence → episode → series.
33. Physical actions must have physically compatible audio.
34. Audio must not contradict established physics without an explicit supernatural/canonical basis.
35. Sound travel time must be respected when physically relevant.
36. Acoustic environment must persist unless an event changes it.
37. Residual sound must persist where physically appropriate.
38. Voice identity must remain stable while natural performance variation is allowed.
39. Pronunciation identity must remain stable unless an authorized exception exists.
40. Music themes and motifs require explicit identity and lineage.
41. Ambient audio must represent persistent world activity rather than arbitrary loops.
42. Repeated procedural audio must be checked for detectable repetition.
43. AI voice cloning requires provenance and authorization records.
44. Every recording must preserve technical and provenance metadata.
45. Final delivery versions must retain lineage to their master.
46. Language variants must retain shared scene/event synchronization.
47. Audio changes must trigger only the smallest required dependency chain.
48. The earliest incorrect state is repaired before downstream outputs.
49. QA validates truth; QA does not create truth.
50. User-approved locked continuity is the final production authority.

## NO SILENT RESET

No audio attribute may silently revert to:

- default voice
- default pronunciation
- default ambience
- default room tone
- default reverb
- default distance
- default spatial position
- default music
- default foley
- default environmental sound
- default performer
- default model
- default mix

unless the change has an explicit causal record.

The audio system must preserve the same continuous world, characters, animals, objects, environments, performances, physical events, emotional states and narrative reality across every generated output while allowing bounded natural human and environmental variation.
