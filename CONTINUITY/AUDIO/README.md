## Critical Continuity Rule

Audio is not independent decoration.

If something happens physically, the audio must be compatible with it.

If something changes physically, its audio may need to change.

If something remains unchanged, its audio identity should persist.

## Voice Rule

A character's voice is a persistent identity.

Natural performance variation is allowed.

Unexplained voice drift is not.

## Dialogue Rule

The authoritative dialogue text remains stable.

Pronunciation, delivery, emotion, pauses, breathing and timing are separate
continuity attributes.

## Foley Rule

Foley must correspond to:

object
material
movement
contact
weight
surface
damage
position

## Ambience Rule

Ambient sound belongs to the world.

It changes naturally with:

location
time
weather
season
population
activity
environment

but must not randomly reset between shots.

## Music Rule

Music has identity through:

theme
motif
character association
location association
instrumentation
tempo
mode
emotional purpose

## Silence Rule

Silence is a real audio state.

UNKNOWN AUDIO is not the same as SILENCE.

## Spatial Rule

Every important source has:

position
direction
distance
height
movement
occlusion
reflection
reverberation

## AI Rule

AI_GENERATION renders established audio truth.

It does not decide:

character identity
voice identity
dialogue truth
pronunciation truth
physical causality
environment truth
canonical sound
continuity state

## Regeneration Rule

Regeneration is repair, not a reset.

Preserve all unaffected continuity.

## Final Principle

The audience should hear one continuous world.

Not a collection of independently generated sounds.
