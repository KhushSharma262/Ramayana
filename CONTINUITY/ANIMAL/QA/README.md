# ANIMAL QA

## Purpose

The Animal QA system validates the complete Animal continuity architecture.

## Master Model

SOURCE OF TRUTH
→ REQUIREMENTS
→ GENERATION / IMPLEMENTATION
→ VALIDATION
→ ERROR DETECTION
→ IMPACT ANALYSIS
→ REPAIR
→ REVALIDATION
→ APPROVAL
→ LOCK

## Critical Rule

QA does not create truth.

The authoritative domain creates truth.

QA verifies it.

## Canon Rule

Canon overrides reconstruction.

Research and biological reconstruction may fill unspecified gaps,
but their classification must remain explicit.

## AI Rule

AI output is a representation.

It is not automatically continuity truth.

## Regeneration Rule

Regeneration is not reset.

All valid state must be preserved unless an authorized change exists.

## Persistence Rule

Established consequences persist until a valid event changes them.

## Unknown Rule

UNKNOWN ≠ UNCHANGED.

Missing information must never silently become a fixed assumption.

## Final Authority

The user remains the final production approval authority.
