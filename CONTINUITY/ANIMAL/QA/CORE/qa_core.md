# ANIMAL QA CORE

## Purpose

QA verifies that every animal-related output agrees with authoritative
continuity, canon, biology, state, physics, performance and AI-generation
requirements.

QA does not create truth.

QA detects whether generated or recorded material agrees with truth.

## Master QA Model

SOURCE OF TRUTH
→ REQUIREMENTS
→ GENERATION / IMPLEMENTATION
→ VALIDATION
→ ERROR DETECTION
→ IMPACT ANALYSIS
→ REPAIR
→ REVALIDATION
→ APPROVAL
→ LOCK

## Primary Principle

An output is not correct merely because it looks plausible.

It must also be:

canonically consistent
biologically plausible where reconstruction is required
state-consistent
temporally consistent
spatially consistent
physically consistent
behaviorally consistent
identity-consistent
AI-artifact-free
continuous with previous and following material

## QA Authority

Global CONTINUITY authority remains highest.

Animal QA validates Animal-domain requirements and interfaces with global QA.
