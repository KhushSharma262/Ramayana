# RETROACTIVE CORRECTION

Never silently rewrite interaction history.

Procedure:

1. Preserve original interaction.
2. Identify incorrect state.
3. Determine dependency chain.
4. Find smallest affected scope.
5. Correct authoritative state.
6. Repair dependent domains.
7. Regenerate affected outputs.
8. Revalidate.
9. Propagate approved correction.
10. Preserve audit history.
