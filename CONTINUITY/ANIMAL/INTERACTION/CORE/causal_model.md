# CAUSAL MODEL

TRIGGER
→ DETECTION
→ PERCEPTION
→ RECOGNITION
→ INTERNAL STATE
→ MOTIVATION
→ DECISION / RESPONSE
→ ACTION
→ CONTACT / EFFECT
→ CONSEQUENCE
→ PERSISTENCE
→ NEXT STATE

Not every interaction contains every stage.

Valid outcomes include:

no_detection
no_recognition
no_reaction
delayed_reaction
avoidance
approach
cooperation
competition
resistance
attack
escape
contact
withdrawal
