# DOMAIN BOUNDARY

INTERACTION:
General causal relationship between participants.

INDIVIDUAL:
Animal identity.

COGNITION:
Animal processing, recognition, memory and decision mechanisms.

BEHAVIOR:
Observable animal behavior.

PHYSIOLOGY:
Biological state.

LOCOMOTION:
Movement mechanics.

GROUP:
Collective state.

HUMAN_INTERACTION:
Specialized human-animal relationship layer.

EVENT:
Event lifecycle.

EQUIPMENT:
Animal-associated equipment.

ECOLOGY:
Ecological consequences.

ENVIRONMENT:
Physical surroundings.

PHYSICS:
Physical mechanics.

SPATIAL:
Geometry.

AUDIO:
Final sound.

AI_GENERATION:
Technical generation.

Interaction must reference these systems rather than duplicate their truth.
