# DIVINE AND MYTHOLOGICAL ANATOMY

## Purpose

Defines anatomical treatment of mythological, divine and supernatural animals.

---

# 1. BASELINE MODEL

Where appropriate:

BIOLOGICAL BASELINE
+
CANONICAL EXCEPTION
+
SUPERNATURAL PROPERTY

---

# 2. AUTHORITY

Extraordinary anatomy must be supported by:

- direct canon
- established tradition
- approved interpretation
- explicitly approved production decision

---

# 3. CLASSIFICATION

Every extraordinary feature should be classified as:

- DIRECT_CANON
- DERIVED_CANON
- TRADITIONAL_INTERPRETATION
- BIOLOGICAL_RECONSTRUCTION
- HISTORICAL_RECONSTRUCTION
- VISUAL_RECONSTRUCTION
- DIRECTORIAL_CHOICE
- PRODUCTION_CHOICE
- UNKNOWN
- UNCERTAIN

---

# 4. BIOLOGICAL LIMITS

Ordinary biological anatomy may be used as a reconstruction baseline
when canon does not specify an extraordinary property.

---

# 5. CANONICAL EXCEPTIONS

Canon overrides biological expectation.

---

# 6. NO AUTOMATIC FANTASY

Divine or mythological status does not automatically justify:

- extra limbs
- extra eyes
- excessive size
- glowing anatomy
- unnatural wings
- magical markings
- fantasy musculature
- arbitrary anatomical structures

Each requires authority.

---

# 7. TRANSFORMATION

If anatomy changes through supernatural transformation:

PREVIOUS FORM
? TRANSFORMATION EVENT
? NEW FORM
? NEW ANATOMICAL STATE

Both forms remain historically recorded.

---

# 8. AI

AI must receive explicit anatomical constraints for extraordinary beings.
