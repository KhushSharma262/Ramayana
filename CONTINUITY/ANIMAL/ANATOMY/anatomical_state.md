# ANATOMICAL STATE

## Purpose

Tracks current anatomical condition without redefining baseline anatomy.

---

# 1. CURRENT STATE

May include:

- normal
- growing
- mature
- injured
- healing
- scarred
- swollen
- diseased
- pregnant where applicable
- moulting
- shedding
- transformed
- supernatural
- unknown

---

# 2. STATE TRANSITION

Every meaningful anatomical state change should have:

previous_state
? event
? change
? consequence
? duration
? current_state

---

# 3. PERSISTENCE

Persistent anatomical changes must propagate to later scenes.

---

# 4. TEMPORARY CONDITIONS

Temporary anatomical effects must have:

- start
- current status
- duration
- resolution
- downstream consequences

---

# 5. IDENTITY

A state change does not automatically create a new animal identity.

---

# 6. REPLACEMENT

Identity changes only through an explicit replacement,
death, transformation or other authorized event.
