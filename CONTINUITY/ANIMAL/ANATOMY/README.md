## System boundary

ANATOMY defines physical structure.

PHYSIOLOGY defines functional condition.

LOCOMOTION defines movement.

BEHAVIOR defines behavioral response.

PERFORMANCE defines shot-level representation.

AI defines generation enforcement.

## Canon rule

Explicit canon has priority.

Biological knowledge fills unspecified details but cannot overwrite
explicit canonical information.

## Divine and mythological animals

Use:

BIOLOGICAL BASELINE
+
CANONICAL EXCEPTION
+
SUPERNATURAL PROPERTY

Extraordinary anatomy must have an explicit authority classification.

## Continuity rule

Anatomy does not reset between shots.

A generated animal must remain the same physical entity unless an
authorized continuity event changes its anatomy.

## Natural variation

Natural variation is permitted within biological and continuity limits.

Natural variation must never become anatomical identity drift.

## Unknown

Unknown information remains UNKNOWN.

AI is not authorized to invent missing anatomical facts.
