# SPECIES MORPHOLOGY

## Purpose

Defines species-level physical morphology.

---

# 1. BODY PLAN

Record:

- body symmetry
- body regions
- limb arrangement
- appendage arrangement
- head structure
- trunk structure
- tail structure
- specialized structures

---

# 2. SPECIES-SPECIFIC MORPHOLOGY

Do not assume all animals share:

- skeleton
- limb arrangement
- joint arrangement
- head shape
- locomotion anatomy
- sensory anatomy
- feeding anatomy
- reproductive anatomy
- surface covering

---

# 3. TAXONOMIC DIFFERENCES

Where species identification is uncertain, record:

- proposed identification
- alternative identification
- evidence
- confidence
- unresolved differences

Do not silently select an unsupported species.

---

# 4. CANONICAL MORPHOLOGY

A textual or traditional description may establish morphology.

Canonical description takes precedence over generic modern visual convention.

---

# 5. RECONSTRUCTION

When morphology is unspecified:

scientific reconstruction may establish plausible anatomy.

It must be labelled as reconstruction rather than canon.

---

# 6. MYTHOLOGICAL MORPHOLOGY

Mythological animals may have:

- biological baseline
- canonical extraordinary features
- traditional extraordinary features
- supernatural structures

Each must retain its classification.

---

# 7. AI CONTROL

AI must not merge unrelated species morphology merely because the
result appears visually attractive.
