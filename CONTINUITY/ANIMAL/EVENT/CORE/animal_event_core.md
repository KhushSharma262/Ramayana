# ANIMAL EVENT CORE

## Purpose

ANIMAL/EVENT defines animal-specific events and their consequences.

It does not replace the global EVENT system.

## Master Model

GLOBAL EVENT
? ANIMAL EVENT
? ANIMAL-SPECIFIC STATE CHANGE
? DOMAIN CONSEQUENCES
? PERSISTENCE
? NEXT ANIMAL STATE

## Core Causal Model

TRIGGER
? PERCEPTION
? ATTENTION
? RECOGNITION
? MEMORY / LEARNING
? INTERNAL STATE
? MOTIVATION
? DECISION
? ACTION / REACTION
? CONSEQUENCE
? PERSISTENCE
? NEXT STATE

Not every animal or event uses every stage.

## Authority

Global continuity systems remain authoritative for their own domains.

ANIMAL/EVENT owns:
- animal-specific event identity
- event participation
- animal-specific causality
- animal-specific state transition
- event lifecycle
- animal-specific consequences
- event history
- interfaces with other Animal domains

ANIMAL/EVENT does NOT own:
- complete physiology
- complete cognition
- complete behavior
- complete locomotion
- complete ecology
- complete environment
- complete equipment
- global timeline
- global event graph
- global state ledger
- final AI generation

## Fundamental Rule

An event is not a visual instruction.

It is a continuity fact that may later be represented visually, audibly, physically, or through performance.

## Unknown

UNKNOWN means information is unavailable.

UNKNOWN does not mean:
- unchanged
- absent
- false
- zero
- irrelevant

## Canon Rule

Canon defines what happened.

Biology explains unspecified mechanics where appropriate.

Biology cannot overwrite explicit canon.
