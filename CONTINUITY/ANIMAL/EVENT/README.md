# ANIMAL / EVENT

This directory defines animal-specific event continuity.

## Boundary

ANIMAL/EVENT answers:

WHAT EVENT HAPPENED TO / INVOLVING THE ANIMAL?
WHAT ROLE DID THE ANIMAL HAVE?
WHAT CAUSED IT?
HOW DID THE ANIMAL EXPERIENCE/RESPOND TO IT?
WHAT CHANGED?
WHAT CONSEQUENCES FOLLOWED?
WHAT MUST PERSIST?

## Fundamental Rules

1. Canon overrides reconstruction.
2. Unknown remains UNKNOWN.
3. Generated output does not automatically become truth.
4. Events do not reset at shot boundaries.
5. Consequences persist until legitimately changed.
6. Identity remains stable unless an authoritative event changes it.
7. Replacement receives a new identity.
8. Transformation is distinct from replacement.
9. Animal cognition must remain species-appropriate.
10. Human anthropomorphism is prohibited unless supported.
11. Global systems remain authoritative for their domains.
12. Animal Event communicates through interfaces rather than duplicating systems.
