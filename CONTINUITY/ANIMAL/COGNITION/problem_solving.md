# PROBLEM SOLVING

## Purpose

Defines species-appropriate problem-solving capability.

---

# LIMITS

Complexity must remain within established biological capability
unless canonical evidence authorizes otherwise.

---

# METHODS

Where supported:

- trial and error
- exploration
- learned solution
- manipulation
- spatial reasoning
- social learning

---

# PRIOR EXPERIENCE

Previous learning may influence solution selection.

---

# AI CONTROL

AI must not automatically assign human-level puzzle solving
to an animal simply because the scene requires an intelligent action.
