# ANIMAL COGNITION CONTINUITY

## Purpose

Defines how an animal processes information, recognizes entities,
uses memory, learns, evaluates situations, makes species-appropriate
decisions and updates its internal cognitive state.

Cognition is not equivalent to human intelligence.

# COGNITION BOUNDARY

COGNITION defines:

- information processing
- attention
- recognition
- memory
- learning
- expectation
- decision-making
- problem-solving
- social cognition
- communication interpretation

BEHAVIOR defines observable action.

PERCEPTION defines available sensory information.

PHYSIOLOGY defines physical/neurological constraints.

---

# CORE RULE

Do not infer human-like cognition merely because an animal performs
an apparently intelligent action.

Observable behavior is not automatically proof of human-like thought.

---

# UNKNOWN

Unsupported cognitive abilities remain UNKNOWN.

AI must not silently convert unknown cognitive capability into fact.
