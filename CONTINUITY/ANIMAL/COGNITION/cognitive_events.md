# COGNITIVE EVENTS

## Purpose

Defines events that modify cognition.

---

# EVENT MODEL

STIMULUS
? PERCEPTION
? PROCESSING
? COGNITIVE CHANGE
? CONSEQUENCE

# EVENT TYPES

Examples:

- recognition
- learning
- conditioning
- habituation
- sensitization
- memory formation
- memory reinforcement
- memory decay
- discovery
- social learning
- spatial learning
- injury
- illness
- transformation

---

# RULE

Every significant persistent cognitive change should have
an event or explicitly recorded UNKNOWN cause.
