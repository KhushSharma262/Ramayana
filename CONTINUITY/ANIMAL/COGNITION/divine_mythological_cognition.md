# DIVINE AND MYTHOLOGICAL COGNITION

## Purpose

Defines extraordinary cognitive capabilities.

---

# BASE MODEL

BIOLOGICAL COGNITIVE BASELINE
+
CANONICAL EXCEPTION
+
SUPERNATURAL PROPERTY

---

# POSSIBLE EXTRAORDINARY CAPABILITIES

Only where supported:

- extraordinary intelligence
- supernatural awareness
- recognition of divine beings
- extraordinary memory
- extraordinary loyalty
- supernatural knowledge
- unusual intentionality
- supernatural communication comprehension

---

# DISTINCTION

Ordinary sensory perception
must remain separate from
supernatural knowledge.

---

# AUTHORITY

Every extraordinary capability must have:

source
source_reference
classification
confidence
evidence
uncertainty

---

# NO AUTOMATIC MYTHOLOGIZATION

Divine status does not automatically mean unlimited intelligence.
