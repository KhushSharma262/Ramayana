# MEMORY DECAY

## Purpose

Controls persistence and weakening of animal memories.

---

# FACTORS

Memory persistence may depend on:

- species
- memory type
- repetition
- reinforcement
- emotional significance
- age
- stress
- injury
- illness
- time

---

# RULE

Memory decay is not automatically applied to every memory.

---

# CANON

Explicit canonical memory persists according to the source,
regardless of modern assumptions.

---

# UNKNOWN

If the persistence of a specific memory is unknown,
record UNKNOWN rather than inventing a decay period.
