# COGNITION MOTIVATION INTERFACE

## Purpose

Connects cognitive processing with animal motivation.

---

# MOTIVATIONS

May include:

- survival
- hunger
- thirst
- safety
- offspring
- reproduction
- territory
- social attachment
- curiosity
- avoidance
- rest

---

# INTERACTION

Cognition evaluates available information
in relation to current motivation.

---

# OUTPUT

motivation
+
perception
+
memory
+
current state
? decision

---

# BOUNDARY

BEHAVIOR defines observable action.

COGNITION defines processing leading toward that action.
