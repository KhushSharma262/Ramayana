# COGNITIVE IDENTITY

## Purpose

Defines persistent cognitive characteristics of important individual animals.

---

# ATTRIBUTES

Where justified:

- attention profile
- recognition capability
- learning profile
- memory profile
- curiosity
- problem-solving capability
- social recognition
- risk response
- habituation
- sensitization
- established learned associations

---

# INDIVIDUAL VARIATION

Individuals may differ within species-appropriate limits.

---

# STABILITY

Cognitive characteristics persist unless changed by:

- maturation
- learning
- repeated experience
- illness
- injury
- aging
- stress
- environmental change
- transformation
- canonical event

---

# HUMANIZATION CONTROL

Individual cognitive variation does not authorize human-level reasoning.
