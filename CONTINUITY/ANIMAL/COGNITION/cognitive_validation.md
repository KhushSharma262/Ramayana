# ANIMAL COGNITIVE VALIDATION

## PURPOSE

Validates cognitive state before approval.

---

# 1. SPECIES

Check:

- species capability
- sensory capability
- memory capability
- learning capability
- social cognition
- spatial cognition

---

# 2. INDIVIDUAL

Check:

- established cognitive identity
- learned associations
- recognition
- memories
- current attention

---

# 3. CAUSALITY

Check:

stimulus
? perception
? attention
? recognition
? processing
? decision
? behavior

---

# 4. MEMORY

Check:

- persistence
- decay
- reinforcement
- relevant previous events

---

# 5. LEARNING

Check:

- species capability
- learning mechanism
- reinforcement
- persistence

---

# 6. HUMANIZATION

Reject unsupported:

- human reasoning
- human language
- impossible planning
- impossible recognition
- instant learning
- unlimited memory

---

# 7. CANON

Verify extraordinary cognition against authority.

---

# 8. CONTINUITY

Compare:

previous cognitive state
? current event
? current cognitive state
? next state

---

# 9. AI ARTIFACTS

Check for:

- impossible recognition
- inconsistent memory
- unexplained intelligence
- human-like reasoning
- random cognitive state changes
- contradictory behavioral consequences
