# ANIMAL COGNITION AI INTERFACE

## Purpose

Defines how approved cognitive state is transferred to AI generation.

---

# ANIMAL SYSTEM OWNS

- species cognition
- individual cognition
- attention
- recognition
- memory
- learning
- expectations
- decision constraints
- social cognition
- spatial cognition
- canonical extraordinary abilities

---

# AI_GENERATION OWNS

- model
- model version
- seed
- generation parameters
- technical workflow
- output version
- regeneration history

---

# AI RECEIVES

- animal identity
- species cognitive baseline
- current cognitive state
- relevant memory
- learned associations
- attention target
- recognition state
- motivation
- behavioral intent
- cognitive constraints
- canonical exceptions
- negative constraints

---

# AI MUST NOT

- invent cognitive abilities
- erase memory
- create instant learning
- create impossible recognition
- create human-level reasoning
- create unsupported supernatural awareness
- change established cognition during regeneration

---

# REGENERATION

Regeneration is not a cognitive reset.
