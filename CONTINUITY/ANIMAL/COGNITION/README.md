# ANIMAL COGNITION

## Purpose

Animal Cognition defines how an animal processes information,
recognizes entities, attends to stimuli, remembers, learns,
anticipates, solves problems and makes species-appropriate decisions.

---

# SYSTEM BOUNDARIES

PERCEPTION
    What can the animal detect?

COGNITION
    How does the animal process what it detects?

BEHAVIOR
    What does the animal do?

PHYSIOLOGY
    What physical/neurological state constrains cognition?

INTERACTION
    What external interaction occurs?

PERFORMANCE
    How is approved cognition/behavior represented in a shot?

AI
    How is the approved state enforced during generation?

---

# MEMORY

Memory is:

- species-specific
- bounded
- variable
- persistent when established
- subject to biologically appropriate decay

---

# LEARNING

Learning is species-specific.

Not every animal receives every learning mechanism.

---

# DECISION-MAKING

Animals can make species-appropriate decisions without being treated
as miniature humans.

Biologically plausible mistakes are permitted.

---

# HUMANIZATION RULE

INTELLIGENCE ? HUMAN INTELLIGENCE.

Animals must not automatically receive:

- human language
- human moral reasoning
- human abstract reasoning
- human self-reflection
- human social conventions
- unlimited memory
- unlimited planning

---

# CONSCIOUSNESS

The system uses operational terms such as:

- awareness
- attention
- recognition
- memory
- learning
- decision

without making unsupported philosophical claims about subjective consciousness.

---

# DIVINE / MYTHOLOGICAL

Use:

BIOLOGICAL COGNITIVE BASELINE
+
CANONICAL EXCEPTION
+
SUPERNATURAL PROPERTY

Extraordinary cognition requires explicit authority.

---

# CONTINUITY

Cognition persists through:

frame
? shot
? scene
? sequence
? episode

when the underlying cognitive state persists.

---

# UNKNOWN

UNKNOWN remains UNKNOWN.

AI generation cannot turn unsupported cognition into canon.
