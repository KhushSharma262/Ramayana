# COGNITIVE DEVELOPMENT

## Purpose

Defines changes in cognition across development.

---

# STAGES

Where applicable:

- newborn
- juvenile
- adolescent
- adult
- mature
- elderly

---

# CHANGES

May include:

- attention
- recognition
- memory
- learning
- exploration
- social cognition
- problem-solving

---

# CONTINUITY

Cognitive development must be gradual where biology requires it.

---

# NO RESET

An older animal must not arbitrarily revert to juvenile cognitive
capability without a cause.
