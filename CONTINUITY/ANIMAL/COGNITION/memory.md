# MEMORY

## Purpose

Defines persistent and temporary animal memory.

---

# MEMORY TYPES

Where biologically supported:

- working / short-term memory
- long-term memory
- spatial memory
- associative memory
- social memory
- procedural / learned memory

---

# MEMORY STRENGTH

Each important memory may have:

memory_id:
source_event:
memory_type:
strength:
confidence:
age:
reinforcement_count:
decay_profile:
emotional_significance:
associated_entities:
associated_location:
associated_behavior:

---

# MEMORY DECAY

Memory may weaken over time where biologically appropriate.

---

# REINFORCEMENT

Repeated experiences may strengthen associations.

---

# SIGNIFICANT EVENTS

Major events may persist longer when species biology and evidence support it.

---

# CONTINUITY

Established memories must not disappear between scenes without cause.
