# COGNITIVE EFFECTS OF INJURY AND ILLNESS

## Purpose

Defines cognitive consequences of physiological change.

---

# POSSIBLE EFFECTS

Where supported:

- reduced attention
- altered recognition
- reduced learning
- memory disruption
- altered decision-making
- confusion
- reduced responsiveness

---

# CAUSALITY

Effects must correspond to actual physiological conditions.

---

# PERSISTENCE

Cognitive consequences persist according to recovery.

---

# BOUNDARY

PHYSIOLOGY defines the physical condition.

COGNITION defines its cognitive consequences.
