# COGNITIVE CONSTRAINTS

## Purpose

Defines hard boundaries preventing unsupported cognition.

---

# PROHIBITED BY DEFAULT

Do not automatically assign:

- human language
- human moral reasoning
- human abstract reasoning
- human self-reflection
- human social conventions
- human conversational logic
- unlimited memory
- unlimited planning
- perfect recognition
- instant learning
- supernatural knowledge

---

# EXCEPTION

An exception requires:

source
source_reference
evidence
classification
confidence

---

# CORE RULE

INTELLIGENCE ? HUMAN INTELLIGENCE.

ANIMAL COGNITION ? HUMAN COGNITION.
