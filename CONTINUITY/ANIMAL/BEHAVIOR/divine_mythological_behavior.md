# DIVINE AND MYTHOLOGICAL BEHAVIOR

## Purpose

Defines behavioral rules for extraordinary animals.

---

# BASE MODEL

BIOLOGICAL BEHAVIORAL BASELINE
+
CANONICAL EXCEPTION
+
SUPERNATURAL PROPERTY

---

# DIVINE ANIMALS

Retain plausible animal behavior unless canon establishes otherwise.

---

# EXTRAORDINARY PROPERTIES

May include, only when supported:

- extraordinary intelligence
- extraordinary loyalty
- supernatural awareness
- extraordinary obedience
- supernatural communication
- divine recognition
- unusual intentionality

---

# AUTHORITY

Each extraordinary property must be classified.

---

# NO AUTOMATIC MYTHOLOGIZATION

"Mythological" does not mean every behavior should become
dramatic, human-like or supernatural.
