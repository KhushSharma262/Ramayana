# ANIMAL LEARNING AND MEMORY

## Purpose

Defines species-appropriate learning and memory.

---

# MEMORY

Animal memory is bounded.

Do not assume unlimited human-like recall.

---

# LEARNING

Possible learned information:

- locations
- routes
- food sources
- predators
- threats
- handlers
- group members
- conditioned signals
- environmental dangers

only where species biology supports it.

---

# PERSISTENCE

Established learned behavior may persist across scenes and episodes.

---

# ASSOCIATION

Track:

stimulus
? association
? learned response
? persistence
? extinction/change

---

# TRAUMA

Persistent fear or avoidance may occur where biologically plausible.

---

# CANONICAL EXCEPTION

Extraordinary memory or intelligence requires explicit authority.
