# BEHAVIORAL EVENT

## Purpose

Defines events that cause behavioral transitions.

---

# EVENT MODEL

TRIGGER
? PERCEPTION
? INTERNAL STATE
? MOTIVATION
? ACTION
? CONSEQUENCE

---

# EVENT TYPES

Examples:

- predator detected
- food discovered
- injury
- human approach
- handler command
- offspring threatened
- territorial intrusion
- environmental disturbance
- group alarm
- mating event
- separation
- reunion
- training
- transformation

---

# EVENT CONTINUITY

Events must be recorded before their consequences are propagated.

---

# CAUSALITY

No major behavioral transition should appear without a recorded
cause, unless its cause is intentionally UNKNOWN.
