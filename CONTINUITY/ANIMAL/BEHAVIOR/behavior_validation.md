# ANIMAL BEHAVIOR QA

## PURPOSE

Validates animal behavior before approval.

---

# 1. SPECIES

Check:

- species appropriateness
- instincts
- social behavior
- feeding
- threat response

---

# 2. INDIVIDUAL

Check:

- identity
- temperament
- behavioral profile
- learned behavior
- established relationships

---

# 3. CAUSALITY

Check:

stimulus
? perception
? internal state
? motivation
? action
? consequence

---

# 4. PHYSIOLOGY

Check behavior against:

- age
- injury
- illness
- fatigue
- reproductive state
- physical capability

---

# 5. MEMORY

Check persistence of:

- training
- fear
- recognition
- previous encounters
- learned routes
- relationships

---

# 6. GROUP

Check:

- individual variation
- group state
- alarm propagation
- collective movement
- population density

---

# 7. REALISM

Reject:

- humanized gestures
- impossible intelligence
- impossible reactions
- random cinematic behavior
- identical repeated behavior
- species-inappropriate action

---

# 8. CONTINUITY

Compare:

previous state
? current event
? current behavior
? next state

---

# 9. CANON

Verify extraordinary behavior against authority.

---

# 10. STATUS

CONDITIONALLY_APPROVED
CHANGES_REQUIRED
