# PERCEPTION TO BEHAVIOR

## Purpose

Defines the causal connection between what an animal detects
and what it does.

---

# DETECTION

An animal may only react to a stimulus it could plausibly detect.

Detection depends on:

- species senses
- distance
- direction
- occlusion
- lighting
- sound
- scent
- vibration
- movement
- environmental conditions

---

# REACTION LATENCY

Behavior must account for species-appropriate reaction time.

---

# NON-REACTION

Non-reaction is a valid behavioral outcome.

An animal does not need to react merely because the audience
or camera can see a stimulus.
