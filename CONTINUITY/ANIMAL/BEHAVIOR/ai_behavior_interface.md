# ANIMAL BEHAVIOR AI INTERFACE

## Purpose

Defines the boundary between behavioral truth and AI generation.

---

# ANIMAL SYSTEM OWNS

- species behavior
- individual behavior
- behavioral state
- motivation
- behavioral history
- relationships
- learned behavior
- behavioral consequences
- canon
- biological constraints

---

# AI_GENERATION OWNS

- model
- generation parameters
- seed
- technical workflow
- generation implementation
- output version
- regeneration history

---

# AI MUST RECEIVE

- animal identity
- species
- current state
- previous state
- behavioral intent
- movement intent
- interaction state
- environment
- relevant memory
- canonical exceptions
- negative constraints
- variation limits

---

# AI MUST NOT

- invent major behavior
- erase behavioral history
- reset fear/training/injury effects
- humanize behavior without authorization
- change species behavior
- create impossible actions

---

# REGENERATION

Regeneration is not a behavioral reset.

Approved behavioral state remains authoritative.
