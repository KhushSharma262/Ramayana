# RETROACTIVE CORRECTION

Never silently rewrite history.

When an error is discovered:

1. Preserve original record.
2. Mark affected state.
3. Identify dependency chain.
4. Determine smallest affected repair scope.
5. Correct authoritative state.
6. Regenerate affected outputs.
7. Revalidate.
8. Propagate approved correction downstream.
9. Preserve audit trail.
