# INTERACTION MODEL

An interaction is a causal relationship between one or more humans and one or more animals.

Required conceptual sequence:

INITIATOR
→ APPROACH / PRESENCE
→ DETECTION
→ PERCEPTION
→ INTERPRETATION
→ INTERNAL STATE
→ RESPONSE
→ CONTACT / ACTION
→ CONSEQUENCE
→ PERSISTENCE

Not every interaction contains every stage.

An animal may:
- detect without reacting
- react before human recognition
- fail to detect
- detect but ignore
- approach voluntarily
- retreat
- resist
- cooperate
- respond with learned behavior

These are valid states and must not be normalized into generic reactions.
