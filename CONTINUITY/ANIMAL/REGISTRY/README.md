layer for the ANIMAL continuity architecture.

## ID Rule

Every important entity has a stable ID.

Replacement entities receive new IDs.

Versions receive separate version IDs.

Generated outputs receive output IDs.

These must never be conflated.

## History Rule

The Registry must preserve discoverability of:

active records
historical records
superseded records
replaced entities
deceased animals
dissolved groups
extirpated populations
rejected outputs
previous versions
invalidated references
old QA states

## Unknown Rule

UNKNOWN ≠ UNCHANGED.

A missing registry value must not be silently interpreted as a known value.

## AI Rule

Registering an AI output does not make it authoritative.

AI_GENERATION remains the technical generation system.

## QA Rule

Registry stores QA pointers and statuses.

QA remains authoritative for validation results.

## Final Authority

The Registry is the map of the continuity system.

It is not the continuity system itself.
