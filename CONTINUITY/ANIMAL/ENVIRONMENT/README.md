# ANIMAL / ENVIRONMENT

## Purpose

The Environment module defines the persistent physical world in which animals,
characters, props and events exist.

## Continuity Principle

Environment is not background art.

It is persistent world-state.

If a branch breaks, it remains broken.

If a wall is damaged, it remains damaged.

If a path becomes muddy, it remains muddy until a valid process changes it.

If a forest burns, later scenes inherit the burned state unless recovery,
replacement, rebuilding, transformation, or another canonical event changes it.

## Canon Principle

Canon defines what happened.

Research and scientific reconstruction explain unspecified mechanics.

Reconstruction must never be presented as direct scripture.
