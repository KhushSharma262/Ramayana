# ENVIRONMENT CORE

## Purpose

Environment defines the persistent physical world surrounding characters,
animals, props, locations and events.

Environment answers:

- What physically exists here?
- What material is it?
- What condition is it in?
- What environmental state currently exists?
- What changed it?
- What consequences remain?
- What should exist in the next shot?

Environment is not merely background scenery.

## Master Model

WORLD
→ REGION
→ LANDSCAPE
→ LOCATION
→ ENVIRONMENT_ZONE
→ MICRO_ENVIRONMENT
→ MATERIAL / OBJECT
→ STATE
→ EVENT
→ CONSEQUENCE
→ PERSISTENCE
→ RECOVERY / TRANSFORMATION
→ NEXT STATE

## Authority

The global CONTINUITY/state_ledger remains the ultimate continuity authority.

Environment provides environmental truth and interfaces with the global ledger.

## Canon Rule

DIRECT_CANON overrides reconstruction.

Canon defines what happened.

Scientific, biological, geological, climatological and historical knowledge may explain
how unspecified environmental mechanics could plausibly exist, but may not overwrite
explicit canonical events.

## Unknown Rule

UNKNOWN does not mean unchanged.

If environmental state is unknown, it remains explicitly unknown until supported.

## Continuity Principle

An environment is persistent world-state, not a newly generated background in every shot.
