# ENVIRONMENT CLASSIFICATION

Every environmental fact should be classified.

## Required Fields

- classification
- source
- source_reference
- evidence
- confidence
- interpretation
- uncertainty
- conflicting_sources
- production_decision

## Example

classification: ENVIRONMENTAL_RECONSTRUCTION

statement:
"The forest floor is moderately damp."

reason:
Required to create plausible physical continuity where the source does not specify
exact moisture conditions.

This must not be presented as direct scripture.
