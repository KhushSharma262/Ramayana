# ANIMAL ECOLOGY

## Purpose

Animal Ecology defines the ecological world surrounding animals.

It connects:

- habitat
- populations
- resources
- food webs
- predator/prey systems
- competition
- seasonality
- climate
- weather
- migration
- reproduction
- disease
- human disturbance
- landscape change
- long-term ecological consequences
