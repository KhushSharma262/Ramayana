# ANIMAL ECOLOGY

## Purpose

Defines the ecological systems surrounding animals and the
relationships between animals, populations, resources, habitats,
food webs, climate, seasonality, migration, disturbance and
long-term ecological consequences.

# CANON RULE

CANON DEFINES WHAT HAPPENED.

ECOLOGY / BIOLOGY EXPLAINS HOW UNSPECIFIED ECOLOGICAL MECHANICS
COULD PLAUSIBLY OCCUR.

Reconstruction must never silently become canon.
