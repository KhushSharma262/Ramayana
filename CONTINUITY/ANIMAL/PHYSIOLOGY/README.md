# ANIMAL / PHYSIOLOGY

## Purpose

Defines the current biological functioning and physical condition of an animal.

## Master Model

BASELINE
→ STIMULUS / EVENT
→ PHYSIOLOGICAL RESPONSE
→ STATE CHANGE
→ COMPENSATION
→ RECOVERY / ADAPTATION
→ NEXT STATE

## Core Principle

Physiology is continuous.

An injury does not disappear at a camera cut.

Fatigue does not disappear because the animal is regenerated.

Pregnancy does not reset.

Healing progresses.

Illness progresses.

Age progresses.

Hydration and energy change according to events and biological timescales.

## Multiple States

Animals can have simultaneous states.

Example:

HEALTHY
+ FATIGUED
+ MILDLY_DEHYDRATED
+ INJURED
+ RECOVERING

Do not collapse these into one label.

## Timescale Principle

Physiological processes operate on different timescales.

Frame-level visual continuity must not be confused with biological timescale.

## Canon

Canon overrides reconstruction.

Biology and veterinary science reconstruct unspecified mechanics.

Every reconstruction must be explicitly classified.

## AI Principle

AI output never defines physiological truth.

Approved physiological continuity controls generation.

AI regeneration is not a biological reset.
