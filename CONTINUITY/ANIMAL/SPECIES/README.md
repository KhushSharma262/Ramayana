# ANIMAL / SPECIES

## Purpose

Defines the species-level identity and biological/canonical baseline for all
animal continuity.

## Master Model

SPECIES IDENTITY
→ CLASSIFICATION
→ TAXONOMIC / TRADITIONAL IDENTIFICATION
→ BIOLOGICAL BASELINE
→ MORPHOLOGY / ANATOMY
→ PHYSIOLOGY
→ LIFECYCLE
→ BEHAVIOR
→ COGNITION
→ PERCEPTION
→ LOCOMOTION
→ ECOLOGY
→ HABITAT
→ DISTRIBUTION
→ SPECIES CONSTRAINTS
→ POPULATION / GROUP / INDIVIDUAL

## Critical Boundary

SPECIES = what kind of animal it is.

POPULATION = local population state.

GROUP = social group.

INDIVIDUAL = specific animal.

ANATOMY = physical structure.

PHYSIOLOGY = current biological function.

BEHAVIOR = observable behavior.

COGNITION = information processing.

PERCEPTION = sensory access.

LOCOMOTION = movement mechanics.

ECOLOGY = ecological relationships.

## Canon Rule

Canon has highest authority for explicit canonical facts.

Biology explains unspecified mechanics.

Historical research may reconstruct historical identity.

Traditional commentary may clarify interpretation.

Visual reconstruction may translate evidence into production appearance.

These must remain explicitly classified.

## Identification Rule

Do not assume that a Sanskrit or traditional animal name maps perfectly to a
modern scientific species.

Where identification is uncertain, preserve:

candidate species
evidence
alternative interpretations
confidence
unknowns

## AI Rule

AI_GENERATION implements species truth.

It does not determine species truth.

AI output cannot redefine species identity merely because it looks plausible.

## Divine / Mythological Rule

BIOLOGICAL BASELINE
+
CANONICAL EXCEPTION
+
SUPERNATURAL PROPERTY

Mythological status alone does not authorize arbitrary biological features.

## Continuity Rule

Once a species identity is approved, all dependent Animal systems inherit it
until an authorized correction or transformation occurs.
