# SPECIES DOMAIN BOUNDARY

SPECIES:
What biological or canonical animal type is this?

POPULATION:
What is the state of this population?

GROUP:
What social group exists?

INDIVIDUAL:
Which particular animal is this?

ANATOMY:
What physical structure does this animal have?

PHYSIOLOGY:
What is its current biological functioning?

BEHAVIOR:
What does this animal do?

COGNITION:
How does it process information?

PERCEPTION:
What can it detect?

LOCOMOTION:
How does it move?

ECOLOGY:
How does it interact with its ecosystem?

ENVIRONMENT:
What physical surroundings exist?

AI_GENERATION:
How is the species technically represented?

Species provides the baseline to these systems without replacing them.
