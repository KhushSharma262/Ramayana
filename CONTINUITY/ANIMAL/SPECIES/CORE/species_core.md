# ANIMAL SPECIES CORE

## Purpose

Defines the authoritative species-level biological, taxonomic, canonical,
historical and continuity baseline used by all Animal systems.

## Master Model

SPECIES IDENTITY
→ CLASSIFICATION
→ TAXONOMIC / TRADITIONAL IDENTIFICATION
→ BIOLOGICAL BASELINE
→ MORPHOLOGY / ANATOMY
→ PHYSIOLOGY
→ LIFECYCLE
→ BEHAVIOR
→ COGNITION
→ PERCEPTION
→ LOCOMOTION
→ ECOLOGY
→ HABITAT
→ DISTRIBUTION
→ SPECIES-SPECIFIC CONSTRAINTS
→ POPULATION / GROUP / INDIVIDUAL INSTANCES

## Core Principle

SPECIES defines what kind of animal something is.

It does not define the current state of an individual animal.
