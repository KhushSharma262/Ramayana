# CANON VS RECONSTRUCTION QA

Every important species attribute must be classified.

Example:

DIRECT_CANON
→ explicit textual description

BIOLOGICAL_RECONSTRUCTION
→ inferred anatomy from known biology

HISTORICAL_RECONSTRUCTION
→ inferred species from historical geography

VISUAL_RECONSTRUCTION
→ production appearance chosen from evidence

DIRECTORIAL_CHOICE
→ deliberate cinematic decision

UNKNOWN
→ insufficient evidence

Never merge these categories silently.
