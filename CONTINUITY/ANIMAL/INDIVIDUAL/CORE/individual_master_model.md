# INDIVIDUAL MASTER MODEL

Every principal individual should be representable as:

animal_id
species_id
population_id
group_id
identity_status
classification
age_state
sex_state
appearance_state
anatomy_reference
health_state
location_state
movement_reference
relationship_state
cognitive_reference
behavior_reference
equipment_reference
memory_reference
history_reference
transformation_state
current_state
previous_state
next_state

The record must preserve causal continuity.

State is never silently reset because a new shot, scene, prompt or generation begins.
