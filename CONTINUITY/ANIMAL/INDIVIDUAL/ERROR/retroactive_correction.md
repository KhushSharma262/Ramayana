# RETROACTIVE CORRECTION

Never silently rewrite an individual's history.

Procedure:

1. Preserve original record.
2. Mark incorrect state.
3. Identify dependency chain.
4. Determine smallest affected scope.
5. Correct authoritative state.
6. Repair affected downstream records.
7. Regenerate affected outputs.
8. Revalidate.
9. Propagate approved correction.
10. Preserve audit history.
