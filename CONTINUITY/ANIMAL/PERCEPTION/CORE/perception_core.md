# ANIMAL PERCEPTION CORE

## Purpose

Defines what an animal can detect, how detection occurs, what affects
sensory access, and how perceptual state persists through continuity.

## Master Model

STIMULUS
→ SENSORY ACCESS
→ DETECTION
→ ATTENTION
→ RECOGNITION INTERFACE
→ COGNITIVE PROCESSING

Perception does NOT determine:

meaning
intention
decision
behavior

Those belong to COGNITION and BEHAVIOR.

## Core Principle

An animal can only respond to what it could plausibly perceive,
unless canonically granted an extraordinary perceptual capability.

## Authority

Global STATE_LEDGER remains ultimate continuity authority.

COGNITION owns interpretation.

PERCEPTION owns sensory access and detection.
