# ANIMAL / PERCEPTION

## Purpose

Defines what an animal can sense and what it actually detects in a given
physical and temporal context.

## Master Model

STIMULUS
→ SENSORY ACCESS
→ DETECTION
→ ATTENTION
→ RECOGNITION INTERFACE
→ COGNITION

## Critical Distinctions

CAPABILITY ≠ DETECTION

DETECTION ≠ RECOGNITION

RECOGNITION ≠ UNDERSTANDING

UNDERSTANDING ≠ RESPONSE

NON-DETECTION ≠ IGNORANCE

UNKNOWN ≠ UNCHANGED

## Core Rule

An animal cannot react to information that it could not plausibly perceive,
unless an authoritative canonical or supernatural capability establishes
otherwise.

## Canon

Canon overrides biological reconstruction.

Biology explains unspecified sensory mechanics.

Extraordinary perception requires explicit authority.

## AI Principle

AI must not invent:

impossible sight
impossible hearing
wrong gaze
wrong attention
reaction to unavailable stimuli
species-inappropriate senses
telepathic-looking behavior
or perceptual state resets.

Approved continuity state controls generation.
