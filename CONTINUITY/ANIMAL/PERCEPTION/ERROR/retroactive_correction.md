# RETROACTIVE CORRECTION

Never silently rewrite perception history.

Procedure:

1. Preserve original record.
2. Identify incorrect perceptual assumption.
3. Determine affected dependency chain.
4. Correct authoritative state.
5. Repair cognition/behavior/event dependencies.
6. Regenerate affected outputs.
7. Revalidate.
8. Propagate approved correction.
9. Preserve audit trail.
