# ANIMAL STATE CORE

## Purpose

Defines the complete current state of an animal or animal-related entity at a
specific point in continuity.

STATE is the central representation of what is true NOW.

## Master Model

IDENTITY
→ BASELINE
→ PREVIOUS STATE
→ EVENT / STIMULUS
→ STATE DELTA
→ CURRENT STATE
→ CONSEQUENCES
→ PERSISTENCE
→ NEXT STATE

## Core Principle

State is not appearance alone.

A state may contain simultaneously:

physical
physiological
cognitive
perceptual
behavioral
social
spatial
temporal
environmental
ecological
interaction
equipment
performance
audio
lighting
physics
knowledge
transformation

## State Does

State records the current condition produced by established causes.

## State Does Not

State does not replace:

identity
species
event
timeline
physics
performance
AI generation
QA

It coordinates their current consequences.
