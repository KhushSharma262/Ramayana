# STATE DOMAIN BOUNDARY

STATE answers:

WHAT IS TRUE ABOUT THE ANIMAL RIGHT NOW?

EVENT answers:

WHAT HAPPENED?

PHYSIOLOGY answers:

HOW IS THE BODY FUNCTIONING?

COGNITION answers:

HOW IS INFORMATION BEING PROCESSED?

BEHAVIOR answers:

WHAT IS THE ANIMAL DOING?

PERFORMANCE answers:

HOW IS THE ESTABLISHED STATE BEING EXPRESSED?

SPATIAL answers:

WHERE IS IT?

TIME answers:

WHEN IS THIS STATE VALID?

STATE connects these without replacing them.
