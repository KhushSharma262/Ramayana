# ANIMAL / STATE

## Purpose

STATE is the central current-condition layer for the Animal continuity system.

## Master Model

IDENTITY
→ BASELINE
→ PREVIOUS STATE
→ EVENT / STIMULUS
→ STATE DELTA
→ CURRENT STATE
→ CONSEQUENCES
→ PERSISTENCE
→ NEXT STATE

## Critical Distinctions

IDENTITY
= who the animal is

STATE
= what condition it is currently in

EVENT
= what happened

PHYSIOLOGY
= how the body is functioning

BEHAVIOR
= what the animal does

PERFORMANCE
= how the state is visibly expressed

TIME
= when the state is valid

SPATIAL
= where the state exists

## Multiple States

Animals can have multiple simultaneous states.

Example:

MOVING
+
INJURED
+
FATIGUED
+
STRESSED
+
WET
+
EQUIPMENT_ATTACHED

These are not contradictory simply because they are simultaneous.

## Persistence

Established states persist until:

a valid event changes them
biological recovery changes them
time changes them
transformation changes them
canon changes them

AI regeneration does not reset state.

## Unknown

UNKNOWN ≠ UNCHANGED.

Missing information must remain unknown.

## State Ledger

Global CONTINUITY/state_ledger remains the ultimate continuity authority.

This domain provides structured Animal state representation and interfaces.

## AI

AI_GENERATION implements state.

It does not create state truth.

## Final Principle

Every frame, shot, scene and episode must inherit the correct approved animal
state unless an explicit causal transition occurs.
