## System boundary

ANIMAL/AUDIO defines animal-specific audio truth.

CONTINUITY/AUDIO defines the global audio system.

AI_GENERATION defines technical AI generation and model/parameter control.

Animal Audio must not create competing global audio or AI-generation systems.

## Canon rule

Explicit canon has priority.

Biological knowledge may reconstruct unspecified animal sounds.

Reconstruction must never be presented as direct canon.

## Identity rule

Important animals may have persistent audio identity.

Natural variation is allowed.

Identity drift is not.

## Silence rule

Animals do not continuously vocalize.

Silence is a valid state.

## Spatial rule

Animal sound sources exist in world space, not merely in camera space.

## Human speech rule

Ordinary animals do not produce human-language speech unless explicitly
supported by canon.

Divine/mythological exceptions require authority classification.

## Final principle

The correct animal sound is not simply a realistic sound.

It must be the sound of:

THE CORRECT SPECIES
+
THE CORRECT INDIVIDUAL
+
THE CORRECT STATE
+
THE CORRECT EVENT
+
THE CORRECT ENVIRONMENT
+
THE CORRECT SPATIAL POSITION
+
THE CORRECT POINT IN TIME.
