# ANIMAL CORE AI BOUNDARY

## ANIMAL OWNS

Animal truth:

- identity
- species
- state
- anatomy
- physiology
- cognition
- behavior
- relationships
- history
- knowledge
- transformation
- canonical exceptions

---

# AI_GENERATION OWNS

Technical generation:

- model
- model version
- parameters
- seed
- prompts
- references
- generation history
- regeneration history
- output version

---

# CORE OUTPUT TO AI

AI_GENERATION may consume:

- approved identity
- current state
- persistent state
- dependencies
- variation limits
- negative constraints
- domain requirements
- canonical exceptions
- approved references

---

# GENERATED OUTPUT

Generated output is not automatically Animal truth.

It must pass validation and approval.

---

# REGENERATION

Regeneration does not authorize:

- identity reset
- state reset
- history deletion
- relationship reset
- knowledge reset
- behavioral reset
- cognitive reset

unless explicitly authorized.

---

# MODEL CHANGE

Changing AI models does not itself authorize Animal continuity changes.
