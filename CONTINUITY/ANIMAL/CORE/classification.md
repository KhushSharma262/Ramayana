# ANIMAL CLASSIFICATION

## PURPOSE

Defines the broad ontological classification of an animal.

---

# CLASSIFICATIONS

ORDINARY
DOMESTIC
WILD
MYTHOLOGICAL
DIVINE
SUPERNATURAL
TRANSFORMED
UNKNOWN

---

# RULE

Classification is not identity.

A divine animal still has an animal identity.

A transformed animal retains lineage while its transformed
state is separately recorded.

---

# VERSIONING

Classification changes must be:

- recorded
- sourced
- versioned
- validated
- propagated to dependent domains
