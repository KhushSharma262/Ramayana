# ANIMAL REFERENCE INTERFACE

## PURPOSE

Defines how Animal CORE consumes external authoritative references.

---

# REFERENCE TYPES

- canonical text
- commentary
- traditional source
- biological research
- historical research
- previous approved output
- technical reference
- production reference

---

# ATTRIBUTE-SCOPED AUTHORITY

A reference may control:

- species
- behavior
- anatomy
- appearance
- historical use
- environment
- equipment
- transformation

without controlling unrelated attributes.
