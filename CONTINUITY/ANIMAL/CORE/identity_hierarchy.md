# SPECIES

Defines species-level identity.

---

# POPULATION

Defines geographically/ecologically/socially relevant population.

---

# GROUP

Defines temporary or persistent social grouping.

---

# INDIVIDUAL

Defines one identifiable animal.

---

# STATE

Defines the animal's current condition.

---

# GLOBAL ID

Every trackable individual receives:

animal_id

The ID remains stable throughout the animal's existence.

---

# APPEARANCE

Appearance may change without changing identity.

---

# REPLACEMENT

A replacement animal receives a new animal_id.

---

# TRANSFORMATION

Transformation normally preserves identity while creating a
new form/state lineage.

Canon may override this rule.
