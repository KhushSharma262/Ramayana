# ANIMAL MASTER REGISTRY INTERFACE

## PURPOSE

Provides the master registry contract for Animal entities.

---

# REGISTRY MUST MAP

- species
- populations
- groups
- individuals
- states
- relationships
- events
- transformations
- replacements
- dependencies
- approvals

---

# ID STABILITY

Assigned IDs remain stable.

---

# RETIRED ENTITIES

Retired/deceased entities remain historically traceable.

---

# REGISTRY RULE

Deletion from active production does not equal deletion from history.
