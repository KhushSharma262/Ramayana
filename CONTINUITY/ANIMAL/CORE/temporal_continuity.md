# ANIMAL TEMPORAL CONTINUITY

## MULTIPLE CLOCKS

Track where relevant:

WORLD TIME
STORY TIME
SCENE TIME
SHOT TIME
FRAME TIME
ANIMAL AGE
TIME SINCE EVENT
TIME IN CURRENT STATE
TIME SINCE LAST INTERACTION

---

# AGE

Animal age is persistent.

It must not be recalculated independently by each shot.

---

# STATE DURATION

Important states may track duration.

---

# EVENT TIME

Every significant event retains its temporal position.

---

# QUERY

Later scenes must be able to determine:

- what happened before
- when it happened
- how long ago it happened
- what state followed it

---

# TIME CONSISTENCY

A later scene cannot contradict an established earlier event
without an explicit correction or canonical exception.
