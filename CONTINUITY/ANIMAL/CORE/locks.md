# ANIMAL CONTINUITY LOCKS

## PURPOSE

Defines common lock behavior.

---

# LOCK LEVELS

ABSOLUTE
STRONG
CONTROLLED
VARIABLE
UNKNOWN
NOT_APPLICABLE

---

# ABSOLUTE

Cannot change without explicit authorized exception.

---

# STRONG

Change requires explicit approval and dependency validation.

---

# CONTROLLED

May change under defined conditions.

---

# VARIABLE

Natural variation is permitted.

---

# UNKNOWN

No authoritative value is established.

---

# NOT_APPLICABLE

Attribute does not apply.

---

# COMMON LOCK TARGETS

Identity:
ABSOLUTE / STRONG

Species:
ABSOLUTE

Persistent state:
STRONG

Natural posture variation:
VARIABLE

Breathing:
VARIABLE

Micro-movement:
VARIABLE

Historical event:
ABSOLUTE

Canonical fact:
ABSOLUTE
