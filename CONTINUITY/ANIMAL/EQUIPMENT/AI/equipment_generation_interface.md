# EQUIPMENT GENERATION INTERFACE

Required inputs:

- equipment_id
- type
- current state
- previous state
- attachment
- animal identity
- species
- fit
- dimensions
- material
- components
- damage
- repair
- ownership
- environment
- movement constraints
- physics constraints
- canon constraints
- approved references
- variation limits

Each field should be marked:

PRESERVE
CHANGE
UNKNOWN
NOT_APPLICABLE
