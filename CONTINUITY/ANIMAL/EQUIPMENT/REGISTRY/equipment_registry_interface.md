# EQUIPMENT REGISTRY INTERFACE

Tracks:

- equipment_id
- equipment_type
- animal_id
- owner_id
- possessor_id
- prop_id where applicable
- weapon_id where applicable
- current state
- lifecycle
- attachment
- condition
- version
- damage
- repair
- location
- approval
- dependencies

Registry references authoritative state.

It does not replace the global state ledger.
