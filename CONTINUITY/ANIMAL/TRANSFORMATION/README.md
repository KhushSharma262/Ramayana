# ANIMAL / TRANSFORMATION

## Purpose

Defines extraordinary or structural changes in an animal's form, identity,
biology or nature while preserving complete continuity.

## Master Model

PRE-FORM
→ PRECONDITION
→ TRIGGER
→ CAUSE
→ TRANSFORMATION EVENT
→ TRANSITION
→ NEW FORM
→ NEW STATE
→ CONSEQUENCES
→ PERSISTENCE
→ REVERSAL / FINAL STATE

## Critical Identity Rule

A transformed entity may retain the same identity.

But this must be established.

Visual resemblance alone is not enough.

Possible outcomes:

SAME_IDENTITY
NEW_IDENTITY
IDENTITY_UNKNOWN
IDENTITY_SPLIT
IDENTITY_MERGED
REPLACEMENT
REBIRTH_WITH_CONTINUITY
REBIRTH_WITH_NEW_IDENTITY

## Canon Rule

Canon overrides reconstruction.

Traditional commentary is not automatically base-text fact.

Historical and biological research may reconstruct unspecified mechanics.

Every reconstruction is explicitly classified.

## Divine / Mythological Rule

BIOLOGICAL BASELINE
+
CANONICAL EXCEPTION
+
SUPERNATURAL PROPERTY

Mythological appearance alone does not authorize arbitrary supernatural
transformation.

## Persistence Rule

Completion of a transformation establishes a new persistent form/state.

Reversal is a separate event.

Reversal does not automatically restore every previous consequence.

## AI Rule

AI_GENERATION renders the transformation.

It does not decide that a transformation occurred.

Regeneration does not create a new transformation.

## Final Principle

Transformation is a causal continuity event, not merely a visual effect.
