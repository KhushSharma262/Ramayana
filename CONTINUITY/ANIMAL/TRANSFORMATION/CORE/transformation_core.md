# ANIMAL TRANSFORMATION CORE

## Purpose

Defines extraordinary or structural changes in an animal's form, identity,
biology, state or nature.

Transformation is a controlled continuity event.

It is NOT ordinary:

aging
growth
weight change
injury
healing
grooming
seasonal appearance
natural variation
temporary posture
lighting change
costume/equipment change

## Master Model

PRE-TRANSFORMATION IDENTITY
→ PRECONDITION
→ TRIGGER
→ CAUSE
→ TRANSFORMATION EVENT
→ TRANSITION STATE
→ NEW FORM
→ NEW STATE
→ CONSEQUENCES
→ PERSISTENCE
→ REVERSAL / FINAL STATE

## Core Principle

Transformation must have a cause and an authoritative basis.

A visually different AI output is not evidence that transformation occurred.

## Critical Rule

Transformation does not automatically destroy identity.

Identity continuity must be explicitly determined.
