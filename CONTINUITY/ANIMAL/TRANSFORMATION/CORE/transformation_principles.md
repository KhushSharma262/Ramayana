# TRANSFORMATION PRINCIPLES

1. Transformation requires an identifiable transition.
2. Ordinary variation is not transformation.
3. Transformation must have a trigger or explicitly unknown cause.
4. Canon has highest authority.
5. Biology cannot overwrite explicit canon.
6. Visual change alone does not establish transformation.
7. Identity continuity must be determined.
8. Pre-transformation state must be preserved.
9. Post-transformation state must be preserved.
10. Reversal is a separate event.
11. Regeneration is never a transformation.
12. AI model changes do not create transformation.
