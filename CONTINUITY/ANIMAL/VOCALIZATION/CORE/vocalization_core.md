# ANIMAL VOCALIZATION CORE

Vocalization defines the animal's biologically, canonically, or otherwise
authoritatively supported sound-producing behavior.

MASTER MODEL:

VOCAL ANATOMY
→ PHYSIOLOGICAL STATE
→ INTERNAL STATE
→ PERCEPTION
→ MOTIVATION
→ VOCAL DECISION
→ VOCAL PRODUCTION
→ SOUND
→ ACOUSTIC PROPAGATION
→ PERCEPTION BY RECEIVER
→ RESPONSE
→ CONSEQUENCE
→ PERSISTENCE

Vocalization is not merely an audio file.

The generated sound must correspond to:

species
individual
age
sex where relevant
health
emotional state
social context
environment
distance
movement
event
time
transformation state
