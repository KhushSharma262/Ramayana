# ANIMAL / POPULATION

## Purpose

Defines the persistent state, structure, distribution and continuity of an
animal population.

## Master Model

SPECIES
→ POPULATION IDENTITY
→ DISTRIBUTION
→ DEMOGRAPHICS
→ RESOURCES / ENVIRONMENT
→ BIRTHS / DEATHS / MOVEMENT
→ POPULATION CHANGE
→ GROUPS / INDIVIDUALS
→ ECOLOGICAL CONSEQUENCES
→ NEXT POPULATION STATE

## Critical Distinctions

SPECIES
= biological species baseline

POPULATION
= population-level biological and continuity state

GROUP
= social aggregation

INDIVIDUAL
= specific animal

ECOLOGY
= organism/environment relationships

ENVIRONMENT
= physical surroundings

## Population Count Rule

Do not invent exact numbers.

Use:

exact
estimate
range
minimum
maximum
qualitative
unknown

according to evidence.

## Continuity

Population state persists through:

birth
death
migration
dispersal
disease
predation
resource change
environmental change
human interaction
seasonal change
group turnover
individual turnover

## Population vs Visual Crowd

A generated crowd does not establish:

population size
demographic structure
species distribution
canonical population count

Those must come from continuity state.

## Canon

Canon overrides reconstruction.

Biology, ecology and historical research may reconstruct unspecified details.

Every reconstruction must be classified.

## Divine / Mythological

BIOLOGICAL POPULATION BASELINE
+
CANONICAL EXCEPTION
+
SUPERNATURAL PROPERTY

Mythological setting alone does not justify impossible population behavior.

## AI Principle

AI generation implements population state.

It does not create population truth.

Regeneration is not a population reset.
