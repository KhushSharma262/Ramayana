# RETROACTIVE CORRECTION

Never silently rewrite population history.

Procedure:

1. Preserve original state.
2. Identify error.
3. Identify authoritative evidence.
4. Determine affected dependency chain.
5. Correct population state.
6. Repair group/individual/ecology dependencies.
7. Regenerate affected outputs.
8. Revalidate.
9. Approve.
10. Preserve audit trail.
