# ANIMAL POPULATION CORE

## Purpose

Defines the persistent state and continuity of a population of animals
belonging to a defined species or population unit.

## Master Model

SPECIES
→ POPULATION IDENTITY
→ DISTRIBUTION
→ DEMOGRAPHICS
→ RESOURCES / ENVIRONMENT
→ BIRTHS / DEATHS / MOVEMENT
→ POPULATION CHANGE
→ GROUPS / INDIVIDUALS
→ ECOLOGICAL CONSEQUENCES
→ NEXT POPULATION STATE

## Core Principle

A population is not merely a visual collection of animals.

It is a persistent biological and continuity entity.

## Boundary

SPECIES = biological species baseline.

POPULATION = population-level state.

GROUP = social aggregation.

INDIVIDUAL = specific animal identity.

ECOLOGY = broader organism/environment relationships.

ENVIRONMENT = physical surroundings.

Population must not duplicate these systems.
