# ANIMAL PERFORMANCE CORE

## Purpose

Defines how an animal's established identity, state, perception, cognition,
behavior, physiology, locomotion and interaction are physically expressed
within a shot, scene and sequence.

PERFORMANCE is the representation layer.

It does not redefine what the animal is.

## Master Model

CONTINUITY STATE
→ PERFORMANCE INTENT
→ BODY EXPRESSION
→ MICRO-ACTIONS
→ MOVEMENT
→ REACTION
→ INTERACTION
→ SHOT REPRESENTATION
→ NEXT PERFORMANCE STATE

## Performance Principle

The animal must behave as a continuous living individual rather than as
a collection of disconnected generated poses.

## Authority

Global STATE_LEDGER remains ultimate continuity authority.

PERFORMANCE translates authoritative state into observable performance.

AI_GENERATION implements the approved performance technically.
