# RETROACTIVE CORRECTION

Never silently rewrite performance history.

Procedure:

1. Preserve original.
2. Identify error.
3. Identify authoritative source.
4. Determine affected dependencies.
5. Correct state.
6. Repair performance.
7. Regenerate affected outputs.
8. Revalidate.
9. Propagate approved correction.
10. Preserve audit trail.
