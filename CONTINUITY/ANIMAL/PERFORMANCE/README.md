# ANIMAL / PERFORMANCE

## Purpose

Performance defines how an animal's established continuity state is expressed
as a living, observable performance inside a scene, shot and frame.

## Master Model

CONTINUITY STATE
→ PERFORMANCE REQUIREMENTS
→ BODY EXPRESSION
→ MICRO-ACTIONS
→ MOVEMENT
→ REACTION
→ CONSEQUENCE
→ NEXT PERFORMANCE STATE

## Performance Is Not Identity

Performance does not redefine:

animal identity
species
anatomy
physiology
cognition
behavior
locomotion
interaction
group state
environment
physics

It represents their current state.

## Human-Realism Principle

A convincing animal must appear alive.

Important cues include:

breathing
eye movement
blinking where applicable
attention
gaze
head movement
ear movement
tail movement
weight shifts
balance corrections
muscle tension
inertia
reaction latency
micro-movements
fatigue
injury
environmental response

## Continuity

Across frames and shots preserve:

identity
current state
posture
gaze
movement phase
breathing
attention
interaction
equipment
injury
fatigue
environment
lighting
audio
spatial relationships

## Natural Variation

Continuity does not mean pixel-identical performance.

Natural variation is permitted within:

species
anatomy
current state
physiology
behavior
locomotion
environment
interaction

## Core Boundary

PERFORMANCE
= how the established state is expressed.

AI_GENERATION
= how that performance is technically generated.

The prompt is not the source of truth.

## Canon

Canon overrides reconstruction.

Biology and behavioral science may reconstruct unspecified details.

Reconstruction must be explicitly classified.

## Critical AI Rule

Never regenerate an animal as a disconnected pose.

Every generated performance must inherit the authoritative previous state
and produce a valid next state.
