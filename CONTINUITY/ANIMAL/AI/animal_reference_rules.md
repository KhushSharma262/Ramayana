# ANIMAL REFERENCE RULES

## Purpose

Defines how references are used when generating animals.

---

# 1. REFERENCE IS NOT AUTOMATICALLY TRUTH

An image, video, artwork, previous AI output, photograph,
3D model, illustration, or internet reference is not automatically canonical.

Each reference must have an authority and purpose.

---

# 2. REFERENCE ROLES

Possible roles:

- identity reference
- species reference
- anatomy reference
- behavior reference
- movement reference
- environment reference
- historical reference
- costume/equipment reference
- lighting reference
- camera reference
- visual style reference
- previous-output reference
- technical reference

---

# 3. ATTRIBUTE-SCOPED AUTHORITY

One reference may be authoritative for anatomy but not appearance.

Another may be authoritative for movement but not identity.

Another may establish historical equipment but not species.

Authority must therefore be recorded per attribute or domain.

---

# 4. CANONICAL REFERENCE

Canonical textual or traditional sources take priority over visual references
when establishing canonical facts.

Visual references may assist visual reconstruction.

---

# 5. BIOLOGICAL REFERENCE

Scientific zoological references may be used to reconstruct unspecified:

- anatomy
- movement
- physiology
- behavior
- ecology
- sensory capabilities

They must remain classified as biological/scientific reconstruction.

---

# 6. HISTORICAL REFERENCE

Historical references may reconstruct:

- domestication
- animal use
- equipment
- regional breeds/types
- husbandry
- historical environment

They must not be presented as direct Ramayana canon unless explicitly supported.

---

# 7. PREVIOUS AI OUTPUT

Previous AI output is not automatically authoritative.

Only validated elements may propagate.

---

# 8. CONFLICT

If references conflict:

1. identify conflict
2. identify authority of each reference
3. determine attribute scope
4. preserve unresolved conflict if necessary
5. obtain production decision when required

Do not silently average conflicting references.

---

# 9. REFERENCE CONTAMINATION

A reference must not introduce:

- wrong species
- modern equipment
- modern anatomy
- fantasy anatomy
- inappropriate coloration
- incorrect scale
- modern environmental features
- anthropomorphic behavior

unless intentionally approved.

---

# 10. REFERENCE VALIDATION

Before use, validate:

- identity compatibility
- species compatibility
- anatomy compatibility
- historical compatibility
- canon compatibility
- temporal compatibility
- visual compatibility
- continuity compatibility

---

# 11. REFERENCE INHERITANCE

A generated output may inherit only those reference attributes
that have been explicitly validated.

---

# 12. REFERENCE EXPIRATION

A reference may become invalid if:

- the animal changes state
- the animal ages
- equipment changes
- injury occurs
- transformation occurs
- the reference is discovered to be incorrect
- the source is superseded

Historical use must remain recorded.
