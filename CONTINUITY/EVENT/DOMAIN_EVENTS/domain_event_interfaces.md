# DOMAIN EVENT INTERFACES

EVENT coordinates state changes owned by:

- CHARACTER
- ANIMAL
- COSTUME
- PROP
- WEAPON
- EQUIPMENT
- LOCATION
- ENVIRONMENT
- SPATIAL
- PERFORMANCE
- PHYSIOLOGY
- COGNITION
- BEHAVIOR
- ECOLOGY
- TRANSFORMATION
- TIMELINE
- AUDIO
- LIGHTING
- CAMERA
- VFX

Each domain retains ownership of its own truth.

EVENT records causal occurrence and state transition.
