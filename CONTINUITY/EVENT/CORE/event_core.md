# EVENT CORE

## Purpose

EVENT is the global causal continuity system.

An Event represents something that happens and explains how one valid state
becomes another valid state.

## Fundamental Rule

STATE
→ EVENT
→ STATE CHANGE

Events explain state changes.

Events do not replace the domain that owns the resulting state.

Example:

EVENT:
"Arrow strikes warrior."

PHYSIOLOGY owns:
injury state.

COSTUME owns:
garment damage.

ENVIRONMENT owns:
blood/residue on environment.

PERFORMANCE owns:
visible reaction.

EVENT coordinates the causal relationship.
