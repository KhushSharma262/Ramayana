# EVENT MASTER MODEL

## Causal Model

CAUSE
→ EVENT
→ EFFECT
→ CONSEQUENCE
→ STATE CHANGE
→ PERSISTENCE
→ NEXT STATE

## Event Principle

An Event is not simply an action visible on screen.

It may be:

- physical
- biological
- psychological
- social
- environmental
- ecological
- supernatural
- narrative
- cinematic
- production-related

Only in-world Events alter world state.

Production Events alter production records, not story chronology.

## No Silent State Changes

If an important state changes, the system should identify the Event
responsible for the change.

If no Event can be identified, the change is flagged for investigation.
