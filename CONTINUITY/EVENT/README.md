# CONTINUITY / EVENT

## Purpose

EVENT is the global causal continuity system.

It answers:

WHAT HAPPENED?

WHY DID IT HAPPEN?

WHO / WHAT WAS INVOLVED?

WHAT CHANGED?

WHAT CONSEQUENCES FOLLOWED?

WHAT REMAINS TRUE AFTERWARD?

## Fundamental Model

PREVIOUS STATE
→ EVENT
→ STATE DELTA
→ RESULTING STATE
→ CONSEQUENCES
→ PERSISTENCE
→ NEXT STATE

## Critical Rule

EVENT explains state change.

EVENT does not own every resulting state.

Examples:

PHYSIOLOGY owns injury.

COSTUME owns garment damage.

ENVIRONMENT owns environmental damage.

EQUIPMENT owns equipment damage.

ANIMAL owns animal reaction.

EVENT coordinates why those changes occurred.

## Event Categories

WORLD_EVENT
STORY_EVENT
CINEMATIC_EVENT
PRODUCTION_EVENT

These must remain distinct.

A camera cut does not create a world event.

An AI regeneration does not create a story event.

A flashback references a historical event.

## Causal Principle

CAUSE
→ EVENT
→ EFFECT
→ CONSEQUENCE
→ STATE CHANGE

## Event Identity

One actual story Event retains one identity even when shown through:

- multiple shots
- multiple scenes
- multiple episodes
- flashbacks
- different camera angles
- regenerated AI outputs

## Persistence

Reversal does not erase the original Event.

Examples:

injury
→ healing Event

damage
→ repair Event

loss
→ recovery Event

death
→ resurrection Event, only where authorized

## Unknown

UNKNOWN_CAUSE remains unknown.

UNKNOWN does not mean:

- no cause
- no event
- unchanged
- unimportant

## Human Realism

Micro-events may represent:

- breathing
- blinking
- glances
- hesitation
- weight shifts
- listening
- reaction latency
- grip changes
- contact
- balance correction

Micro-events are used only where continuity or realism requires them.

## AI Principle

AI_GENERATION implements approved Event state.

AI does not invent or redefine Event state.

Regeneration of the same Event remains the same Event unless continuity authority
explicitly creates a different Event.

## Ultimate Authority

The global CONTINUITY/state_ledger remains the ultimate continuity authority.
