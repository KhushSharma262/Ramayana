# DATABASE SCOPE, GAPS AND FUTURE EXPANSION

## Current state

The database now covers the major physical material families required for:

- architecture
- terrain
- props
- weapons
- armour
- jewellery
- costumes
- ritual objects
- vehicles
- tools
- furniture
- containers
- vegetation-derived objects
- animal-derived objects
- food
- pigments
- dyes
- coatings
- construction
- environmental close-ups

## Deliberately not exploded into hundreds of species

The database uses family-level files plus individual material records inside them.

A separate file should be created only when:

1. the material is repeatedly used,
2. its physical identity is substantially different,
3. its historical evidence is substantial,
4. it needs independent AI/3D/physics treatment,
5. or the existing category becomes operationally unmanageable.

## Mandatory future additions

Whenever production research identifies a material not covered here:

1. Check whether it belongs to an existing family.
2. Add an individual record before creating a new file.
3. Create a new category file only if justified.
4. Assign a permanent MAT ID.
5. Link evidence.
6. Link physics/structure/behavior/state.
7. Register the material in `12_REGISTRY`.

## No silent modern substitution

If an exact historical material cannot be identified:

UNKNOWN / PROVISIONAL / MULTIPLE_POSSIBILITIES must be used until research or a deliberate production decision resolves it.
