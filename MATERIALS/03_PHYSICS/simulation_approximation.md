# SIMULATION APPROXIMATION

Every approximation must identify:

1. Physical phenomenon being approximated.
2. Exact physical model if known.
3. Simplification introduced.
4. Reason for simplification.
5. Expected effect.
6. Validity range.
7. Error or uncertainty if measurable.
8. Visual consequence.
9. Physical consequence.
10. Whether the approximation is acceptable for the shot.

Never label a visual cheat as physically exact.
