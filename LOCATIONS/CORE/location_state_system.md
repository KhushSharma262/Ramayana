# LOCATION STATE MODEL

Every location has:

1. IDENTITY
2. BASE SPATIAL STATE
3. TEMPORAL STATE
4. ENVIRONMENTAL STATE
5. STORY-EVENT STATE
6. DIVINE-EVENT STATE
7. AFTERMATH STATE
8. RECOVERY STATE

State changes must be explicit.

Example:

NORMAL
    ↓
EVENT ONSET
    ↓
EVENT PEAK
    ↓
EVENT DECAY
    ↓
AFTERMATH
    ↓
RECOVERY
    ↓
NEW NORMAL

A state change must not silently modify permanent geography.

## Permanent state

Examples:

- mountain position
- palace location
- major entrance
- established courtyard
- established altar
- major landmark

## Temporary state

Examples:

- rain
- fog
- smoke
- crowds
- flowers
- ash
- ritual activity
- temporary damage
- divine radiance
- changed atmospheric conditions

## State continuity

Every scene must inherit the correct previous location state.

No scene may reset a location to an earlier state without a narrative reason.
