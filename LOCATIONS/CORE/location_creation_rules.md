# LOCATION CREATION RULES

Create a new location ID only when there is a genuinely distinct
narrative/spatial place.

Do NOT create a new location merely because of:

- day/night
- weather
- season
- camera angle
- lighting
- crowd size
- temporary decoration
- divine effect
- damage
- story aftermath
- different character presence

These are location states.

Create a new location when:

- the physical place is distinct
- the narrative treats it as a distinct destination
- spatial relationships cannot be represented as a sub-space
- travel between places is meaningful
- continuity requires an independent identity

## Sub-space rule

If a room, courtyard, entrance, clearing, platform or chamber
belongs permanently to a parent location, represent it as a
sub-space unless it becomes an independent narrative destination.

Example:

DAKSHA_PALACE
    ├── entrance
    ├── courtyard
    ├── audience space
    └── private interior

Do not automatically create four new locations.

## State rule

If the same place changes because of an event:

same LOCATION ID
+
new LOCATION STATE

not a new location.
