# LOCATION TRANSITION RULES

Locations must have explicit transitions where narrative movement
occurs.

A transition can contain:

ORIGIN
    ↓
DEPARTURE POINT
    ↓
ROUTE
    ↓
INTERMEDIATE SPACE
    ↓
ARRIVAL
    ↓
NEW LOCATION

Examples include:

- departure from Himavan's household
- movement toward tapasya
- wedding procession
- return toward Kailash

The route does not automatically become a permanent location.

Create a separate location only when the route itself becomes a
meaningful narrative space.

Otherwise it is a transition record.

## Transition continuity

Track:

- direction
- approximate distance
- time passage
- characters present
- environmental change
- costume state
- props
- weather
- emotional/performance state
- arrival state

Do not teleport characters between visually incompatible spaces
without establishing the transition or intentionally using an
elliptical edit.
