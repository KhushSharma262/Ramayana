# LOCATIONS

LOCATIONS is the authoritative spatial-definition system for the Ramayan production.

It defines:

- location identity
- canonical location references
- spatial relationships
- topology
- scale
- permanent spatial features
- internal spaces
- location states
- transitions
- continuity
- environmental handoff
- architectural handoff
- scene usage
- AI consistency locks

LOCATIONS does not replace:

CANON
ARCHITECTURE
ENVIRONMENT
SCENES
SHOTS
CINEMATOGRAPHY
CONTINUITY

Each system owns its own domain.

## Fundamental rule

A location is not recreated from scratch for every shot.

The production uses:

LOCATION IDENTITY
    +
LOCATION SPATIAL MODEL
    +
LOCATION STATE
    +
SCENE STATE
    +
SHOT STATE

## Permanent vs temporary

Permanent:
- geography
- major spatial relationships
- established structures
- established landmarks
- canonical location identity

Variable:
- time
- weather
- lighting
- temporary objects
- temporary populations
- story-event effects
- divine-event effects
- damage caused by story events

## Canon rule

No reconstruction may silently become canon.

Every uncertain spatial feature must be classified as:

DIRECT_SOURCE
TRADITIONAL_SOURCE
SECONDARY_SOURCE
RECONSTRUCTION
DIRECTORIAL_CHOICE

## AI rule

AI generation must inherit the approved location state.

AI must not independently redesign:
- geography
- architecture
- entrances
- landmarks
- spatial proportions
- permanent features
- established orientation

unless an approved story event explicitly changes them.
