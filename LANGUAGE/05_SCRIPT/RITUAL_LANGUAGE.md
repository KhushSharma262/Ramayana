# RITUAL LANGUAGE

## SYSTEM IDENTITY

system_name:
  RITUAL_LANGUAGE

system_scope:
  Master system for all ritual, sacred, ceremonial, devotional, mantra,
  prayer, vow, blessing, invocation, yajna, worship, and sacred speech
  appearing in the RAMAYAN project.

system_level:
  SCRIPT_LANGUAGE

primary_source_policy:
  Ramcharitmanas-first

purpose:
  Protect textual accuracy, ritual context, linguistic correctness,
  pronunciation, cultural dignity, performance integrity, and source
  traceability of ritual language.

IMPORTANT:

This file defines HOW ritual language is handled.

It does NOT invent ritual text.

It does NOT write Episode 01 ritual scenes.
